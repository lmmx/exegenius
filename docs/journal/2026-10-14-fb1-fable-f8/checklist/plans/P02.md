# Plan P02

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): There is one deterministic Turing machine with a fixed finite alphabet and a fixed finite number of one-dimensional tapes that computes the exact $2n$-bit product of two $n$-bit integers for every $n\ge1$ in worst-case time $T_A(n)=O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$; hence $n\log n$ is not the optimal order of multiplication cost in this model, contrary to the Schonhage-Strassen conjecture.
  - method: Reduce multiplication to a radix-digit convolution computed by approximate Fourier transforms over the polynomial ring $\mathbb C[y]/(y^r+1)$; accelerate the two operations that would each cost $\Theta(n\log n)$, address rearrangement and butterfly layers, by recursive procedures built from fixed linear networks with a rank saving $s<Wm$; then verify exact recovery of the integer coefficients and sum a cost table whose every term is a power of $\log n$ strictly below one.
  - motivation (explicit): In the transform representation the work consists of address rearrangements, signed shifts and butterflies; since even scanning the array once per transform level already costs $n\log n$, both the data movement and the arithmetic layers must be made sublinear per level, which the two network-based procedures achieve.
  - relies on: n-log-n-barrier, multitape-turing-machine, big-o-notation, binary-numerals-and-bit-strings, subroutines-and-composition-of-algorithms
  - **S1** (show, page `rank-saving-recurrence`): A fixed linear network with $W$ wires, labelled by subspaces of an $m$-dimensional space so that the edge changes need $s<Wm$ smaller calls in total, turns one call at parameter $e=m^k$ on logical volume $V$ into $s$ calls at parameter $e/m$ on role streams of volume $V/W$; the resulting recurrence $F_k\le(s/W)F_{k-1}+O(1)$ for cost per unit volume has solution $F_k=O(e^\tau)$ with $\tau=1-2^{-50}<1$, and in particular two address chunks of $m^k$ digits are interchanged in $O(Ve^\tau)$ time.
    - method: Build a scalar three-stage bank exchange that restores its scratch wires; lift scalars to arrays with a frame at each vertex so that only endpoint operators remain on every role; attach nested subspace labels built from three-element subsets so that the total residual dimension is $Wm-2N+2L$ with $L<N/2$; implement each unit of an edge's rank by one smaller interchange after a triangular factorization; split rows among the $W$ roles so each smaller call has volume $V/W$ and solve the recurrence by a geometric sum.
    - motivation (explicit): Dividing cost by volume, a call at parameter $mf$ contributes $s/W$ times the normalized cost at parameter $f$; because $s/W<m$ this contribution grows more slowly than the parameter, which is exactly a power saving, and the sources name this strict inequality as the source of the saving.
    - relies on: divide-and-conquer-and-recurrences, geometric-series-and-sums, tape-address-model, matrices-vectors-and-linear-maps, rank-and-orthogonal-subspaces, subroutines-and-composition-of-algorithms

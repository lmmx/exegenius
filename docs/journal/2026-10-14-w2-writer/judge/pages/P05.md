A frame on wire arrays is an invertible linear operator attached to each vertex of a network. Frames let the procedures of [Integer multiplication below n log n](main-theorem.md) store each wire in a convenient representation, because the implemented operator depends only on the frames at the inputs and outputs.

Frames act on the wires of the [Linear exchange network with restored scratch wires](linear-network.md) once each scalar is replaced by an array indexed by a finite address set $\Omega$ common to all wires. Let $\mathsf S_\Omega$ denote the network acting on these arrays; its scalar gates act pointwise, address by address. A source starts an input wire, a sink ends an output wire, and a gate combines wire values.

Each source, gate and sink $v$ carries an invertible linear operator $D_v$ on arrays indexed by $\Omega$, called its frame. Each frame is checked invertible by the rank criterion of [Rank, subspaces and orthogonal complements](linear-algebra-basics.md): it has full rank, so $D_v^{-1}$ exists. An edge from a vertex $u$ to a vertex $v$ applies $D_vD_u^{-1}$ to the wire's array, so the logical array is stored in frame $D_u$ before the edge and $D_v$ after it. A gate's edges all use its frame.

A wire's fixed place in the network is its role $w$. Let $\mathrm{source}(w)$ be the source of input role $w$. Let $\mathrm{sink}(w)$ be the sink of output role $w$. Let $D_{\rm in}=\bigoplus_w D_{\mathrm{source}(w)}$ and $D_{\rm out}=\bigoplus_w D_{\mathrm{sink}(w)}$ be their block-diagonal sums over all roles. A supplied input $f$ has logical array $g=D_{\rm in}^{-1}f$.

Claim: at each vertex $v$ the stored array equals $D_v g$, with $g$ the logical array there. The claim holds at the sources by the definition of $g$. It passes along an edge by applying $D_vD_u^{-1}$. It passes through a pointwise linear gate $G$ with $z$ incoming arrays, since $G(D_v g_1,\dots,D_v g_z)=D_v\,G(g_1,\dots,g_z)$ by linearity. Induction carries it to the sinks, so the network maps $f$ to $D_{\rm out}\,\mathsf S_\Omega\,D_{\rm in}^{-1}f$.

Take a route from a source $q$ through a gate $x$ to a sink $p$. Its edge operators $D_xD_q^{-1}$ and $D_pD_x^{-1}$ multiply to $D_pD_q^{-1}$, so the frame $D_x$ cancels. For a signed role permutation sending input role $w$ to output role $\rho(w)$ with sign $\varepsilon_w$, each route applies $\varepsilon_w D_{\mathrm{sink}(\rho(w))}D_{\mathrm{source}(w)}^{-1}$ to its array, auxiliary roles included. So interior frames can be chosen to make each edge cheap.

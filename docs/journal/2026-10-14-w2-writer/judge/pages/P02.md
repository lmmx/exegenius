A frame is an invertible linear operator attached to a vertex of a linear network run on arrays: it says how a wire's array is stored there. Each route then applies an operator fixed by its end frames, leaving interior frames free to make steps cheap.

Replace each scalar of the [linear exchange network](linear-network.md) by an array in $R^\Omega$, where $R$ is the scalar ring and $\Omega$ a finite address set shared by all wires, and apply each gate at every address; call the result $\mathsf S_\Omega$.

At each vertex $v$ (source, gate or sink) choose an invertible $R$-linear frame $D_v$ on $R^\Omega$; unlike a gate, it may mix addresses. All wires at a gate share its frame; an edge from $u$ to $v$ applies the change of frame $D_vD_u^{-1}$. $D_{\rm in}$ applies $D_{\mathrm{source}(w)}$ to the input array on each role $w$; $D_{\rm out}$ applies $D_{\mathrm{sink}(w)}$ to each output.

Read a physical input $f$ as the logical input $g=D_{\rm in}^{-1}f$; no work is done. Invariant: at each vertex $v$ the stored array is $D_v$ applied to the logical array, which $\mathsf S_\Omega$ holds there on input $g$. It holds at sources by definition. An edge carrying logical array $\varphi$ turns stored $D_u\varphi$ into $D_v\varphi$. A gate outputs combinations $\sum_jc_j\varphi_j$ of its logical inputs $\varphi_j$, with coefficients $c_j\in R$ equal at every address, so by linearity $\sum_jc_jD_v\varphi_j=D_v\sum_jc_j\varphi_j$: the shared frame commutes with the gate. By induction the invariant reaches the sinks, so the network implements $D_{\rm out}\,\mathsf S_\Omega\,D_{\rm in}^{-1}$ <cite data-source="paper">The implemented operator is therefore</cite>.

The exchange network sends input role $w$ to output role $\rho(w)$ with sign $\varepsilon_w=\pm1$, where $\rho$ swaps the two banks and fixes every scratch role. So $\mathsf S_\Omega$ moves the logical array $g_w$ of $w$ to role $\rho(w)$ as $\varepsilon_wg_w$, and the route from $w$ applies $\varepsilon_wD_{\mathrm{sink}(\rho(w))}D_{\mathrm{source}(w)}^{-1}$ to its input array, scratch roles included. Interior frames cancel because edge changes telescope, $(D_{v_2}D_{v_1}^{-1})(D_{v_1}D_{v_0}^{-1})=D_{v_2}D_{v_0}^{-1}$ for consecutive vertices $v_0,v_1,v_2$ on a wire, and gates let their frame through; they only set edge costs.

In the bit procedure, addresses contain two chunks $h,d$ of $m$ fields each; vertex $v$ gets a rational $m\times m$ matrix $M_v$ and the frame $\Phi_{M_v}$ moving the entry at $(h,d)$ to $(h+M_vd,\,d)$. An edge applies $\Phi_{M_v}\Phi_{M_u}^{-1}=\Phi_{M_v-M_u}$; the matrices satisfy $M_{\mathrm{sink}(\rho(w))}-M_{\mathrm{source}(w)}=I_m$, so every role receives the shear $h\gets h+d$ <cite data-source="paper">M_{\mathrm{sink}(\rho(w))}-M_{\mathrm{source}(w)}=I_m</cite>. The cost of an edge is counted by the [rank](linear-algebra-basics.md) of $M_v-M_u$, one smaller interchange per unit <cite data-source="paper">implements an edge change with one smaller interchange per unit of its rational rank</cite>.

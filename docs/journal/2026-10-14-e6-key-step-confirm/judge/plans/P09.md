# Plan P09

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A single deterministic multitape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, disproving the $n\log n$ optimality conjecture.
  - method: reduce integer multiplication to convolution over a polynomial ring, and speed up the data movement and the butterfly layers of its transforms with two new tape procedures that each save a power of the logarithm
  - motivation (explicit): Scanning an array of $\Theta(n)$ bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so savings are needed in both movement and arithmetic.
  - relies on: integer-multiplication-conjecture, multitape-tm, big-o, established-multiplier
  - **R1** (show, page `tape-address-model`): Arrays stored in lexicographic order on tapes support linear-time rearrangements: digit moves, row splitting and controlled cyclic shifts.
    - method: state the storage convention and prove the two elementary linear-time scan lemmas
    - motivation (reconstructed): Every later procedure is built from scans of the stored array, so the paper first fixes how an address is implicit in tape position and which rearrangements cost only $O(V)$, the baseline against which the later savings are measured.
    - relies on: multitape-tm, binary-representation-and-bit-operations, sorting-and-data-movement-on-tapes, finite-alphabet-encodings-and-constant-factor-simulation
    - **R1.1** (infer, page `elementary-stream-ops`): Splitting on a digit, permuting two digits, moving a digit and dealing rows cyclically to $W$ streams are all $O(V)$-time scans on a fixed number of tapes.
      - relies on: tape-address-model, sorting-and-data-movement-on-tapes, finite-alphabet-encodings-and-constant-factor-simulation
      - quotes line 494: "volume $V$ takes $O(V)$ steps on a fixed number of one-dimensional tapes:"

      - relies on: tape-address-model, elementary-stream-ops, modular-arithmetic, primes-coprimality-and-gcd

# Plan P14

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A deterministic multitape Turing machine multiplies two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: Reduce the product to a convolution of radix digits evaluated by approximate Fourier transforms over a polynomial ring, make the transform's address movement and arithmetic cheaper with two new tape procedures, then show the result is exact and add up the cost.
  - motivation (explicit): Scanning the data once per transform level already costs $\Theta(n\log n)$, so a power saving needs savings in both address movement and arithmetic, one tape procedure for each.
  - relies on: n-log-n-barrier, convolution, multitape-turing-machine, big-o-notation

    - method: Build the interchange from elementary scans and controlled shifts and a fixed linear network with a rank saving for power widths, then pad to arbitrary widths.
    - motivation (explicit): A network whose total edge rank is below the wire count times the dimension turns the interchange cost into a recurrence with a power saving, which a plain pass over the array per level cannot give.

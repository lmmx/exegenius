# Plan P13

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): One deterministic multitape Turing machine multiplies $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, refuting the $n\log n$ optimality conjecture in this model.
  - method: Reduce the product to a convolution of short digits evaluated by Fourier transforms, speed up the two costly ingredients (moving data between addresses, and butterfly arithmetic) by a power of a block size using one recursive saving, and total every cost term.
  - motivation (explicit): A plain transform scans $\Theta(n)$ bits at each of $\Theta(\log n)$ levels, which already costs $n\log n$, so both the data movement and the arithmetic must be made cheaper than a full scan per level.
  - relies on: schonhage-strassen-conjecture, multitape-turing-machine, big-o-notation, asymptotic-notation-beyond-big-o, limits-and-limit-inferior, subroutines-and-reductions-between-problems

    - motivation (explicit): The later tape procedures only use a few elementary scans, so they are proved once up front.

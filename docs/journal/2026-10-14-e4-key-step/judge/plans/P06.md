# Plan P06

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A single deterministic multitape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: reduce multiplication to a convolution computed by Gaussian-resampling, Bluestein and synthetic transforms, accelerate the address movement and butterfly layers by two network-based tape procedures, and add up the costs
  - motivation (explicit): Scanning the array at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so both the movement and the arithmetic of the transforms must be made cheaper.
  - relies on: history, big-o, multitape-tm
  - **S1** (show): The tape toolkit: elementary stream scans, controlled shifts, and the finite exchange networks with rank saving are available on a fixed number of tapes.
    - method: collect the stream operations and the finite networks that both tape procedures use
    - motivation (reconstructed): Both procedures run on the same elementary scans and the same kind of finite network, so these are set up once before either is built.
    - **S1.1** (infer, page `stream-ops`): An array with a product address set, stored in lexicographic order, supports digit permutation, digit move, splitting on a digit with a pointwise map and merging, and cyclic row splitting into streams, each in $O(V)$ time on a fixed number of tapes.
      - relies on: lexicographic-order-and-mixed-radix-indexing, multitape-tm, tape-based-subroutines-and-stacks, sorting-merging-and-radix-sort
      - quotes line 494: "volume $V$ takes $O(V)$ steps on a fixed number of one-dimensional tapes:"
    - **S1.2** (infer, page `controlled-shift`): Updating a later address field $y$ by $y+a(\text{controls})$ modulo $q^b$, or multiplying it by a fixed rational unit, costs $O(V)$.
      - relies on: stream-ops, modular-arithmetic, dyadic-and-rational-numbers, primes-divisibility-coprimality-and-gcd

      - motivation (explicit): The tape procedures need a network whose representation changes along edges are cheap; the scalar gadget fixes what is computed, the frames separate what is computed from how it is stored, and the labels make the edge changes few.
      - relies on: linear-algebra, sets-subsets-and-binomial-coefficients, xor-and-mod-2-arithmetic, matrices-and-matrix-vector-products

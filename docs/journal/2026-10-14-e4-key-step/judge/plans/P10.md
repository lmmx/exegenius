The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): One deterministic multitape Turing machine multiplies $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, using fast address interchange, fast simultaneous butterfly layers, and the resampling, chirp and synthetic-convolution reduction.
  - method: supply the two fast tape procedures, then insert them into a reduction from the integer product to polynomial-ring convolution, and add up every cost
  - motivation (explicit): Scanning $\Theta(n)$ bits at each of $\Theta(\log n)$ transform levels costs $\Theta(n\log n)$, so both data movement and arithmetic need a power saving, and the reduction must be arranged so that both procedures apply.
  - relies on: integer-multiplication-problem, optimality-conjecture, harvey-hoeven-multiplier, turing-machine, big-o

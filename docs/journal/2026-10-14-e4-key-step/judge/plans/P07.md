# Plan P07

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A single deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: Replace the logarithmic number of full scans of Fourier-transform multiplication by two power-saving tape procedures, build an exact convolution-based multiplier around them, and add up the costs
  - motivation (explicit): Scanning $\Theta(n)$ bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so both the data movement and the butterfly arithmetic must be made cheaper than one scan per level.
  - relies on: fixed-tape-model, nlogn-conjecture, hvdh-multiplier
  - **S1** (show, page `chunk-interchange`): Interchanging two disjoint contiguous $u$-bit address fields of an array of volume $V$ takes $O(Vu^\tau)$ time for a fixed $\tau<1$, by recursing through a network of $W$ wires and $m$-dimensional labels that makes only $s<Wm$ smaller interchanges.
    - method: Build a fixed linear network whose edge changes cost rank-many smaller interchanges, and solve the resulting rank-deficit recursion
    - motivation (explicit): An edge change of rank $a$ costs $a$ smaller interchanges, and because the total rank is below the number of wires times $m$, the recursion on chunk width grows only by a power less than one.
    - relies on: fixed-tape-model, recurrences-and-divide-and-conquer, xor-and-arithmetic-over-f₂
    - **S1.1** (infer, page `streams`): Splitting, merging and fixed permutations of digits of an array stored in lexicographic address order cost $O(V)$ by linear scans on a fixed number of tapes.
      - relies on: fixed-tape-model, lexicographic-order-and-mixed-radix-indices, tape-basics
      - quotes line 493: "Each of the following operations on an array of volume $V$ takes $O(V)$ steps on a fixed number of one-dimensional tapes:"
    - **S1.2** (infer, page `controlled-shifts`): Adding to a later address field an offset computed from earlier fields, or multiplying it by a fixed unit modulo $q^b$, costs $O(V)$.
      - relies on: streams, modular-arithmetic, division-with-remainder
      - quotes line 561: "Suppose a target field $y\in[Q]$ follows its control fields, each control used in an offset having $O(b)$ digits."
    - **S1.3** (infer, page `scalar-exchange-network`): A fixed linear network of copy, gather, scatter and side-injection gates on banks $X,Y$ and scratch wires sends $(X,Y)$ to $(-Y,X)$ in three stages and restores arbitrary initial scratch values.
      - relies on: three-subset-pairing, linear-algebra, xor-and-arithmetic-over-f₂
      - quotes line 729: "For arbitrary initial values of its auxiliary wires, a forward invocation changes $y_S$ to $y_S+x_S$ and leaves every other value unchanged."
    - **S1.4** (infer, page `frames`): If each vertex $v$ of the network carries an invertible operator $D_v$ so that stored arrays are $D_v$ applied to logical arrays, pointwise gates commute with the common frame and the network implements $D_{\rm out}\,\mathsf S\,D_{\rm in}^{-1}$, leaving only the edge changes $D_vD_u^{-1}$ to pay for.
      - relies on: scalar-exchange-network, linear-algebra, matrices-and-linear-maps
      - quotes line 812: "Thus the common frame commutes with the pointwise gate, and the invariant continues to the sinks."
    - **S1.5** (infer, page `subspace-labels`): Nested nondegenerate subspaces of an $m$-dimensional space attached to the gates and terminals make the only dimension losses the central-wire returns, so the total rank of the edge changes satisfies $s<Wm$.
      - relies on: three-subset-pairing, linear-algebra, frames
      - quotes line 998: "Every edge joins comparable nondegenerate labels. The only decreasing edges are the central-wire edges from time 3 to time 4; their dimension loss is $h$."
    - **S1.6** (infer, page `bit-network`): The $\mathbb F_2$ network with $W_{\rm b}$ wires and rational labels has endpoint matrices differing by the identity on every input role, which gives the address shear $H\leftarrow H+D$ on every role at total edge rank $s_{\rm b}<W_{\rm b}m$.
      - relies on: scalar-exchange-network, frames, subspace-labels, power-saving-recursion, linear-algebra
      - quotes line 1139: "The bit network has $W_{\rm b}$ wires, uses only pointwise XOR gates, and sends its input vector to the permutation $\rho$ of that vector."
    - **S1.7** (infer, page `lower-triangular-factorization`): Every rational matrix $A$ of rank $a$ equals $E_1\Pi E_2$ with $E_1,E_2$ invertible lower triangular and $\Pi$ a partial permutation with exactly $a$ ones.
      - relies on: linear-algebra, matrices-and-linear-maps
      - quotes line 1366: "Every rational $m\times m$ matrix $A$ of rank $a$ has a factorization"
    - **S1.8** (infer, page `address-shear`): The permutation $(H,D)\mapsto(H+AD,D)$ of address fields modulo $q^b$ is done with exactly $\operatorname{rank}(A)$ interchanges of $b$-digit fields plus $O(V)$ work, using triangular factors and controlled shifts.
      - relies on: controlled-shifts, lower-triangular-factorization, bit-network, streams, modular-arithmetic
      - quotes line 1406: "can be performed with exactly $a$ interchanges of pairs of $b$-digit fields and $O(V)$ further work."
    - **S1.9** (infer, page `power-saving-recursion`): The network makes $s<Wm$ calls on streams of volume $V/W$, so the per-volume cost obeys $F_k\le(s/W)F_{k-1}+O(1)$ with $s/W<m^\tau$, giving $F_k=O(e^\tau)$ at width $e=m^k$, scheduled depth first on fixed tapes.
      - relies on: recurrences-and-divide-and-conquer, asymptotic-notation-beyond-big-o, streams, frames, subspace-labels
      - quotes line 1554: "For $a=s/W<m^\tau$ the geometric sum $\sum_{j=0}^k a^j$ is $O(m^{k\tau})$."
    - **S1.10** (infer): Arbitrary widths and row counts reduce to power widths with enough rows, supplied by a few of the array's own high digits at cost below the final bound, so the interchange costs $O(Vu^\tau)$ for every $u$.
      - quotes line 1628: "Rows for a general array can be supplied by a few of its own high digits."
  - **M** (show, page `multiplication-algorithm`): Digits in radix $2^b$ are placed on distinct prime cyclic axes, two source transforms (Gaussian resampling with chirp convolution over the ring via a twist) and one opposite transform give their convolution, and rescaling, rounding and carrying yield the exact $2n$-bit product.
    - method: Reduce the product to a radix-digit convolution, compute it with Fourier transforms made of Gaussian resampling, chirps and synthetic ring convolution, then recover exact integers
    - motivation (explicit): Multiplication is a convolution of the digit sequences, and a Fourier transform turns convolution into pointwise multiplication.
    - relies on: convolution, dft, hvdh-multiplier
    - **D** (show, page `synthetic-convolution`): Two forward synthetic transforms, a pointwise ring product by signed packing and the opposite transform give the normalized convolution $(f*g)/T$ over $\mathbb C[y]/(y^r+1)$, with $T=rM$, error below $\sqrt2\,M(3\ell+1)2^{-p}$ and cost $O(Tp[dK+pK^{\tau-1}+\ell d^{\lambda'}+\log(rp)])$.
      - method: Apply the convolution theorem over the ring: transform both operands, multiply pointwise, transform back
      - motivation (recoverable): Convolution becomes pointwise multiplication under a Fourier transform; over this ring the transform needs only signed shifts and the pointwise products are polynomial products done by the established multiplier.
      - relies on: convolution, dft, fixed-point
      - **C** (show, page `transform-layout`): Placing the selected bits of the participating axes at a common offset in $K$-bit chunks lets every synthetic transform round use the simultaneous layer, so a transform of $T$ entries costs $O(Tp[dK+pK^{\tau-1}+\ell d^{\lambda'}])$.
        - method: Build the simultaneous layer, define the synthetic transform and its stored order, then lay out the axes so each round is one layer call
        - motivation (explicit): Each radix-two round must act on the same bit position of many axes at once for the layer to apply, so the axes' bits have to be brought to a common offset in consecutive chunks.
        - relies on: fixed-point, chunk-interchange
        - **B** (show, page `simultaneous-layer`): Applying $H_0(u,v)=((u+v)/2,(u-v)/2)$ at one common bit position of $D\le d$ address chunks of an array of $r$-coefficient polynomial records, then truncating once to the $2^{-p}$ grid, takes $O(Vd^{\lambda'})$ time with error below $\sqrt2\,2^{-p}$, rather than $D$ whole-array passes.
          - method: Write the layer as a tensor product of the two-point kernel $C$ through phase frames of the complex network, recurse on $e=mf$ axes with rank-deficit calls, make the basis changes by packed bit additions, and evaluate exactly in Gaussian dyadics before one truncation
          - motivation (recoverable): The rank-deficit recursion that speeds up address interchange also applies to a network of two-point kernels; the layer must be evaluated exactly in dyadics because the intermediate operators are not contractions.
          - relies on: fixed-point, dyadic-exact, chunk-interchange, power-saving-recursion
          - **B1** (infer, page `phase-frames`): A complex network with binary labels and Hadamard-conjugated phase frames $i^{\operatorname{wt}(P_Ux)}$ makes every edge a product of translation kernels $aI+bX_v$ and produces $C^{\otimes e}$ on every role, where $C=H\operatorname{diag}(1,i)H$, and $H_0=b\,\mathsf S C\mathsf S$.
            - relies on: scalar-exchange-network, frames, subspace-labels, linear-algebra, complex-numbers, xor-and-arithmetic-over-f₂
            - quotes line 1911: "Proposition~\ref{prop:complex-motif-interface} therefore gives $C^{\otimes e}$ on every role, including roles whose initial scratch values were arbitrary."
          - **B2** (infer, page `packed-selected-bits`): A binary row addition on corresponding selected bits of address chunks, which implements the binary basis changes, takes a constant number of whole-chunk cyclic shifts followed by repair of an explicitly bounded exceptional set of addresses.
            - relies on: chunk-interchange, controlled-shifts, streams, xor-and-arithmetic-over-f₂
            - quotes line 1947: "The construction first uses a constant number of cyclic shifts of whole chunk ranges, then corrects an explicitly bounded set of addresses."
          - **B3** (infer): A node of $e=m^k$ selected axes makes $s_{\rm c}<W_{\rm c}m$ recursive calls on slots of $e/m$ axes, each on a $1/W_{\rm c}$ share of the volume, so the same rank-deficit recursion gives cost $O(d^{\lambda'})$ per unit volume.
            - relies on: power-saving-recursion, phase-frames, packed-selected-bits
            - quotes line 2289: "The phase construction supplies one recursive call on a slot for each vector in an edge residual basis, hence exactly \(s\) calls in one invocation of the network."
          - **B4** (infer, page `dyadic-exact`): Intermediate values of a butterfly layer are Gaussian integers over powers of two, computed exactly with a guard width of $O(d^{20})=o(p)$ extra bits, with a single truncation at the end.
            - relies on: fixed-point, two-s-complement-and-truncation, complex-numbers, binary-representation-and-integer-arithmetic
            - quotes line 2452: "The accelerated network is evaluated exactly until an entire normalized butterfly layer is complete."
          - **B5** (infer): Every row of the layer matrix has absolute sum one, so the layer maps disk arrays to disk arrays and the single final truncation toward zero adds error below $\sqrt2\,2^{-p}$.
            - relies on: fixed-point, dyadic-exact, inequalities-for-error-bounds
            - quotes line 2752: "Thus $\mathcal H$ maps disk arrays to disk arrays, and componentwise truncation preserves that disk"
        - **C1** (show, page `synthetic-transform`): Over $\mathcal R_r=\mathbb C[y]/(y^r+1)$ the normalized transforms $F_t^{-}$ and $F_t^{+}$ with roots of unity $\omega_t=y^{2r/t}$ are evaluated by radix-two butterfly rounds whose twiddle multiplications are signed shifts.
          - method: Run the radix-two decimation-in-frequency recursion with powers of $y$ as the roots of unity
          - motivation (explicit): Powers of $y$ serve as roots of unity and multiplication by such a root is a signed shift of the coefficient list.
          - relies on: dft, ring-mod-yr-plus-1, butterfly
          - **C1.1** (infer, page `ring-mod-yr-plus-1`): In $\mathbb C[y]/(y^r+1)$ with $y^r=-1$, multiplication by any power of $y$ permutes the coefficients and changes some signs, so it is a signed shift and an isometry for the maximum coefficient norm.
            - relies on: polynomials, complex-numbers, modular-arithmetic
            - quotes line 2782: "Multiplication by $y^a$, for any integer $a$, permutes the coefficients and changes some signs; consequently it is an isometry for this norm."
          - **C1.2** (infer): Character sums of $\omega_t=y^{2r/t}$ vanish unless $t\mid j$, shown directly because the ring has zero divisors, so $F_t^+F_t^-=t^{-1}I$.
            - relies on: ring-mod-yr-plus-1, dft
            - quotes line 2807: "The ring has zero divisors, so we verify character cancellation directly instead of dividing by $\omega_t^j-1$."
          - **C1.3** (infer, page `butterfly`): The map $H_0$, followed by multiplying one output by a power of $\omega_t$, splits a length-$t$ transform into two half-length transforms (decimation in frequency), and $\log_2 t$ rounds give the transform.
            - relies on: dft, fast-fourier-transform-as-an-algorithm, recurrences-and-divide-and-conquer
            - quotes line 2832: "For $t\geq2$, the decimation-in-frequency step pairs $z_k$ with $z_{k+t/2}$ for $0\leq k<t/2$."
        - **C2** (infer, page `stored-order`): The forward synthetic transform writes its outputs in bit-reversed slots, and the pointwise product and the opposite-sign transform consume that same order, so no reordering is executed.
          - relies on: synthetic-transform, butterfly, sets-functions-and-permutations
          - quotes line 2869: "The recursion writes its outputs directly in this order; it does not move whole frequency indices."

          - relies on: chunk-interchange, simultaneous-layer, fixed-point

      - **D1** (infer, page `signed-packing`): Evaluating polynomials at $2^{4p}$ (a signed Kronecker substitution) turns one product in the ring into four integer products by the established multiplier, and centered coefficients are read back, in $O(rp\log(rp))$ time.
        - relies on: ring-mod-yr-plus-1, hvdh-multiplier, fixed-point, two-s-complement-and-truncation
        - quotes line 3228: "One can compute the exact Gaussian integer numerators of $fg$, and then return $Q_p(fg/r)$ in that same format, in time $O(rp\log(rp))$ on a fixed number of tapes."
      - **D2** (infer): Both forward transforms keep the layout order, the records are multiplied pointwise in that order, and the opposite transform followed by exact scaling by $M$ returns $\mathcal M_r(f,g)=(f*g)/T$.
        - relies on: stored-order, signed-packing, convolution, dft
        - quotes line 3415: "Perform both forward transforms and retain their common $LB$ order."
    - **M1** (infer, page `gaussian-resampling`): Gaussian resampling expresses the Fourier transform of length $s_i$ through a power-of-two length $t_i>s_i$ transform by contractions $A$ and $B_0$, with $P_{s_i}F_{s_i}=2^{2\alpha^2}B_0P_{t_i}F_{t_i}A$ and a small error $N-I$.
      - relies on: dft, fixed-point, complex-numbers, inequalities-for-error-bounds, convolution
      - quotes line 3559: "There are linear contractions $A:\mathbb C^s\to\mathbb C^t$ and $B_0:\mathbb C^t\to\mathbb C^s$ satisfying"
    - **M2** (infer): The one-dimensional maps are applied one coordinate line at a time to a $d$-fold tensor, giving $RF_{\boldsymbol s}=2^\gamma\mathcal B_0QF_{\boldsymbol t}\mathcal A$ at line cost $O(dTp^{3/2+\delta}\alpha)$, with axis movement by the fast interchange.
      - relies on: gaussian-resampling, chunk-interchange
      - quotes line 3796: "For the tensor product, apply the one-dimensional maps to one coordinate line at a time."
    - **M3** (infer, page `bluestein-chirp`): A Fourier transform is a pointwise phase multiplication, a cyclic convolution with a chirp array $a$, and another phase multiplication: $QF_{\boldsymbol t}u=\overline a\cdot(a*(\overline a\cdot u))/T$.
      - relies on: dft, convolution, gaussian-resampling, complex-numbers
      - quotes line 3901: "The factor $QF_{\boldsymbol t}$ in \eqref{eq:no-sort-tensor} can be computed from a cyclic convolution and two pointwise phase multiplications."
    - **M4** (infer, page `retained-permutations`): The chirp absorbs the target permutation $Q$, and the source permutation $R$ cancels across two forward transforms, a pointwise product and the opposite transform: $(RF_{\boldsymbol s}^+)[(RF_{\boldsymbol s}u)\cdot(RF_{\boldsymbol s}v)]=(u*v)/S^2$.
      - relies on: bluestein-chirp, gaussian-resampling, dft, convolution, sets-functions-and-permutations
      - quotes line 3905: "The second identity shows how the retained source permutation $R$ cancels when computing a convolution."
    - **M5** (infer, page `size-parameters`): Taking $b=\lceil\log_2 n\rceil$, $p=6b$, $d\approx b^\epsilon$, $K\approx d^c$, $T\approx n/b$ a power of two, axis lengths $t_i\in\{r/2,r\}$ and distinct odd primes $s_i$ just below $t_i$ with $T/2<S<T$ gives $Tp=\Theta(n)$ and $r$ larger than every power of $p$.
      - relies on: primes-divisibility-and-coprimality, logarithms-floors-and-ceilings, fixed-point, asymptotic-notation-beyond-big-o
      - quotes line 4058: "Take the power of two $T$ in $[4n/b,8n/b)$, and let $r=2^{\lceil(\log_2T)/d\rceil}$ and $\ell=\log_2r$."
    - **M6** (infer, page `digit-convolution`): Writing both inputs in radix $2^b$ with $q=\lceil n/b\rceil$ digits, the product coefficients are a cyclic convolution of length $S>2q-2$ with no wraparound and each coefficient is below $2^{3b}$.
      - relies on: convolution, polynomials, schoolbook-and-karatsuba-multiplication, binary-representation-and-integer-arithmetic
      - quotes line 4188: "Thus convolution modulo $x^S-1$ has no nonzero wraparound."
    - **M7** (infer, page `crt-cyclic-axes`): For pairwise coprime lengths $s_i$ the map $x\mapsto\prod_i x_i^{\mu_i}$ turns a length-$S$ cyclic convolution into convolution on a product of prime cyclic axes, realized by triangular controlled shifts.
      - relies on: convolution, digit-convolution, primes-divisibility-and-coprimality, modular-arithmetic, controlled-shifts, chunk-interchange
      - quotes line 4219: "Hence $\Phi$ is an isomorphism and preserves cyclic convolution."
    - **M8** (infer, page `phase-twist`): Multiplying coefficient $k$ by $\zeta^k$ with $\zeta=e^{\pi i/r}$ maps $\mathbb C[x]/(x^r-1)$ isomorphically onto $\mathbb C[y]/(y^r+1)$, so negative wrap becomes cyclic wrap.
      - relies on: ring-mod-yr-plus-1, convolution, complex-numbers
      - quotes line 4308: "On the bases $(x_d^k)_{0\le k<r}$ and $(y^k)_{0\le k<r}$ it is diagonal, multiplying coefficient $k$ by the nonzero number $\zeta^k$."
    - **M9** (infer): The digits are placed on the prime axes by $\Phi$, two source transforms and one opposite transform with a pointwise product give the digit convolution, and two exact rescalings by $S$ and $2^{2b+4}$ follow.
      - relies on: crt-cyclic-axes, synthetic-convolution, retained-permutations, phase-twist
      - quotes line 4508: "Apply the coefficient-address map $\Phi$, with its padded layout, to obtain source arrays $u,v$."
    - **M10** (infer, page `exact-recovery`): Undoing the known scales $S$ and $2^{2b+4}$ leaves coefficient error below $1/2$, so rounding gives the exact integer coefficients and carry propagation in radix $2^b$ gives the exact $2n$-bit product.
      - relies on: fixed-point, digit-convolution, crt-cyclic-axes, inequalities-for-error-bounds, two-s-complement-and-truncation, division-with-remainder
      - quotes line 4730: "The strict error below $1/2$ makes the nearest integer to that value the unique correct coefficient."
  - **S3** (infer, page `cost-accounting`): Dividing each cost term by $Tp$ leaves powers of $p$ with margins $g_i$ below one; the smallest margin is $2\kappa=2^{-181}$, which absorbs any polylogarithmic factor and gives total time $O(n(\lg n)^{1-\kappa})$.
    - relies on: big-o, asymptotic-notation-beyond-big-o, size-parameters, synthetic-convolution, chunk-interchange, multiplication-algorithm
    - quotes line 4854: "Thus $\min_i g_i=2^{-181}=2\kappa$."

  - method: Build two fast tape procedures from fixed linear networks with a rank deficit, use them to accelerate synthetic polynomial transforms, reduce integer multiplication through radix digits, Chinese-remainder axes, Gaussian resampling and chirps to such convolutions, then recover the exact product and tally the cost.
  - motivation (explicit): Scanning an array of n bits at each of log n transform levels already costs n log n, so we therefore need savings in both movement and arithmetic.

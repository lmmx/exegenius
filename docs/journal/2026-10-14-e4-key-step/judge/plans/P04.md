# Plan P04

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `integer-multiplication-below-nlogn`): One deterministic fixed-alphabet, fixed-tape Turing machine multiplies two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ worst-case time, where $\kappa=2^{-182}$.
  - method: Reduce the product to a convolution of radix digits evaluated by synthetic-transform Fourier transforms, and cut the cost of their data movement and arithmetic with two power-saving tape procedures built on finite linear networks
  - motivation (explicit): Scanning $\Theta(n)$ bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so both movement and arithmetic must be sped up.
  - relies on: nlogn-conjecture, convolution, nlogn-multiplier-subroutine, karatsuba-and-classical-multiplication-algorithms, deterministic-algorithms-and-worst-case-time, turing-machine-tapes, big-o
  - **S1** (show): Elementary scans on a fixed number of tapes (digit moves, splitting and merging streams, cyclic row splitting, controlled shifts) cost $O(V)$ time in the logical volume $V$.
    - method: Collect the linear-time scan operations that every later tape procedure is built from
    - motivation (explicit): The later procedures are assembled from these scans, so they must be shown to cost only linear time first.
    - relies on: tape-address-arrays
    - **S1.1** (infer, page `elementary-stream-operations`): Permuting or moving a radix-$q$ digit, splitting on a digit and merging, and splitting whole rows cyclically into $W$ streams each take $O(V)$ steps.

  - **S3** (show, page `address-chunk-interchange`): Two disjoint equal-width address chunks of $u$ bits in a bit array of volume $V$ can be interchanged on a fixed number of tapes in $O(Vu^\tau)$ time for a fixed rational $\tau<1$.

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A single deterministic multitape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: Build the algorithm bottom-up: two fast tape primitives (address-chunk interchange and simultaneous butterfly layers), synthetic transforms and ring convolution built on them, Gaussian resampling with retained permutations to reach prime-length transforms, the digit-convolution algorithm with its exactness proof, and a cost table.
  - motivation (explicit): Scanning the data at each of the logarithmically many transform levels already costs $n\log n$, so the saving has to come from both data movement and arithmetic.
  - relies on: history, multitape-tm, big-o
  - **S1** (show, page `chunk-interchange`): Interchanging two disjoint $u$-bit address fields of an array in which all address combinations occur costs $O(Vu^{\tau})$ for a fixed $\tau<1$.

    - motivation (explicit): Doing the interchange by sorting would cost a logarithmic factor; the network lets the same operation recurse into pieces whose total size is only slightly less than a naive $m$-fold branching, which is already enough for a power saving.
    - relies on: modular-arithmetic, xor-and-mod-2-arithmetic, lexicographic-order-and-mixed-radix-indexing

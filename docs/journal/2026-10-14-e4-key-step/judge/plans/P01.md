# Plan P01

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): One deterministic fixed-tape Turing machine multiplies $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, which refutes the $n\log n$ optimality conjecture in this model.
  - method: build two faster tape primitives (address interchange and simultaneous butterfly layers) from recursive linear networks with a rank saving, then run them inside the Gaussian resampling, chirp and synthetic convolution reduction of integer multiplication to convolution, and add up the costs
  - motivation (explicit): Scanning an array of $\Theta(n)$ bits at each of $\Theta(\log n)$ transform levels already costs $n\log n$, so both data movement and arithmetic must be sped up.
  - relies on: integer-multiplication-problem, optimality-conjecture, harvey-hoeven-multiplier
  - **S1** (show): Linear-time stream scans and controlled cyclic shifts are available on a fixed number of tapes.
    - method: collect the elementary array scans and the ordered affine updates that every later procedure calls
    - motivation (explicit): Interchanging fields whose lengths grow is not a bounded number of scans, so the paper first fixes which operations are linear in the volume, with counters and rewinds charged.
    - relies on: turing-machine, binary-counters-and-finite-state-bookkeeping
    - **S1.1** (infer, page `elementary-streams`): Fixed digit permutations, digit moves, splitting into aligned streams, pointwise maps, merging and cyclic row splitting each take $O(V)$ steps on an array of volume $V$.
      - relies on: turing-machine, binary-counters-and-finite-state-bookkeeping, sets-functions-bijections-and-permutations
      - quotes line 507: "The bounds include shape preparation, counter initialization and resets,"
    - **S1.2** (infer, page `controlled-cyclic-shifts`): Updating a later address field $y \mapsto y + a(\text{controls}) \bmod q^b$ and multiplying by a fixed rational unit mod $q^b$ cost $O(V)$.
      - relies on: elementary-streams, modular-arithmetic-and-congruences, greatest-common-divisor-and-the-euclidean-algorithm, stacks-and-queues
      - quotes line 564: " y\longmapsto y+a(\text{controls})\pmod Q"

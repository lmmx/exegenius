# Plan P12

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time, with $\kappa=2^{-182}$.
  - method: reduce the product to a convolution evaluated by Fourier-type transforms, make the two bottlenecks (address movement and butterfly layers) cheaper by recursive linear networks, then assemble the exact algorithm and total the cost
  - motivation (explicit): Scanning an array at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so both movement and arithmetic must be made cheaper.
  - relies on: fixed-tape-model, nlogn-conjecture, big-o, asymptotic-notation-beyond-big-o, logarithms-floors-and-ceilings
  - **S1** (show, page `streams`): Splitting, merging, fixed digit permutations and controlled cyclic shifts of address fields of an array of volume $V$ each cost $O(V)$ on a fixed number of tapes.
    - method: split the stream on a digit or field into aligned substreams, process them in lockstep scans, and merge them back
    - motivation (recoverable): Every later procedure moves address fields by tape scans; the reader needs to know which rearrangements are linear and which (growing-width interchanges) are not.
    - relies on: tape-basics, fixed-tape-model, lexicographic-order-and-mixed-radix-indices, two-s-complement-and-truncation

      - relies on: modular-arithmetic, division-with-remainder, primes-divisibility-and-coprimality, streams

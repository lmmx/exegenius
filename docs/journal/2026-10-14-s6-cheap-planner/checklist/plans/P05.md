# Plan P05

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A single deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ worst-case time, with $\kappa=2^{-182}$.
  - method: compute the exact product by a Gaussian-resampling convolution whose transform layers are made cheap by two tape procedures, then sum the costs of every stage
  - motivation (explicit): A plain scan of $\Theta(n)$ bits at each of $\Theta(\log n)$ levels already costs $\Theta(n\log n)$, so the savings in movement and arithmetic are needed.
  - relies on: n-log-n-conjecture, fixed-tape-model
  - **S1** (show, page `subspace-labels`): The bit network and the complex network have total edge rank $s<Wm$ with a fixed relative deficit, so that $s/W<m^{\tau}$ for both.
    - method: label the gates and terminals with nested subspaces of a fixed bilinear space, so that every edge change is an orthogonal residual, and sum the residual dimensions
    - motivation (explicit): Dimension lost on decreasing edges is the only obstruction to a total rank below $Wm$, so keeping it small gives the deficit the recursion needs.
    - relies on: frames, stream-arrays, matrices-invertibility-and-rank, vector-spaces-basis-and-dimension

    - **S1.3** (infer, page `bilinear-orthogonal`): On each edge the orthogonal residual of the smaller label inside the larger has dimension equal to the absolute change in label dimension.

# Plan P02

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): There is one deterministic fixed-alphabet, fixed-tape Turing machine multiplying $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, disproving the $n\log n$ optimality conjecture in this model.
  - method: Reduce multiplication to a convolution computed by transforms of coprime length, and obtain a power saving in the logarithmic factor from two tape procedures (fast address interchange and simultaneous butterfly layers), each built on a finite linear network with a rank saving $s<Wm$; then assemble the exact product and balance the parameters.
  - motivation (explicit): Scanning an array of $\Theta(n)$ stored bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so savings are needed in both movement and arithmetic.
  - relies on: fixed-tape-model, nlogn-conjecture, tape-machines, big-o, logarithms-and-exponentials, determinism-and-exact-versus-approximate-computation, nlogn-multiplier

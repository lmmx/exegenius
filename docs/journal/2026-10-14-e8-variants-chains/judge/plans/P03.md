# Plan P03

The plan of the argument for the main theorem, as a tree of steps.

- **R** (show, page `main-theorem`): A single deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: Reduce multiplication to convolution over $\mathbb C[y]/(y^r+1)$ through radix digits, Chinese-remainder axes, Gaussian resampling and chirps, speed up the data movement and the butterfly arithmetic with two network-based tape procedures with a strict rank saving, recover the exact product by rounding and carries, and add up the costs.
  - motivation (explicit): Scanning the whole array at each of the logarithmically many transform levels already costs $n\log n$, so both the data movement and the arithmetic need savings.
  - relies on: multiplication-algorithm, cost-analysis, nlogn-conjecture, multitape-model, established-multiplier, schoolbook-multiplication-and-karatsuba

    - motivation (explicit): After dividing cost by volume, multiplying the parameter by $m$ raises the recursive contribution by $s/W<m$, and this strict inequality is the source of the power saving.

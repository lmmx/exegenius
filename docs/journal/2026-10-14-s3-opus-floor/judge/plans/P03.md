# Plan P03

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): One deterministic Turing machine with a fixed finite alphabet and a fixed number of one-dimensional tapes outputs $\operatorname{bin}_{2n}(\operatorname{val}(x)\operatorname{val}(y))$ for all $n$-bit inputs $x,y$ in time $T_A(n)=O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$, so the $n\log n$ optimality conjecture fails in this model.
  - method: Build two network-derived tape procedures that beat one pass per transform level, use them to compute convolution over $\mathbb C[y]/(y^r+1)$ by synthetic transforms, reduce exact multiplication to that convolution through radix digits, a Chinese-remainder map, Gaussian resampling, chirps and a phase twist, then bound the error and sum the normalized costs.
  - motivation (explicit): In a transform-based multiplier, merely scanning the $\Theta(n)$ stored bits at each of $\Theta(\log n)$ transform levels costs $\Theta(n\log n)$, so going below $n\log n$ needs savings in both address movement and butterfly arithmetic; the reduction isolates exactly those two operations.
  - relies on: n-log-n-barrier, convolution, multitape-turing-machine, big-o-notation
  - **S1** (show): Two fixed-tape procedures beat one pass per level: interchanging two disjoint contiguous $u$-bit address fields of an array costs $O(Vu^{\tau})$, and a normalized butterfly $H_0$ applied simultaneously to one selected bit in each of $D\le d$ equal $K$-bit address chunks costs $O(Vd^{\lambda'})$, with fixed $\tau,\lambda'<1$.
    - method: Build fixed linear networks that exchange two banks while restoring scratch values, give each wire a frame so that every edge change is a smaller call of the same procedure, and solve the resulting volume-normalized recurrences.
    - motivation (explicit): A network whose wires carry whole arrays turns one large operation into a fixed number of smaller instances of itself, so its cost obeys a recurrence, and well-chosen frames make every edge such an instance.
    - relies on: multitape-turing-machine, tape-address-model, fft-butterflies
    - **S1.1** (infer, page `tape-address-model`): On an array of logical volume $V$ stored in lexicographic order, a fixed permutation of the digits at two radix-$q$ positions, moving one digit, splitting on a digit to apply a fixed pointwise map and merging back, and cyclically splitting whole rows into a fixed number of streams (and merging them) each cost $O(V)$ steps.
      - relies on: multitape-turing-machine, multidimensional-arrays-and-row-major-order, positional-notation-in-any-radix, big-o-notation
      - quotes line 493: "Each of the following operations on an array of volume $V$ takes $O(V)$ steps on a fixed number of one-dimensional tapes:"
    - **S1.2** (infer, page `controlled-cyclic-shift`): If a target field $y\in[Q]$, $Q=q^b$, follows its control fields, the update $y\mapsto y+a(\text{controls})\bmod Q$ costs $O(V)$ whenever the offset is computable in $b^{O(1)}$ time, by splitting each fiber's $Q$ blocks at $Q-a$ and merging the two pieces in the opposite order; multiplying $y$ by a fixed rational unit also costs $O(V)$.
      - relies on: tape-address-model, modular-arithmetic, cyclic-shifts-and-rotations-of-lists
      - quotes line 566: "costs $O(V)$ if the offset can be prepared in $b^{O(1)}$ time from the fixed number of control values."
    - **S1.3** (show, page `rank-saving-recurrence`): Two fixed linear networks with $W$ wires each exchange two banks of $N$ values while restoring every scratch value, and their frame changes need in total only $s<Wm$ smaller calls on role streams of volume $V/W$, indeed $s/W<m^{\tau}$ with $\tau=1-2^{-50}$; so when the recursion parameter is multiplied by $m$ the volume-normalized cost is multiplied by less than $m^{\tau}$, a power saving.
      - method: Label every vertex of each network by a subspace of an $m$-dimensional space, count the dimension changes along edges, convert them into rational ranks (bit network) or orthonormal residual bases (complex network), and compare the total with $Wm$.
      - motivation (explicit): A recursion that replaces one call at parameter $mf$ by $s$ calls at parameter $f$, each on volume $V/W$, multiplies the normalized cost by $s/W$ per factor $m$; only a strict deficit $s<Wm$ makes this factor $m^{\tau}$ with $\tau<1$, so the exact count of edge ranks decides whether any saving exists.

      - **S1.3.1** (show, page `scratch-restoring-exchange`): For arbitrary initial scratch values, a forward invocation of the eight-row schedule (copy, gather, scatter, side injection and their undoings) effects $y\gets y+x$, and a forward, an inverse and a forward stage send $(X_a,Y_a)\mapsto(-Y_a,X_a)$ while restoring every auxiliary wire; over $\mathbb F_2$ this is the bank exchange.
        - method: Track the old scratch vectors through the schedule, compute the net coefficient from each $x_T$ to $y_S$ from the size of $S\cap T$, and compose the three stages.
        - motivation (explicit): The schedule first cancels the effect of the unknown scratch contents and finally restores them, so the net effect is a fixed linear map that can be computed as if the scratch were zero; only its coefficients, which depend on triple intersections, remain to be checked.

        - **S1.3.1.3** (infer): In the complex construction the central coefficient is $(|S\cap T|-1)/2$; the side wires cancel it for distinct triples meeting in $0$ or $2$ points, intersection one contributes $0$, and the self coefficient is $(3-1)/2=1$, so again $y\gets y+x$.

      - **S1.3.7** (show, page `address-shear-factorization`): For a fixed rational $m\times m$ matrix $A$ of rank $a$ and two groups of $m$ fields over $\mathbb Z/q^b\mathbb Z$ ($q$ a fixed odd prime avoiding all denominators), with every $H_i$ before every $D_j$, the shear $(H,D)\mapsto(H+AD,D)$ costs exactly $a$ interchanges of $b$-digit field pairs plus $O(V)$ work, so each edge of the bit network costs as many smaller interchanges as its rank.

        - motivation (explicit): Controlled shifts are linear-time only when the target field follows its controls, which is exactly what a lower-triangular change of coordinates needs; the factorization pushes all non-triangular work into the $a$ ones of $\Pi$.

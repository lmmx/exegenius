# Plan P13

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A fixed deterministic multitape Turing machine multiplies $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: reduce the product to convolution over a polynomial ring, speed up its transforms with two tape procedures having a recursive power saving, then recover the exact product by rounding
  - motivation (explicit): Plain transforms cost n log n by scanning n bits at each of log n levels, so the logarithmic factor itself must shrink; this needs a faster tape procedure for data movement and arithmetic, plus a reduction placing multiplication where those procedures apply.
  - relies on: nlogn-conjecture, big-o, multitape-tm, dft-convolution, logarithms-and-floor-ceiling
  - **S1** (infer, page `radix-digit-convolution`, reported out of order): Splitting the inputs into radix digits reduces multiplication to convolution of short integer coefficients.
    - relies on: dft-convolution, binary-representation-of-integers, schoolbook-multiplication-and-basic-divide-and-conquer
    - quotes line 76: "Splitting the inputs into radix digits reduces multiplication to"
  - **S4** (show): The address rearrangements and butterfly layers of the synthetic transforms cost $O(Vu^\tau)$ and $O(Vd^{\lambda'})$ for stored bit volume $V$, a power saving below the linear-per-level cost.
    - method: build each procedure from a fixed linear network whose smaller calls number $s<Wm$ and recurse
    - motivation (explicit): Each procedure is a fixed network whose edges are smaller calls of the same procedure; a rank saving s<Wm makes the recursion beat linear cost per level, so the networks, their saving and the two instances are shown in that order.
    - **S4.1** (infer, page `tape-streams`): Elementary scans, controlled shifts and fixed scalings on tape streams each cost linear time in the stored volume $V$.
      - relies on: multitape-tm, tensor-kronecker-product-and-multidimensional-arrays
      - quotes line 443: "the elementary scans it uses."
    - **S4.2** (infer, page `gate-frames`): A fixed linear network exchanging banks of values, with an invertible frame per gate, restores all auxiliary values and leaves only the endpoint operator on every role array.
      - relies on: vectors-matrices-and-linear-maps, tape-streams
      - quotes line 646: "pointwise without disturbing the representation."
    - **S4.3** (infer, page `finite-network-subspaces`): Networks built from three-element subsets with nested subspaces of an $m$-dimensional space need only $s<Wm$ smaller calls.
      - relies on: gate-frames

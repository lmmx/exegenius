# Plan P19

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): Show that $n$-bit integers can be multiplied exactly on a fixed deterministic multitape Turing machine in $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$.
  - method: reduce multiplication to convolution over a negacyclic ring, compute it with synthetic transforms whose address movement and butterflies are accelerated by two linear-network tape procedures, then recover the exact product
  - motivation (explicit): Scanning an array at each of the log n transform levels costs n log n already, so a power saving needs savings in both data movement and arithmetic.
  - relies on: multiplication-history, big-o, multitape-turing-machine, convolution-dft
  - **S1** (infer, page `tape-streams`): Arrays are stored in address order on tape and elementary scans, pointwise operations and field updates take linear time.
    - relies on: multitape-turing-machine, finite-state-machine-and-constant-size-alphabet
    - quotes line 449: "An array with address set $[a_1]\times\cdots\times[a_t]$ is stored in"
  - **S2** (show, page `fast-address-interchange`): Interchange two disjoint contiguous $u$-bit address fields of an array of volume $V$ in time $O(Vu^\tau)$ for a fixed $\tau<1$.
    - method: run the bank-exchange linear network on the arrays, with frames chosen so each edge is a smaller interchange, and recurse
    - motivation (recoverable): Scanning the array at each of the log n levels already costs n log n, so a power saving needs a cheaper way to rearrange addresses; XOR combinations through a linear network turn the exchange into smaller exchanges whose total count is below the naive count.
    - relies on: tape-streams
    - **S2.1** (infer, page `bank-exchange-network`): A fixed linear network of gates on role wires swaps two banks of values with signs and restores every auxiliary value.
      - relies on: tape-streams
      - quotes line 643: "We construct two fixed linear networks that exchange two banks of values"
    - **S2.2** (infer, page `frames`): Choosing a frame $D_v$ at each vertex lets gates act pointwise on whole arrays, and intermediate frames cancel so only an endpoint operator remains.
      - relies on: matrices-and-linear-maps, bank-exchange-network
      - quotes line 793: "At each source, gate and sink $v$, assign an invertible $R$-linear operator"
    - **S2.3** (infer, page `subset-intersection-labels`): Three-element subset gather/scatter with intersection-count coefficients, plus side wires, yields nested subspace labels whose total rank deficit $s$ is less than $Wm$.
      - relies on: rank-subspaces-and-orthogonal-complements, binomial-coefficients-and-counting, frames
      - quotes line 853: "The saving will come from keeping the total dimension lost on decreasing"
    - **S2.4** (infer, page `recursive-power-saving`): Edge operators of rank $a$ need $a$ smaller interchanges; since $s<Wm$, the recursion saves a power of the chunk width.
      - relies on: recurrences-and-recursion-analysis, subset-intersection-labels
      - quotes line 1352: "Because the sum of these ranks is less than the number of wires times"
    - **S2.5** (infer, page `address-shear`): Updating fields $(H,D)\mapsto(H+D,D)$ over a residue ring and factoring matrices into triangular pieces can be done in tape order.
      - relies on: triangular-and-permutation-matrices, gaussian-elimination, tape-streams, modular-arithmetic-and-congruences
      - quotes line 1360: "is the Bruhat factorization for arbitrary matrices, with coordinate order"
    - **S2.6** (infer): Two disjoint $u$-bit address fields of an array of volume $V$ are interchanged exactly, for arbitrary auxiliary values, in $O(Vu^\tau)$ with $\tau<1$ fixed.
      - relies on: address-shear, recursive-power-saving
      - quotes line 1633: "There exist fixed $0<\tau<1$ and one fixed finite-alphabet multitape"
  - **S3** (show, page `simultaneous-butterfly-layers`): Apply $H_0(u,v)=((u+v)/2,(u-v)/2)$ on the same selected bit in each of $d$ address chunks of an array of volume $V$ in time $O(Vd^{\lambda'})$, $\lambda'<1$.
    - method: reuse the recursive-saving network with phase frames, moving whole address chunks by fast interchange, and bound the exact dyadic values before one truncation
    - motivation (explicit): Separate butterfly factors would need D whole-array passes; the same rank-saving network that speeds address interchange applies to the numerical layer.
    - relies on: bank-exchange-network, frames, subset-intersection-labels, recursive-power-saving, fast-address-interchange, fixed-point-gaussian-dyadics
    - **S3.1** (infer, page `fixed-point-gaussian-dyadics`): Records are polynomials with fixed-point Gaussian dyadic coefficients in the unit disk; intermediate values are exact and a single truncation follows the contractive layer.
      - relies on: gaussian-integers, dyadic-rationals, complex-modulus-and-norms
      - quotes line 1775: "coefficients, initially in the unit disk on the grid"
    - **S3.2** (infer): Using phase frames and the complex network, the normalized layer $H_0$ on the same selected bit in each of $d$ address chunks is applied to volume $V$ in $O(Vd^{\lambda'})$ with $\lambda'<1$.
      - relies on: recursive-power-saving, frames, fast-address-interchange, fixed-point-gaussian-dyadics
      - quotes line 2588: "\begin{proposition}[Simultaneous normalized butterfly layer]"
  - **S4** (show, page `synthetic-transforms`): Compute the normalized Fourier transforms needed for convolution as synthetic polynomial transforms over $\mathcal R_r$ at cost accelerated by the two tape procedures.
    - method: use Nussbaumer-style polynomial transforms, so all work is shifts, rearrangement and butterflies, which the two procedures speed up
    - motivation (explicit): Roots of unity that are powers of y make multiplications by roots free of arithmetic, leaving exactly the two operations (movement and butterflies) that the tape procedures accelerate.
    - relies on: negacyclic-ring, fast-fourier-transform-divide-and-conquer-idea, fast-address-interchange

  - **S5** (show, page `normalized-polynomial-products`): Multiply ring elements pointwise exactly and obtain normalized convolution over $\mathcal R_r$.
    - method: pack ring elements into integers and call the O(n log n) multiplier on small inputs
    - motivation (recoverable): The pointwise products are on short records of O(rp) bits, so the log-factor cost of the established multiplier is paid only on small inputs and does not recurse.
    - relies on: synthetic-transforms, convolution-dft, negacyclic-ring

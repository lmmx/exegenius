# Plan P02

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): Integer multiplication of $n$-bit integers takes $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$ on one fixed multitape machine.
  - method: reduce to digit convolution, build the fast tape and ring-transform tools bottom up, then assemble reductions, precision and cost
  - motivation (explicit): The fast address and butterfly procedures give the savings; the reductions place them inside multiplication.
  - relies on: multitape-model, nlogn-conjecture, convolution-reduction, big-o, deterministic-computation-and-time-complexity-classes, fast-fourier-transform-algorithm
  - **S1** (infer, page `convolution-reduction`): Splitting the $n$-bit inputs into radix digits reduces integer multiplication to convolution of short integer coefficient lists, with carries propagated afterwards.
    - relies on: big-o, binary-representation-and-bit-operations, convolution, schoolbook-and-karatsuba-multiplication, polynomials
    - quotes line 76: "Splitting the inputs into radix digits reduces multiplication to"
  - **S2** (show): The two tape procedures, fast address interchange and simultaneous butterfly layers, exist with power savings.
    - method: construct each procedure from its own fixed linear network, after the elementary scans
    - motivation (explicit): Scanning the array at each transform level already costs $n\log n$, so both movement and arithmetic need savings.
    - **S2.1** (infer, page `controlled-shifts`): Elementary scans and controlled shifts (updating a field by an offset from earlier control fields) take $O(V)$ steps on a fixed number of tapes.

      - motivation (explicit): Scanning $\Theta(n)$ bits at each of $\Theta(\log n)$ levels costs $n\log n$; a recurrence whose calls total fewer than the width times the parameter gains a power.
      - relies on: multitape-model, controlled-shifts, permutations, big-o

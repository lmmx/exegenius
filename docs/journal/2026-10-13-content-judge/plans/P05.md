# Plan P05

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `fast-multiplication`): Integer multiplication of $n$-bit integers takes $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$ on a fixed multitape Turing machine.
  - method: reduce to digit convolution, supply two fast tape procedures, chain reductions, then total the cost
  - motivation (recoverable): The known O(n log n) algorithm already spends a log factor on transform levels, so beating it needs a cheaper transform in movement and arithmetic, placed inside the standard convolution reduction.
  - relies on: multitape-model, known-nlogn, big-o, turing-tapes, convolution-dft
  - **S1** (infer, page `radix-digit-reduction`): Splitting inputs into radix digits reduces multiplication to convolution of short integer coefficients.

    - quotes line 76: "Splitting the inputs into radix digits reduces multiplication to"
  - **S2** (show): Two tape procedures, a fast address interchange and fast simultaneous butterfly layers, save over one scan per transform level.
    - method: give two tape procedures, each from a linear network with recursive saving
    - motivation (explicit): Scanning the array at each of the log n levels already costs n log n, so savings are needed in both data movement and arithmetic.
    - **S2.1** (infer, page `address-interchange`): Two disjoint address fields of $u$ bits can be interchanged at cost $O(Vu^\tau)$ with $\tau<1$.

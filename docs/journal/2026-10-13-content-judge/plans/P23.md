# Plan P23

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A deterministic fixed-tape Turing machine multiplies $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, disproving the $n\log n$ optimality conjecture in this model.
  - method: reduce multiplication to a ring convolution whose transforms are accelerated by two fast tape procedures, then account for the cost
  - motivation (explicit): Scanning $\Theta(n)$ bits at each of $\Theta(\log n)$ transform levels costs $\Theta(n\log n)$, so beating it needs savings in both data movement and arithmetic.
  - relies on: big-o, turing-tapes, exponentials-logarithms-and-iterated-logarithm-bounds
  - **S0.1** (infer, page `nlogn-conjecture`): Schönhage and Strassen gave $O(n\log n\log\log n)$ and proposed $n\log n$ as optimal; Harvey and van der Hoeven reached $O(n\log n)$.
    - relies on: big-o
    - quotes line 39: "Sch\"onhage and Strassen proved in 1971 that two $n$-bit integers can"
  - **S0.2** (infer, page `fixed-tape-model`, reported out of order): The machine model has one fixed finite alphabet and a fixed finite number of one-dimensional tapes; moving one digit in a fixed radix takes a bounded number of scans, but interchanging fields with growing numbers of digits does not.
    - relies on: turing-tapes, big-o
    - quotes line 494: "takes $O(V)$ steps on a fixed number of one-dimensional tapes:"
  - **S1** (show): Two tape procedures, fast address interchange and simultaneous fast butterfly layers, cut the cost of address rearrangement and of transform layers by a power of the logarithm.
    - method: derive both from a fixed linear network with a strict deficit in the number of smaller calls and recurse
    - motivation (explicit): A power saving needs a recursion whose subcalls cost slightly less in total than the work they replace; the network provides exactly this strict deficit.
    - relies on: fixed-tape-model
    - **S1.1** (infer, page `linear-network-frames`): A fixed linear network exchanges two banks of values with signs, frames $D_v$ change representation along edges so that intermediate frames cancel, and auxiliary values are restored.
      - relies on: linear-algebra-over-the-rationals, matrix-and-block-notation
      - quotes line 793: "assign an invertible $R$-linear operator"
    - **S1.3** (infer, page `subset-network`): A finite network with nested subspaces of an $m$-dimensional space attached to its gates, built from three-element subset intersection counts, has total number $s$ of smaller calls with $s<Wm$.
      - relies on: linear-network-frames, binomial-coefficients-and-basic-counting, linear-algebra-over-the-rationals
      - quotes line 1152: "=177176569088785861287000000<W_{\rm b}m."
    - **S1.4** (infer, page `recursive-saving`): Applying the network at parameter $mf$ uses $s$ calls at parameter $f$ on streams of volume $V/W$, and $s<Wm$ makes the cost per unit volume grow like a power of the parameter below 1.
      - relies on: subset-network, linear-network-frames, recurrences-and-divide-and-conquer
      - quotes line 1343: "\qquad 0<\tau=\sigma<1."
    - **S1.2** (infer, page `address-shear`): For the bit procedure the endpoint operator is the address shear $(H,D)\mapsto(H+D,D)$ over a residue ring, implemented through lower-triangular factorization.
      - relies on: linear-network-frames, gaussian-elimination-and-the-general-linear-group-over-f2, modular-arithmetic, linear-algebra-over-the-rationals

    - **S1.5** (infer, page `fast-address-interchange`): Two disjoint contiguous address fields of $u$ bits in an array with a complete Cartesian product of addresses can be interchanged in time $O(Vu^{\tau})$ for a fixed $\tau<1$, ending as an exact permutation.
      - relies on: address-shear, recursive-saving, fixed-tape-model, bitwise-xor

      - motivation (recoverable): The numerical layer arises from the same kind of fixed network as the address interchange, so the same strict saving applies once phase frames and exact dyadic arithmetic keep every edge a smaller call of the same procedure.

  - **S2** (show, page `multiplication-algorithm`): The product of two $n$-bit integers is computed exactly by the pipeline: digits to prime axes, resampling and chirps to power-of-two axes, phase twist to the ring, synthetic-transform convolution, then exact recovery.

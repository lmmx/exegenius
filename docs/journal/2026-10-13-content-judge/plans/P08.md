# Plan P08

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A single deterministic Turing machine with a fixed alphabet and a fixed number of one-dimensional tapes multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ worst-case time with $\kappa=2^{-182}$, refuting the $n\log n$ optimality conjecture in this model.
  - method: Convert the product into a convolution computed by synthetic transforms after Gaussian resampling and a chirp, speed up the transforms with two network-based tape procedures (address interchange and simultaneous butterfly layers), then prove the product exact and add up the time.
  - motivation (explicit): Scanning the stored bits at each of the logarithmically many transform levels already costs order $n\log n$, so savings in both movement and arithmetic are needed, and the two tape procedures supply them.

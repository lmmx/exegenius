# Plan P07

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): There is a deterministic fixed multitape Turing machine multiplying $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: build two fast tape procedures, use them for synthetic and resampled transforms, and assemble the exact product through convolution
  - motivation (recoverable): The Schoenhage-Strassen style product is a convolution, and fast transforms cost n log n only because of movement and butterflies, so power savings on those two operations give a power saving overall.
  - relies on: multitape-model, nlogn-conjecture, big-o, logarithms-and-exponentials
  - **S1** (show): Two tape procedures, an address interchange of cost $O(Vu^\tau)$ and a simultaneous butterfly layer of cost $O(Vd^{\lambda'})$, exist for volume $V$ with fixed $\tau,\lambda'<1$.
    - method: build both from fixed linear networks with a rank saving, applied recursively
    - motivation (reconstructed): Scanning the whole array at each of the log n transform levels already costs n log n, so movement and arithmetic must both be made cheaper than a scan per level; a recursion whose normalized cost grows by a factor below the parameter gives a power saving.
    - **S1.1** (infer, page `stream-operations`): Arrays are stored in address order and elementary scans, controlled shifts and affine updates take linear time.
      - relies on: multitape-model
      - quotes line 491: "\begin{lemma}[Elementary stream operations]"
    - **S1.2** (infer, page `linear-network-frames`): A fixed linear network with roles can be applied to arrays by giving each wire an invertible frame so intermediate frames cancel and only an endpoint operator remains.
      - relies on: stream-operations
      - quotes line 793: "assign an invertible $R$-linear operator"
    - **S1.3** (infer, page `subset-intersection-labels`): Nested subspace labels from three-element subsets give a network whose total edge rank $s$ is less than $Wm$.
      - relies on: linear-network-frames
      - quotes line 853: "The saving will come from keeping the total dimension lost on decreasing"
    - **S1.4** (infer, page `recursive-saving`): A call at parameter $mf$ uses $s<Wm$ calls at parameter $f$ on volume $V/W$, giving cost $V\cdot(\text{parameter})^{\tau}$ with $\tau<1$.
      - relies on: subset-intersection-labels
      - quotes line 1326: "For both recurrences we may use the fixed rational exponent"
    - **S1.5** (show, page `fast-address-interchange`): Two address fields of $u$ bits can be interchanged at cost $O(Vu^\tau)$.
      - method: express each edge matrix of the network by shears, factor them, and recurse on smaller interchanges
      - motivation (recoverable): An edge matrix of rank a requires only a smaller interchanges once it is factored, so the rank saving of the network turns into a recurrence saving a power of the chunk width.
      - relies on: recursive-saving, stream-operations
      - **S1.5.1** (infer, page `lower-triangular-factorization`): Every rational matrix of rank $a$ factors as $E_1\Pi E_2$ with lower triangular $E_i$ so a shear costs $a$ interchanges plus linear-time updates.
        - relies on: linear-algebra-basics, stream-operations
        - quotes line 1364: "\begin{lemma}[Lower triangular factorization]"
      - **S1.5.2** (infer): Chunks of power-of-two width can be interchanged, with rows, in time $O(Vu^\tau)$.
        - quotes line 1475: "\begin{proposition}[Power-width interchange with rows]"
      - **S1.5.3** (infer): The restrictions on width and rows are removed for arbitrary chunk width.
        - quotes line 1631: "\begin{lemma}[Arbitrary-width interchange]"
    - **S1.6** (infer, page `simultaneous-butterfly-layer`): A butterfly layer $H_0$ on the same bit of up to $d$ address chunks at once costs $O(Vd^{\lambda'})$ on records of complex fixed-point polynomials.
      - relies on: fast-address-interchange, recursive-saving, butterfly-h0
      - quotes line 2588: "\begin{proposition}[Simultaneous normalized butterfly layer]"
  - **S2** (show, page `synthetic-transform`): Normalized synthetic transforms over $\mathbb C[y]/(y^r+1)$ can be computed and inverted with the frequency order retained, using the parallel layers.
    - method: use powers of $y$ as roots of unity and compute with radix-two butterflies on a layout fitting the parallel layers
    - motivation (recoverable): Multiplication by a root of unity becomes a signed shift, so only butterflies cost arithmetic, and those are exactly what the simultaneous layer accelerates.
    - relies on: polynomial-ring, butterfly-h0
    - **S2.1** (infer): Sums of powers of the synthetic roots of unity cancel, so the transform and its opposite invert each other up to a scale.
      - quotes line 2810: "\begin{lemma}[Synthetic character cancellation]"
    - **S2.2** (infer): A layout places the selected bits in common chunks so each round is one parallel layer, with total transform cost within the budget.
      - quotes line 2929: "\begin{lemma}[Transform layout and cost]"
  - **S3** (show, page `ring-convolution`): Cyclic convolution over the polynomial ring is computed exactly from forward transforms, pointwise ring products and the opposite transform.
    - method: transform both operands, multiply pointwise with signed packing and invert in the same frequency order
    - motivation (recoverable): Pointwise products correspond to convolution after a DFT-style transform, and ring products are short enough to be given to an ordinary integer multiplier.
    - relies on: synthetic-transform, dft-convolution
    - **S3.1** (infer, page `signed-packing`): Ring polynomials with negative integer coefficients are multiplied exactly by Kronecker packing and one call of the integer multiplier.
      - relies on: hvdh-multiplier, polynomial-ring
      - quotes line 3221: "\begin{lemma}[Signed packing and normalized ring multiplication]"
    - **S3.2** (infer): The normalized convolution has an approximation with small error computed from the retained transform layout.
      - quotes line 3391: "\begin{proposition}[Convolution from the retained transform layout]"
  - **S4** (show, page `resampling-keep-permutations`): Fourier transforms of pairwise coprime lengths reduce to power-of-two transforms without executing the resampling permutations.
    - method: keep the source and target permutations inside the transform identity so they cancel
    - motivation (explicit): Gaussian resampling normally sorts twice on each coordinate, which is too costly, so the permutations are left in the formula and cancel between forward and inverse transforms.
    - relies on: gaussian-resampling, bluestein, dft-convolution
    - **S4.1** (infer): One-dimensional resampling maps give the transform without executing the two permutations.
      - quotes line 3548: "\begin{lemma}[Resampling without executing the two permutations]"
    - **S4.2** (infer): The one-dimensional maps combine into a tensor interface for growing dimension.
      - quotes line 3800: "\begin{lemma}[Tensor interface]"
    - **S4.3** (infer): A chirp identity computes the middle transform and the retained source permutation cancels in a convolution.
      - quotes line 3911: "\begin{lemma}[Chirp and permutation cancellation]"
  - **S5** (show, page `multiplication-algorithm`): The full algorithm turns the integer product into digit convolution, runs the transforms, and recovers the exact product in $O(n(\lg n)^{1-\kappa})$ time.
    - method: digits, then CRT address map, transforms and pointwise product, then rescale, round and carry, with error and cost accounting
    - motivation (recoverable): Each reduction maps one convolution problem to the next, and the exact product is recovered only after bounding the final coefficient error below 1/2.
    - relies on: ring-convolution, resampling-keep-permutations, synthetic-transform, parameter-choice
    - **S5.1** (infer, page `parameter-choice`): Rational parameters $\tau,\lambda,\lambda',\epsilon,\delta,\kappa=2^{-182}$ are chosen compatibly.
      - relies on: recursive-saving, simultaneous-butterfly-layer
      - quotes line 4016: "These constants are deliberately conservative; no optimization is claimed."
    - **S5.2** (infer, page `radix-digit-reduction`): Splitting the operands into radix-$2^b$ digits makes the product a convolution with no wraparound.
      - relies on: binary-representation-and-radix-expansion, schoolbook-multiplication-and-carries
      - quotes line 4183: "Write the two inputs as polynomials in $2^b$, each with"
    - **S5.3** (infer, page `cyclic-crt`): A Chinese-remainder address map places the digit list on distinct prime cyclic axes preserving convolution.
      - relies on: prime-numbers-and-coprimality, modular-arithmetic, cartesian-product-and-mixed-radix-indexing
      - quotes line 4195: "\subsection{An explicit cyclic-convolution layout}"
    - **S5.4** (infer, page `coefficient-twist`): Multiplying coefficient $k$ by $\zeta^k$ turns cyclic convolution into multiplication modulo $y^r+1$.
      - relies on: polynomial-ring
      - quotes line 4298: "\subsection{Complex convolution by a coefficient twist}"
    - **S5.5** (infer): The algorithm applies the address map, two forward transforms, a pointwise product, the inverse transform, scaling, rounding and carries.
      - quotes line 4506: "With these streams prepared, perform the following operations."
    - **S5.6** (infer, page `fixed-point-precision`): The recovered coefficient error is strictly below $1/2$ with truncation errors tracked through contractions.
      - relies on: fixed-point-and-rounding-arithmetic, euclidean-norm-and-unit-disk
      - quotes line 4546: "\subsection{Precision and exact recovery}"

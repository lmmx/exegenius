# Plan P09

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A deterministic fixed-tape machine multiplies $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: reduce multiplication to ring convolution evaluated by fast synthetic transforms, built from two power-saving tape procedures, then recover the exact product and total the cost
  - motivation (recoverable): The conjectured n log n comes from n bits times log n transform levels; a power saving in the log factor needs cheaper layers and cheaper data movement, then an exact reduction from multiplication to those layers.
  - relies on: schonhage-strassen-conjecture, hvdh-multiplier, big-o, binary-integers
  - **S1** (infer, page `fixed-tape-model`): The model: one fixed finite alphabet and finitely many one-dimensional tapes, where time counts steps and moving growing fields costs scans.
    - relies on: tm-basics, fixed-finite-alphabet-and-worst-case-time, sorting-and-sequential-scans-on-tapes
    - quotes line 435: "A machine has one fixed finite alphabet and one fixed finite number of"
  - **S2a** (show): Two tape procedures save a power of the logarithm: fast address interchange costs $O(Vu^\tau)$ and simultaneous butterfly layers cost $O(Vd^{\lambda'})$, with $\tau,\lambda'<1$.
    - method: derive both from linear networks with a recursive rank saving
    - motivation (explicit): Scanning the whole array at each of log n transform levels costs n log n, so movement and arithmetic must both be accelerated.
    - relies on: fixed-tape-model
    - **S2** (show, page `recursive-power-saving`): A recursive linear network gives a power saving: with $W$ roles, $m$-fold parameter growth and $s$ smaller calls, $s<Wm$ makes the recursion cost per unit volume $V$ grow like a power below $m$ per factor.
      - method: construct a fixed linear network with a rank saving and recurse on it
      - motivation (recoverable): Scanning at every transform level already costs n log n, so a saving must come from a recursion whose branching is strictly below the volume split.
      - relies on: recurrences-and-recursion-cost-analysis
      - **S2.1** (infer, page `linear-network`): A fixed linear network exchanging two banks of values while restoring auxiliary values lets arrays on wires carry invertible frames that cancel along routes, leaving an endpoint operator on each of $W$ role arrays of volume $V/W$.
        - relies on: linear-maps-and-matrices, fixed-point-contraction
        - quotes line 643: "We construct two fixed linear networks that exchange two banks of values"
      - **S2.2** (infer, page `subset-network`): Nested subspaces attached to gates by three-element subsets, with auxiliary wires cancelling unwanted intersection coefficients, give a network whose total number $s$ of smaller calls satisfies $s<Wm$.
        - relies on: subsets-binomial-counts-and-combinatorial-counting, subspaces-bases-and-dimension, inner-product-and-orthogonality, linear-network
        - quotes line 658: "Let $\mathcal T$ be the set of three-element subsets of $[h]$."
      - **S2.3** (infer): Recursing at parameter $mf$ with $s$ calls at parameter $f$ on streams of volume $V/W$ makes cost per volume grow by $s/W<m$ per factor $m$, a power saving.
        - quotes line 1353: "$m$, the resulting recurrence saves a power of the chunk width."
    - **S3** (show, page `address-interchange`): Address chunks of $u$ digits are interchanged in $O(Vu^\tau)$ time for some $\tau<1$.
      - method: apply the bit network to address shears, factored into triangular scans, and recurse
      - motivation (recoverable): The bit network turns an interchange into shears of address fields, whose triangular factorization needs only ordered scans, with recursion giving the power saving.
      - relies on: recursive-power-saving, linear-network, subset-network, finite-field-f-2-and-xor, bit-operations-and-address-fields, permutations
      - **S3.1** (infer, page `matrix-shear`): A rational matrix factors as $E_1\Pi E_2$ with lower triangular $E_1,E_2$, so a shear of address fields is done by ordered scans.
        - relies on: triangular-matrices-and-permutation-matrices, linear-independence-and-rank, sorting-and-sequential-scans-on-tapes
        - quotes line 1366: "Every rational $m\times m$ matrix $A$ of rank $a$ has a factorization"
      - **S3.2** (infer): Two disjoint address chunks of $u$ digits can be interchanged on volume $V$ in time $O(Vu^\tau)$ with a fixed $\tau<1$.

    - **S4** (infer, page `simultaneous-butterfly-layer`): Applying $H_0(u,v)=((u+v)/2,(u-v)/2)$ on one bit in each of up to $d$ address chunks at once costs $O(Vd^{\lambda'})$ with $\lambda'<1$, using the complex network and phase frames.
      - relies on: recursive-power-saving, linear-network, subset-network, address-interchange, fixed-point-contraction, poly-ring, fft-butterfly, dft
      - quotes line 2588: "\begin{proposition}[Simultaneous normalized butterfly layer]"
  - **S5** (show, page `ring-convolution`): Normalized convolution over the ring modulo $y^r+1$ on the remaining axes is computed accurately within the target cost.
    - method: two forward synthetic transforms in retained layout, pointwise products via signed packing, opposite transform
    - motivation (recoverable): Over the ring modulo y^r+1, roots of unity are signed shifts and polynomial products reduce to integer products handled by the known n log n multiplier on short inputs.
    - relies on: convolution, kronecker-packing, hvdh-multiplier, fixed-point-contraction, poly-ring

    - motivation (explicit): Resampling usually sorts twice on each coordinate, which would cost full scans; keeping both permutations in the formula lets them cancel.
    - relies on: bluestein-chirp, ring-convolution, dft, permutations

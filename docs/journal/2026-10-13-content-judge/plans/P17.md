# Plan P17

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A deterministic multitape Turing machine multiplies $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: reduce multiplication to convolution, accelerate the tape procedures by a power saving, then chain the reductions to an exact product
  - motivation (recoverable): The cost n log n comes from Theta(log n) transform levels each costing a scan; a power saving in movement and arithmetic per level lowers the log factor to a power below 1.
  - relies on: nlogn-conjecture, big-o, logarithms-and-iterated-logarithms
  - **S0.0** (infer, page `nlogn-conjecture`): The theorem refutes an eventual $\Omega(n\log n)$ lower bound for every fixed multiplication machine.
    - relies on: little-o-omega-and-liminf-asymptotics, turing-machine-tapes
    - quotes line 71: "eventual $\Omega(n\log n)$ lower bound for every fixed multiplication"
  - **S1** (infer, page `convolution-dft`): Splitting inputs into radix digits reduces multiplication to convolution of short integer coefficients, computed by Fourier transforms.
    - relies on: convolution-of-sequences, fast-fourier-transform, integer-multiplication-algorithms
    - quotes line 77: "convolution of short integer coefficients."
  - **S2** (show): Two tape procedures save both movement and arithmetic: address interchange at cost $O(Vu^\tau)$ and simultaneous butterfly layers at cost $O(Vd^{\lambda'})$, with $\tau,\lambda'<1$.
    - method: supply two tape procedures, each from its own linear network with a recursive power saving
    - motivation (explicit): Scanning Theta(n) bits at each of Theta(log n) levels costs Theta(n log n), so transform levels and rearrangements must each be done for less.
    - **S2.1** (infer, page `tape-scans`): Scanning $\Theta(n)$ bits at each of $\Theta(\log n)$ levels already costs $\Theta(n\log n)$, so movement must be saved.

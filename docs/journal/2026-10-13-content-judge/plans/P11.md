# Plan P11

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A deterministic multitape Turing machine multiplies $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: Reduce the product to a convolution over the polynomial ring through a chain of representation changes, and make the transforms there cheap with two fast tape procedures that save a power of the logarithmic factor.
  - motivation (explicit): Plain transform layers cost a scan of the data at each of the log n levels, giving n log n; so both address movement and butterfly arithmetic must be made cheaper than a scan per level, and the reductions must route all transforms through those cheaper layers.
  - relies on: nlogn-conjecture, multitape-turing-machine, big-o, logarithms-and-iterated-logarithms
  - **S1** (infer, page `radix-digit-convolution`): Splitting the inputs into radix digits reduces the product to a convolution of short integer coefficients, and carries then give the exact product.
    - relies on: convolution, positional-radix-notation, binary-representation-of-integers
    - quotes line 76: "Splitting the inputs into radix digits reduces multiplication to"
  - **S2** (show): Two tape procedures cost less than a scan per level: interchanging address fields and applying butterfly layers both save a power.
    - method: State the two procedures with their costs, each obtained from its own fixed linear network.
    - motivation (explicit): Scanning the data once per transform level costs n log n, so address rearrangement and arithmetic layers must each be done in less than one scan per level.
    - **S2.1** (infer, page `address-interchange`): Two disjoint address fields of $u$ bits in a Cartesian-product array are interchanged at cost $O(Vu^\tau)$ for a fixed $\tau<1$.
      - relies on: tape-arrays-and-streams, controlled-shifts, address-shear, bitwise-operations-and-xor, cartesian-products-and-multidimensional-arrays
      - quotes line 97: "Its cost is $O(Vu^\tau)$ for a fixed $\tau<1$."
    - **S2.2** (infer, page `butterfly-layer`): The map $H_0(u,v)=((u+v)/2,(u-v)/2)$ is applied on one bit position in each of $d$ address chunks at cost $O(Vd^{\lambda'})$ for a fixed $\lambda'<1$.
      - relies on: dft, ring-mod-yr, complex-numbers, dyadic-rationals-and-fixed-point-numbers, address-interchange

    - **S3.2** (infer, page `address-shear`): For the bit procedure the endpoint operator is the address shear $(H,D)\mapsto(H+D,D)$, cheap by lower-triangular factorization.
      - relies on: linear-networks-frames, controlled-shifts, tape-arrays-and-streams, triangular-matrices-and-gaussian-elimination
      - quotes line 152: "updated by $(H,D)\mapsto(H+D,D)$."
    - **S3.3** (infer, page `finite-subset-network`): A fixed network from three-element subsets with nested subspaces has total number of smaller calls $s<Wm$.

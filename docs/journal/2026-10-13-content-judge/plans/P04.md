# Plan P04

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-result`): A fixed deterministic multitape Turing machine multiplies two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: build two fast tape procedures, use them in synthetic transforms for ring convolution, then chain the reductions from integer multiplication
  - motivation (explicit): Scanning $\Theta(n)$ bits at each of $\Theta(\log n)$ transform levels costs $n\log n$, so savings in movement and arithmetic are needed.
  - relies on: nlogn-conjecture, address-interchange, butterfly-layer, exact-ring-products, main-algorithm
  - **S1** (infer, page `nlogn-conjecture`): Schönhage and Strassen conjectured that $n\log n$ is the optimal order of growth for multiplication, the conjecture the new bound refutes.
    - relies on: multitape-tm, big-o
    - quotes line 41: "machine, and proposed $n\log n$ as the optimal order of growth"
  - **S2** (show): Two tape procedures, an address interchange and a simultaneous butterfly layer, cost a power of their parameter below the first power times the volume.
    - method: build both from fixed linear networks that restore scratch values, and recurse on their rank saving
    - motivation (explicit): Scanning a $\Theta(n)$-bit array at each of $\Theta(\log n)$ transform levels already costs $n\log n$, so both movement and arithmetic must be sped up.
    - **S2.1** (infer, page `stream-operations`): Fixed-radix digit moves, splits, merges and row splitting on an array of volume $V$ take $O(V)$ steps on a fixed number of tapes.

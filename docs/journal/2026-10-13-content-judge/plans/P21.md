# Plan P21

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-result`): A multitape Turing machine multiplies $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: chain reductions from the integer product to a convolution over $\mathbb C[y]/(y^r+1)$, compute it with accelerated synthetic transforms, then recover the exact product
  - motivation (recoverable): Each stage changes the problem into one whose transform uses only shifts, address rearrangements and butterflies, which the two fast tape procedures speed up; precision analysis then gives exactness.

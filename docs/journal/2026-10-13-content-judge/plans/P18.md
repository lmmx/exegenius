# Plan P18

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): One fixed-tape Turing machine multiplies n-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: Beat the $n\log n$ cost of transform-based multiplication by making the two tape operations (address rearrangement and butterfly layers) cost a power of their width less than a full scan, then plug them into the Harvey-van der Hoeven resampling reduction
  - motivation (explicit): Scanning the data once per transform level already costs n log n, so savings are needed in both movement and arithmetic.
  - relies on: multitape-model, nlogn-conjecture, hh-multiplier
  - **S1** (infer, page `address-fields-layout`): In the fixed multitape model data movement costs time, so arrays are laid out in address order and fields of addresses are contiguous chunks.
    - relies on: multitape-model, binary-representation-and-bit-operations, turing-machine-basics
    - quotes line 435: "A machine has one fixed finite alphabet and one fixed finite number of one-dimensional tapes."
  - **S2** (show): Fixed linear networks with restored auxiliary values give $s<Wm$ smaller calls per recursion level.
    - method: Construct finite networks, explain how frames let arrays flow through them, label gates by nested subspaces, and count dimension drops
    - motivation (recoverable): A strict rank deficit in a finite network is what turns into a power saving when the network is applied recursively on tape.
    - **S2.1** (infer, page `linear-network`): A fixed linear network on $W$ wires exchanges two banks of values with signs and restores every auxiliary value.
      - relies on: vectors-matrices-and-linear-maps
      - quotes line 643: "We construct two fixed linear networks that exchange two banks of values"
    - **S2.2** (infer, page `frames`): Giving all wires at a gate a common invertible frame lets the gate act pointwise, intermediate frames cancel, and only an endpoint operator remains.
      - relies on: linear-network, vectors-matrices-and-linear-maps
      - quotes line 645: "arrays, a common representation on all wires at a gate lets that gate act"
    - **S2.3** (infer, page `subset-subspace-labels`): Nested subspace labels from three-element subsets make the changes of frame on edges cost only their dimension drops, with total $s<Wm$ available.
      - relies on: frames, subspaces-dimension-and-rank, vector-spaces-over-gf-2
      - quotes line 849: "A label is a nondegenerate subspace of a fixed bilinear space."
    - **S2.4** (infer, page `recursive-saving`): A call at parameter $mf$ makes $s<Wm$ calls at parameter $f$ on volume $V/W$, so cost per volume grows by a factor below $m$: a power saving.
      - relies on: subset-subspace-labels, divide-and-conquer-recurrences
      - quotes line 1341: "\frac{s_{\rm b}}{W_{\rm b}}<m^\tau,"
  - **S3** (show, page `fast-address-interchange`): Two disjoint contiguous $u$-bit address fields of an array of volume $V$ can be swapped in cost $O(Vu^\tau)$ with $\tau<1$.
    - method: Apply the bit network whose endpoint operator is an address shear, completed by a triangular factorization, recursing on smaller interchanges
    - motivation (recoverable): Plain permutation of fields costs more than scanning; XOR combinations through the network permit recursion that saves a power of the width.
    - relies on: recursive-saving, address-fields-layout
    - **S3.1** (infer, page `address-shear`): The endpoint operator $(H,D)\mapsto(H+D,D)$ is a shear, and a lower-triangular factorization lets two further linear updates complete the interchange.
      - relies on: triangular-matrices-and-elimination, frames, address-fields-layout
      - quotes line 1362: "We give its elementary elimination proof in this order."
    - **S3.2** (infer): For power widths the recursion gives interchange cost $O(Vu^\tau)$.
      - quotes line 1475: "\begin{proposition}[Power-width interchange with rows]"
    - **S3.3** (infer): Padding removes the width and row restrictions.
      - quotes line 1631: "\begin{lemma}[Arbitrary-width interchange]"
  - **S4** (infer, page `fast-butterfly-layers`): The same butterfly bit of at most $d$ chunks can be processed simultaneously in cost $O(Vd^{\lambda'})$ with $\lambda'<1$, with one final truncation.
    - relies on: butterfly-layer, recursive-saving, fixed-point-precision, fast-address-interchange
    - quotes line 2588: "\begin{proposition}[Simultaneous normalized butterfly layer]"
  - **S5** (show, page `synthetic-transforms`): Synthetic transforms over $\mathbb C[y]/(y^r+1)$ are computed with shifts, rearrangements and butterflies at reduced cost.
    - method: Use powers of y as roots of unity and run the transform by layers, using the fast layers and interchanges
    - motivation (recoverable): Roots being signed shifts removes all multiplications except butterflies and address movement, exactly the two accelerated operations.
    - relies on: ring-y-r-plus-1, dft-roots-of-unity, multidimensional-transform, butterfly-layer
    - **S5.1** (infer): Synthetic roots satisfy character cancellation, so the transforms invert each other.
      - quotes line 2810: "\begin{lemma}[Synthetic character cancellation]"
    - **S5.2** (infer, page `fast-synthetic-transform`): Forward synthetic transforms keep the same frequency order through the pointwise product and the opposite transform consumes it, at the layer-based cost.
      - relies on: fast-butterfly-layers, fast-address-interchange, cyclic-convolution
      - quotes line 2929: "\begin{lemma}[Transform layout and cost]"
  - **S6** (infer, page `signed-packing`): Ring products are computed by signed Kronecker packing and the established $O(N\log N)$ multiplier.
    - relies on: hh-multiplier, ring-y-r-plus-1
    - quotes line 3221: "\begin{lemma}[Signed packing and normalized ring multiplication]"
  - **S7** (show, page `gaussian-resampling`): Fourier transforms on pairwise coprime lengths reduce to power-of-two tensor transforms with contraction bounds.
    - method: Gaussian resampling, keeping both coordinate permutations inside the transform formula rather than sorting
    - motivation (explicit): The needed transform lengths are coprime but synthetic transforms need powers of two; resampling converts one to the other.
    - relies on: multidimensional-transform, dft-roots-of-unity, fixed-point-precision, permutations-and-bijections
    - **S7.1** (infer, page `retained-permutations`): The source and target permutations stay in the transform identity and cancel across forward, product and inverse transforms.
      - relies on: gaussian-resampling, bluestein-chirp, cyclic-convolution
      - quotes line 3548: "\begin{lemma}[Resampling without executing the two permutations]"
    - **S7.2** (infer): The tensor product over a growing number of axes keeps the interface.
      - quotes line 3800: "\begin{lemma}[Tensor interface]"
    - **S7.3** (infer): A chirp turns the middle transform into a convolution and the retained permutation cancels.
      - quotes line 3911: "\begin{lemma}[Chirp and permutation cancellation]"
  - **S8** (show, page `multiplication-assembly`): The exact product is recovered by the chain of reductions and its cost is $O(n(\lg n)^{1-\kappa})$.
    - method: Chain radix digits, CRT prime axes, resampling and chirps, phase twist, ring convolution, then rescale, round, carry and sum the cost table
    - motivation (recoverable): Each reduction changes the problem into one the fast tape procedures serve; a cost table then shows every term fits the bound.
    - relies on: cyclic-convolution, gaussian-resampling, retained-permutations, fast-synthetic-transform, signed-packing, fixed-point-precision, bluestein-chirp, radix-base-b-expansion, schoolbook-multiplication-and-carries
    - **S8.1** (infer, page `crt-prime-axes`): A Chinese-remainder address map places the digit list on distinct prime cyclic axes preserving convolution.
      - relies on: modular-arithmetic-and-congruences, prime-numbers-and-coprimality, cyclic-convolution
      - quotes line 4197: "To use the source tensor, we first place the ordinary coefficient stream"
    - **S8.2** (infer, page `phase-twist`): A phase twist turns the last cyclic axis into a polynomial modulo $y^r+1$.
      - relies on: ring-y-r-plus-1, exponential-function-and-euler-s-formula
      - quotes line 4308: "is well defined, since $(\zeta y)^r=(-1)(-1)=1$."
    - **S8.3** (infer): Bluestein chirps turn the middle transform into a convolution.
      - quotes line 4417: "We next use the complex convolution to evaluate the middle factor"
    - **S8.4** (infer): The algorithm applies the address map, transforms, pointwise product, inverse transform, rescale, round and carries.
      - quotes line 4508: "Apply the coefficient-address map $\Phi$, with its padded layout, to obtain"
    - **S8.5** (infer, page `fixed-point-precision`): With fixed-point arrays the final coefficient error is below $1/2$, so rounding recovers exact integers.
      - relies on: fixed-point-and-finite-precision-numbers, floor-ceiling-and-rounding, norms-and-triangle-inequality
      - quotes line 4546: "\subsection{Precision and exact recovery}"
    - **S8.6** (infer): Summing the cost table, all terms are $O(n(\lg n)^{1-\kappa})$.
      - relies on: constants-exponents-and-power-of-two-sizes
      - quotes line 4810: "For the cost calculation put $V=Tp=\Theta(n)$."

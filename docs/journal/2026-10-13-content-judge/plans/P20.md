# Plan P20

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): Two $n$-bit integers can be multiplied exactly on a fixed finite-tape machine in time $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$.
  - method: reduce multiplication to convolution, build two fast tape procedures whose recursion has a strict rank saving, and assemble the transforms into an exact product
  - motivation (recoverable): Scanning costs a pass per transform level, giving $n\log n$; a power saving requires cheaper movement and arithmetic, then a full exact multiplication assembled around them.
  - relies on: multitape-model, time-complexity-and-reductions
  - **S1** (infer, page `nlogn-conjecture`): Schönhage and Strassen conjectured that $n\log n$ is optimal, and Harvey and van der Hoeven reached $O(n\log n)$; the goal is to beat it.
    - relies on: multitape-model, big-o
    - quotes line 43: "Harvey and van der Hoeven reached the unconditional $O(n\log n)$ upper"
  - **S2** (infer, page `convolution`): Splitting the inputs into radix digits reduces integer multiplication to convolution of short integer coefficient lists.
    - relies on: radix-base-b-positional-representation, schoolbook-multiplication
    - quotes line 76: "Splitting the inputs into radix digits reduces multiplication to"
  - **S3** (show): Two tape procedures, a fast address-field interchange and fast simultaneous butterfly layers, beat the $\Theta(n\log n)$ cost of scanning.
    - method: show that scanning is too expensive, then build both procedures from one network
    - motivation (explicit): The ordinary cost is a scan per level; a saving must come from changing how movement and arithmetic are done.
    - **S3.1** (infer, page `tape-address-rearrangement`): Scanning $\Theta(n)$ stored bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so savings are needed in both movement and arithmetic.
      - relies on: multitape-model, turing-tapes, big-o
      - quotes line 90: "Scanning an array of $\Theta(n)$ stored bits at each of"
    - **S3.2** (show, page `linear-network-frames`): Both tape procedures arise from one fixed linear network exchanging two banks of values with frames, and recursion on it saves a power.
      - method: describe the network with frames, build a finite one with a rank deficit, then recurse
      - motivation (recoverable): Each procedure must be implemented by smaller calls to itself; a network with frames lets every edge be such a call and the rank deficit makes the recursion cheaper than linear growth.
      - relies on: linear-algebra-over-the-reals-and-rationals, permutations
      - **S3.2.1** (infer): Along a fixed linear network that exchanges two banks of values, each vertex has an invertible frame $D_v$ whose changes cancel along a route, leaving an endpoint operator on every role.

      - **S3.2.2** (show, page `finite-network-subspaces`): A finite network with fewer than $Wm$ smaller calls exists, with explicit bit and complex interfaces.
        - method: construct the network from three-element subsets with nested subspace labels, then check scalar behaviour, rank budget and the two interfaces
        - motivation (reconstructed): The recursive saving needs a concrete finite network whose rank deficit is strict, so it has to be built and its label dimensions counted.
        - relies on: linear-network-frames, linear-algebra-over-the-reals-and-rationals, basic-set-notation-and-counting
        - **S3.2.2.1** (infer): Subspaces of an $m$-dimensional space attached to gates, built from three-element subsets, give a network with total number $s$ of smaller calls satisfying $s<Wm$.
          - quotes line 168: "number $s$ of smaller calls satisfies $s<Wm$."
        - **S3.2.2.2** (infer, page `scalar-motifs`): With arbitrary initial scratch values, three stages of the scalar gates exchange the banks $(X,Y)\mapsto(-Y,X)$ and restore every auxiliary value.
          - relies on: linear-network-frames
          - quotes line 729: "For arbitrary initial values of its auxiliary wires, a forward"
        - **S3.2.2.3** (infer, page `motif-residuals`): Edges join comparable subspace labels, and the total dimension change over edges is $Wm-2N+2L$, giving the strict rank deficit $s<Wm$.
          - relies on: scalar-motifs, linear-algebra-over-the-reals-and-rationals
          - quotes line 998: "Every edge joins comparable nondegenerate labels."
        - **S3.2.2.4** (infer, page `motif-interfaces`): The bit network realises the address permutation with small rank sum, and the complex network realises phase frames made of translation kernels.
          - relies on: motif-residuals, binary-representation-and-bit-operations
          - quotes line 1139: "The bit network has $W_{\rm b}$ wires, uses only pointwise XOR gates,"
      - **S3.2.3** (infer, page `recursive-power-saving`): Calls at parameter $mf$ use $s$ calls at parameter $f$ on volume $V/W$, and $s/W<m^\tau$ with $\tau<1$ gives a power saving.
        - relies on: finite-network-subspaces, divide-and-conquer-recurrences
        - quotes line 1341: "\frac{s_{\rm b}}{W_{\rm b}}<m^\tau,"
    - **S3.3** (show, page `address-interchange`): Two address fields of $u$ bits are interchanged at cost $O(Vu^\tau)$ with $\tau<1$.
      - method: apply the recursive network to address shears, then to chunk interchange
      - motivation (recoverable): Ordinary scanning pays one pass per level; the network turns the interchange into shears whose cost obeys the strict recursion.
      - relies on: elementary-streams, recursive-power-saving, permutations
      - **S3.3.1** (infer, page `matrix-shear`): Any rational matrix of rank $a$ factors as $E_1\Pi E_2$ with lower triangular $E_1,E_2$, so the shear $(H,D)\mapsto(H+AD,D)$ needs exactly $a$ field interchanges plus linear work.
        - relies on: elementary-streams, gaussian-elimination-and-triangular-matrices, recursive-power-saving

      - **S3.3.2** (infer, page `chunk-swap`): Two address chunks of width $e=m^k$ are interchanged in $O(Ve^\tau)$, and then chunks of arbitrary width $u$ are interchanged by decomposition.

        - quotes line 1631: "\begin{lemma}[Arbitrary-width interchange]"
    - **S3.4** (show, page `fast-butterfly-layer`): Simultaneous butterfly layers on selected coordinate bits cost $O(Vd^{\lambda'})$, $\lambda'<1$.
      - method: apply the complex phase network, changing numerical address coordinates by packed bit additions
      - motivation (recoverable): The numerical layer has the same recursive shape as the address interchange, but needs address coordinates of the arrays changed, which packed additions supply.
      - relies on: linear-network-frames, recursive-power-saving, address-interchange, fixed-point-arithmetic-and-rounding-error
      - **S3.4.1** (infer, page `packed-selected-bit-addition`): Selected bits at positions $\rho+iK$ of several chunks are XORed simultaneously by packing, with a small exceptional set of addresses repaired.
        - relies on: address-interchange, binary-representation-and-bit-operations
        - quotes line 1974: "\begin{lemma}[Packed selected-bit addition on one rectangle]"
      - **S3.4.2** (infer): The layer $H_0(u,v)=((u+v)/2,(u-v)/2)$ is applied simultaneously on selected coordinate bits of complex fixed-point arrays at cost $O(Vd^{\lambda'})$ with $\lambda'<1$.
        - quotes line 2588: "\begin{proposition}[Simultaneous normalized butterfly layer]"
  - **S4** (show): The integer product is reduced to a convolution over $\mathbb C[y]/(y^r+1)$, computed with the fast procedures, with exact recovery of the result.
    - method: chain the reductions: convolution on the ring, Gaussian resampling, chirps, Chinese-remainder axes, phase twist, then precision and cost
    - motivation (recoverable): The sources present the reductions as a flow of changes of problem, each cheap, ending at a ring where the fast transforms apply; the last stage recovers the exact integer.
    - **S4.1** (show, page `synthetic-transforms`): Convolution over $\mathbb C[y]/(y^r+1)$ is computed with synthetic transforms and packed polynomial products.
      - method: apply a synthetic transform, multiply pointwise by signed packing, and apply the opposite transform
      - motivation (recoverable): Over this ring the roots of unity are powers of $y$, so the transforms are cheap shifts and butterflies, and the pointwise products are ordinary integer multiplications.
      - relies on: polynomial-ring-y-r-1, fourier-transform, complex-numbers
      - **S4.1.1** (infer): Synthetic characters cancel: sums of powers of $\omega_t$ are $t$ or $0$, so the forward and backward synthetic transforms invert each other up to $t^{-1}$.

      - **S4.1.3** (infer, page `signed-packing`): Signed packing turns polynomial products in $\mathcal R_r$ into integer products solved by the established $O(n\log n)$ multiplier.

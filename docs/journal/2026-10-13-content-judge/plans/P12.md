# Plan P12

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A deterministic multitape Turing machine multiplies $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$.
  - method: reduce integer multiplication to a Fourier convolution evaluated with two fast tape procedures, then bound error and cost
  - motivation (explicit): Scanning Theta(n) bits at each of Theta(log n) transform levels costs n log n, so power savings are needed in both movement and arithmetic.
  - relies on: nlogn-conjecture, harvey-hoeven-multiplier, multitape-tm, big-o
  - **S1** (show, page `chunk-interchange`): Two equal-width address chunks of $u$ digits in an array of volume $V$ can be interchanged in $O(Vu^\tau)$ time for a fixed $\tau<1$.
    - method: build a fixed linear network that exchanges two banks with restored scratch, label its edges so that edge matrices have small total rank, and recurse on smaller interchanges
    - motivation (explicit): Plain address rearrangement costs a full scan per level, so a recursion in which the total number of smaller calls is below (wires x parameter) is needed to save a power of the chunk width.
    - relies on: fixed-tape-model, elementary-streams
    - **S1.1** (show, page `linear-network`): A fixed linear network of gates on wires (roles), applied to arrays, can have each wire carry an invertible frame, so that only the change of frame on each edge has to be implemented.
      - method: attach a frame to every source, gate and sink and observe that frames commute with pointwise gates
      - motivation (recoverable): Pointwise gates act on matching addresses, so a common frame at a gate leaves the gate unchanged and intermediate frames cancel; only edges cost anything.
      - relies on: fixed-tape-model, elementary-streams, graphs-and-networks, matrices-and-linear-maps

      - method: schedule the operation, then undo the unwanted scratch contributions so arbitrary initial values cancel
      - motivation (recoverable): The tape machine cannot assume scratch arrays are zero, so the net effect must be independent of their initial contents.
      - relies on: linear-network, binary-representation-and-bit-operations
      - **S1.2a** (infer): A forward invocation changes $y_S$ to $y_S+x_S$ for arbitrary scratch values; three stages exchange the banks and restore scratch.

    - **S1.4** (show, page `rank-saving`): The edges of the finite network need $s<Wm$ smaller calls in total, so a call on volume $V$ at parameter $m f$ costs $s$ calls at parameter $f$ on volume $V/W$ with $s/W<m^\tau$.
      - method: turn the strict rank inequality into a recurrence whose per-volume growth is below $m$
      - motivation (explicit): Dividing by volume, multiplying the parameter by $m$ multiplies cost by only $s/W<m$, which gives a power saving instead of linear growth.

    - **S1.5** (show, page `bruhat-shear`): Every rational matrix factors as $E_1\Pi E_2$ with lower triangular $E_1,E_2$ and a partial permutation of rank-many ones, so an edge matrix of rank $a$ costs $a$ smaller interchanges plus tape-order shears.

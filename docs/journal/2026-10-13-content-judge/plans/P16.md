# Plan P16

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A deterministic fixed-tape Turing machine multiplies two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: Reduce multiplication to digit convolution computed by Fourier transforms, and speed up the two bottlenecks, address rearrangement and butterfly layers, by a recursion with a strict rank saving
  - motivation (explicit): Plain transform multiplication spends $\Theta(\log n)$ scans of the data; shaving a power off that factor requires savings in both movement and arithmetic.
  - relies on: nlogn-conjecture, convolution, hvdh-multiplier
  - **S1** (infer, page `tape-streams`): Moving data on a fixed-tape machine costs time: scanning $\Theta(n)$ stored bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$.
    - relies on: turing-machine, big-o, finite-state-and-constant-size-alphabets
    - quotes line 91: "$\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$."
  - **S2** (show, page `fast-interchange`): Two equal address chunks of $u$ digits of an array of volume $V$ can be interchanged in time $O(Vu^\tau)$ for a fixed $\tau<1$.
    - method: Build a fixed linear exchange network whose endpoint operator is an address shear, show its total edge rank $s$ is below $Wm$, and recurse on smaller interchanges
    - motivation (explicit): Plain sorting of address fields costs a pass per level; a recursion whose number of smaller calls is less than the number of roles times the dimension saves a power of the chunk width.
    - relies on: tape-streams, address-fields, linear-network, subset-network, recursive-power-saving, shear-factorization, linear-algebra-over-gf-2, big-o
    - **S2.1** (infer, page `linear-network`): A fixed linear exchange network with a common invertible frame at each gate lets arrays flow through pointwise, so only the endpoint frame operators remain on each of the $W$ roles.

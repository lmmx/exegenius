# Plan P22

The plan of the argument for the main theorem, as a tree of steps.

- **R** (show, page `main-theorem`): Two $n$-bit integers are multiplied exactly by a deterministic fixed-tape machine in time $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$.
  - method: Reduce the product to convolution through a chain of exact changes of representation, supply the movement and butterfly cost savings by two fast tape procedures, and assemble parameters, precision and cost.
  - motivation (explicit): Scanning an array of $\Theta(n)$ bits at each of $\Theta(\log n)$ transform levels costs $\Theta(n\log n)$, so both address movement and arithmetic must be sped up before the transform chain is used.
  - relies on: conjecture
  - **S1** (infer, page `multitape-model`): A machine with one fixed alphabet and a fixed number of tapes pays for moving data by scans, so a pass over $n$ bits costs $\Theta(n)$.
    - relies on: turing-tapes, big-o
    - quotes line 435: "A machine has one fixed finite alphabet and one fixed finite number of"
  - **S2** (show, page `recursive-power-saving`): Fixed linear exchange networks with $s<Wm$ give a recursion whose per-volume cost grows by a factor $s/W<m$ when the parameter is multiplied by $m$, hence cost $V\cdot(\text{parameter})^\theta$ with $\theta<1$.
    - method: Build a fixed network on $W$ roles with frames, label its gates by nested subspaces of an $m$-dimensional space so that the number $s$ of smaller calls is below $Wm$, then solve the recursion.
    - motivation (explicit): The power saving comes only from a strict rank deficit across the edges of the network, so the argument must construct the network and its labels before the recursion can be analysed.
    - relies on: recurrences-and-divide-and-conquer, big-o, multitape-model
    - **S2.1** (infer, page `linear-network-frames`): With an invertible frame $D_v$ at each vertex, gates act pointwise and intermediate frames cancel, leaving an endpoint operator on each role array.
      - relies on: matrices-and-linear-maps, diagonal-matrices
      - quotes line 793: "At each source, gate and sink $v$, assign an invertible $R$-linear operator"
    - **S2.2** (infer, page `subset-intersection-network`): Labelling gates by subspaces of an $m$-dimensional space built from three-element subsets makes adjacent edge operators nested, so the total number $s$ of smaller calls is less than $Wm$.
      - relies on: linear-network-frames, vector-spaces-over-finite-fields, matrices-and-linear-maps
      - quotes line 853: "The saving will come from keeping the total dimension lost on decreasing"
    - **S2.3** (infer): A call at parameter $mf$ uses $s$ calls at parameter $f$ on volume $V/W$ with $W$ roles and label dimension $m$, so $s/W<m^\tau$ with $\tau<1$ and the cost is $V$ times a power of the parameter below $1$.
      - quotes line 1341: "\frac{s_{\rm b}}{W_{\rm b}}<m^\tau,"
  - **S3** (show, page `chunk-interchange`): Two disjoint contiguous address fields of $u$ bits of an array of volume $V$ can be interchanged in time $O(Vu^\tau)$ with a fixed $\tau<1$, exactly for arbitrary auxiliary values.
    - method: Realise the bit network on tape: factor each edge operator into lower triangular shears performed in linear time, and apply the recursion with the rank saving; then remove width and row restrictions.
    - motivation (recoverable): Plain sorting of fields costs a full pass per level; computing XOR combinations through the saving network replaces most passes by smaller interchanges, which is where $\tau<1$ comes from.
    - relies on: recursive-power-saving, subset-intersection-network, linear-network-frames, multitape-model
    - **S3.1** (infer, page `lower-triangular-shear`): A rational shear $(H,D)\mapsto(H+AD,D)$ of rank $a$ is performed with $a$ interchanges of $b$-digit fields plus linear work, via lower triangular factors with reversed coordinate order, on $u$-digit fields.
      - relies on: matrices-and-linear-maps, permutations, multitape-model
      - quotes line 1360: "is the Bruhat factorization for arbitrary matrices, with coordinate order"
    - **S3.2** (infer): The interchange of two $u$-bit chunks $(p,h,g,d,z)\mapsto(p,d,g,h,z)$ is done for arbitrary widths $u$ in $O(Vu^\tau)$ steps.
      - quotes line 1633: "There exist fixed $0<\tau<1$ and one fixed finite-alphabet multitape"
  - **S4** (show, page `fast-butterfly-layer`): A butterfly layer $H_0$ on the same bit of $d$ address chunks of a polynomial array of volume $V$ costs $O(Vd^{\lambda'})$ with $\lambda'<1$, instead of $d$ full passes.
    - method: Apply the complex network to a tensor product of an auxiliary kernel using phase frames, bound the exact dyadic intermediate values, then convert to $H_0$ with a single truncation.
    - motivation (explicit): Separate butterfly factors would need $D$ whole-array passes; the same rank-saving recursion over selected bits gives a power saving in the number of chunks.
    - relies on: recursive-power-saving, chunk-interchange, ring-y-r, fixed-point-precision

      - quotes line 1778: "of $H_0(u,v)=((u+v)/2,(u-v)/2)$ on the $D$ selected bits, acting"
    - **S4.2** (infer, page `phase-frames`): Diagonal phase frames express a tensor product of the auxiliary kernel $C$ on many selected bits via smaller groups of bits separated by binary changes of basis done by moving whole chunks.

    - **S4.3** (infer, page `gaussian-dyadics`): All intermediate values are exact Gaussian dyadics, and the layer is evaluated exactly before one truncation.

    - **S4.4** (infer): The layer over $d$ chunks costs $O(Vd^{\lambda'})$ with $\lambda'<1$.

  - **S5** (show, page `transform-layout`): Convolution over $\mathcal R_r=\mathbb C[y]/(y^r+1)$ with $r$ coefficients per record is computed with synthetic transforms laid out on tape, a pointwise product and the opposite transform, with the stored frequency order retained.
    - method: Use polynomial roots of unity $y^{2r/t}$ so the transforms are signed shifts and butterflies, arrange tape layout so the parallel layers apply, then multiply pointwise by exact ring products.
    - motivation (recoverable): Roots of unity inside the ring act as signed shifts, which makes each transform level a butterfly layer that the fast simultaneous layer accelerates.
    - relies on: ring-y-r, dft-convolution, fast-butterfly-layer, chunk-interchange, synthetic-transform
    - **S5.1** (infer, page `ring-y-r`): The ring of polynomials modulo $y^r+1$ with $r$ coefficients has powers of $y$ as roots of unity, and multiplication by $y^a$ is a signed cyclic shift of the coefficients.

  - **S7** (show, page `gaussian-resampling`): A Fourier transform of coprime length is expressed through a power-of-two tensor transform by Gaussian resampling, with the permutations retained and the middle transform turned into cyclic convolution.
    - method: Use Harvey--van der Hoeven resampling, keeping source and target permutations inside the transform formula, apply it line by line over many coordinates, and rewrite the middle transform by a chirp identity.

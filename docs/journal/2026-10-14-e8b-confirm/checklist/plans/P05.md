The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): One deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time, with $\kappa=2^{-182}$, refuting the $n\log n$ optimality conjecture in this model.
  - method: Build the multiplier bottom-up: first the two power-saving tape procedures, then a convolution over a polynomial ring made from them, then the Gaussian-resampling and Bluestein reductions, then assemble the algorithm and add up its costs.
  - motivation (explicit): Scanning an array of $\Theta(n)$ bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so savings are needed in both address movement and arithmetic.

    - method: Prove both from one construction: elementary linear-time stream scans, one fixed linear network whose edge changes are smaller calls with total $s<Wm$, then specialise it to the bit network (address interchange) and to the complex network (butterfly layer).

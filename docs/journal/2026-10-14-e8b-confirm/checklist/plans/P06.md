# Plan P06

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `multiplication-below-nlogn`): A single deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: Build two fast tape procedures (address interchange and simultaneous butterfly layers), use them to compute the synthetic ring convolution and the Gaussian-resampled source transforms, then assemble the digit-convolution multiplication and account for precision and cost.
  - motivation (explicit): Scanning an array of $\Theta(n)$ stored bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$. We therefore need savings in both movement and arithmetic.
  - relies on: multiplication-algorithm, exact-recovery, time-bound-accounting, hvdh-multiplier, big-o, turing-machines
  - **S1** (infer, page `convolution-multiplication`): Writing the inputs in radix digits reduces the product to a convolution of short integer coefficient lists.
    - relies on: polynomials, radix-representation-and-carry-propagation
    - quotes line 76: "Splitting the inputs into radix digits reduces multiplication to convolution of short integer coefficients."
  - **S2** (show): Two fast tape procedures exist: interchanging two address chunks of $u$ bits in $O(Vu^\tau)$ time, and applying a normalized butterfly layer to $d$ chunks at once in $O(Vd^{\lambda'})$ time, with fixed $\tau,\lambda'<1$.
    - method: Derive each procedure from a fixed linear network that exchanges two banks with restored scratch wires and whose rank sum $s$ is smaller than $Wm$, so that the recursion on smaller calls saves a power.
    - motivation (explicit): The decisive property is that the total number $s$ of smaller calls satisfies $s<Wm$.
    - **S2.1** (show, page `chunk-interchange`): Two disjoint address chunks of $u$ bits in an array whose addresses form a complete Cartesian product can be interchanged in $O(Vu^\tau)$ time for a fixed $\tau<1$, although the intermediate steps XOR data together.
      - method: Realise the interchange as an exact permutation computed by a fixed linear network with restored scratch wires, give every network edge a frame so that it becomes a smaller interchange, and let the rank deficit $s<Wm$ produce a recursion with power saving.
      - motivation (explicit): Because the sum of these ranks is less than the number of wires times $m$, the resulting recurrence saves a power of the chunk width.
      - relies on: power-width-interchange, binary-representation-bit-strings-and-xor, cartesian-products-and-lexicographic-order
      - **S2.1.1** (infer, page `multitape-streams`): Fixed digit permutations, digit moves, splitting on a digit and splitting rows cyclically into $W$ streams each cost $O(V)$ on a fixed number of tapes, so these elementary scans are free at the scale of the recursion.
        - relies on: turing-machines, big-o, cartesian-products-and-lexicographic-order

      - **S2.1.3** (show, page `bank-exchange-network`): Three invocations of a fixed schedule of linear gates exchange the two banks $X,Y$ up to sign and restore every scratch wire, whatever its initial value.
        - method: Schedule gates so the old scratch contributions are first cancelled and later restored, then check the net coefficient from each source to each target by the size of the triple intersection.
        - motivation (recoverable): The network must give the same answer for arbitrary initial scratch contents, because on tape the scratch roles hold real data; a schedule that cancels and restores the scratch values makes the net effect independent of them.
        - relies on: binary-representation-bit-strings-and-xor, rational-numbers-and-dyadic-fractions

# Plan P03

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A deterministic multitape Turing machine multiplies two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, disproving the $n\log n$ optimality conjecture in this model.
  - method: Build the multiplier bottom-up: power-saving tape procedures from linear exchange networks with a rank saving; a fast convolution over a polynomial ring by synthetic transforms; extension to coprime-length axes by Gaussian resampling and chirps; then the integer reduction with exact recovery and the cost accounting.
  - motivation (explicit): Scanning $\Theta(n)$ stored bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so both data movement and arithmetic must be sped up by a power of the logarithm.
  - relies on: n-log-n-barrier, multitape-turing-machine, big-o-notation, subroutines-and-composition-of-algorithms
  - **S1** (show, page `tape-address-model`): On a fixed number of tapes, arrays stored in lexicographic order admit digit moves, splits, row splitting and controlled cyclic shifts in $O(V)$ time, where $V$ is the logical bit volume.
    - method: State the elementary scans once, with counters, rewinds and cleanup charged, and then count every later procedure in units of one such scan.
    - motivation (recoverable): Every later procedure (interchange, butterfly layer, CRT map) is assembled from these scans, so their linear cost is the unit in which all later bounds are stated; the machine model has to be pinned down before any saving can be measured.
    - relies on: multitape-turing-machine, multidimensional-arrays-and-row-major-order, binary-numerals-and-bit-strings, positional-notation-in-any-radix
    - **S1.1** (infer): For a fixed radix $q$, permuting the digit values at two positions, moving one digit, splitting on a digit with a fixed pointwise map and merging back, and splitting whole rows cyclically into $W$ streams of volume $V/W$ (and merging them) each take $O(V)$ steps.

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `sub-linearithmic-integer-multiplication`): A single deterministic fixed-alphabet machine with a fixed number of one-dimensional tapes multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ worst-case time, with $\kappa=2^{-182}$.
  - method: reduce the product to a transform pipeline whose tape-costly layers each save a power of their width, then fix rational exponents so that every cost term is within the bound
  - motivation (explicit): Scanning the stored bits at every transform level already costs $n\log n$, so savings in both movement and arithmetic are needed.
  - relies on: integer-multiplication-problem, fixed-tape-model, sch-conjecture
  - **S1** (show, page `fast-address-interchange`): Two disjoint equal-width address chunks of $u$ bits in an array of stored volume $V$ are interchanged in $O(Vu^{\tau})$ time for a fixed exponent $\tau<1$.

    - motivation (explicit): Because each edge needs only as many smaller interchanges as its rank, the total rank saves a power of the chunk width.

# Plan P07

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): One deterministic fixed-alphabet multitape Turing machine computes $\operatorname{bin}_{2n}(\operatorname{val}(x)\operatorname{val}(y))$ for all $n$-bit inputs in time $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$, refuting the $n\log n$ optimality conjecture in that model.
  - method: build two sub-logarithmic tape procedures (address-chunk interchange and simultaneous butterfly layers) from finite linear networks with a rank saving, insert them into the Harvey--van der Hoeven reduction of multiplication to convolution over $\mathbb C[y]/(y^r+1)$ via a Chinese-remainder map, Gaussian resampling, chirps and a phase twist, recover the integer coefficients exactly, and sum the normalized cost table
  - motivation (explicit): In the $O(n\log n)$ approach every one of $\Theta(\log n)$ transform levels rescans $\Theta(n)$ bits, so going below $n\log n$ requires saving both on address movement and on butterfly arithmetic, which is what the two network-based procedures provide.
  - relies on: exact-multiplication-problem, optimality-conjecture, multitape-turing-machine, big-o-notation, hvdh-multiplier
  - **S1** (show, page `chunk-swap`): Two disjoint contiguous address fields of $u$ bits in an array of logical volume $V$ can be interchanged on a fixed number of tapes in $O(Vu^\tau)$ time for a fixed $\tau<1$.

    - motivation (explicit): An interchange whose field width grows cannot be done by a bounded number of scans; the network turns one shear of width $mf$ into $s$ shears of width $f$ on streams of volume $V/W$, and since $s<Wm$ the recurrence saves a power of the width.
    - relies on: power-width-interchange, elementary-streams, bank-exchange, rank-saving, binary-field

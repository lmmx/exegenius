# Plan P06

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): One deterministic fixed-tape Turing machine computes the exact $2n$-bit product of two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: build two linear-network tape procedures, fast address interchange and simultaneous butterfly layers, from fixed networks with a strict rank saving; use them in synthetic transforms; place these in the Harvey–van der Hoeven reduction through radix digits, a CRT map, Gaussian resampling with retained permutations, Bluestein chirps and a phase twist; and bound every cost term
  - motivation (explicit): A single scan per transform level already costs $\Theta(n\log n)$, so going below $n\log n$ needs savings in both address movement and butterfly arithmetic.
  - relies on: nlogn-conjecture, radix-digit-convolution, hvdh-multiplier, multitape-turing-machine, big-o-notation
  - **S1** (show, page `fixed-tape-model`): On a fixed number of tapes, digit moves, permutations of two digit values, splits with fixed pointwise maps, cyclic row splits, controlled shifts and fixed rational scalings of an address field each cost $O(V)$ on an array of volume $V$.
    - method: stream each operation in lexicographic address order, splitting the array into a fixed number of aligned streams and merging them back
    - motivation (recoverable): Addresses are implicit in the position of an entry in the ordered stream, so any operation that needs only a fixed number of aligned streams, or a target field that follows its controls, can be done in a bounded number of scans.
    - relies on: multitape-turing-machine, lexicographic-order, deterministic-worst-case-time-complexity
    - **S1.1** (infer): Fixed digit-pair permutations, single-digit moves, splits with a pointwise map, and cyclic splits of whole rows into $W$ streams each cost $O(V)$.

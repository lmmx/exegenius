# Plan P07

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): There is one deterministic Turing machine with a fixed finite alphabet and a fixed finite number of one-dimensional tapes that, for every $n\ge1$, returns the exact $2n$-bit product of two $n$-bit integers in worst-case time $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$, so the $n\log n$ optimality conjecture fails in this model.
  - method: Follow the Harvey–van der Hoeven reduction of the radix-digit convolution to power-of-two transforms over $\mathbb C[y]/(y^r+1)$ (Chinese-remainder axes, Gaussian resampling, chirps, a coefficient twist, synthetic transforms), replace its two $\Theta(n\log n)$ bottlenecks, address rearrangement and butterfly layers, by two tape procedures that save a power of their width, recover the exact product by rounding and carries, and choose the parameters so that every cost is $O(n(\log n)^{1-\kappa})$.
  - motivation (explicit): In the synthetic-transform representation the whole transform is address rearrangements, signed shifts and two-point butterflies, and merely scanning $\Theta(n)$ bits at each of $\Theta(\log n)$ levels already costs $\Theta(n\log n)$; so beating $n\log n$ needs savings in both data movement and arithmetic, which the two procedures supply inside an otherwise standard reduction.
  - relies on: fixed-tape-model, nlogn-conjecture, nlogn-multiplier, tape-machines, big-o, logarithms-and-exponentials, determinism-and-exact-versus-approximate-computation
  - **S1** (show): On a fixed number of tapes, two disjoint $u$-bit address chunks of an array of $V$ stored bits can be interchanged in $O(Vu^\tau)$ time, and the normalized butterfly $H_0$ can be applied on one selected bit in each of $D\le d$ address chunks in $O(Vd^{\lambda'})$ time, for fixed exponents $\tau,\lambda'<1$.
    - method: Build linear-time stream primitives; construct two fixed linear networks that exchange two banks while restoring scratch values and whose frame changes need only $s<Wm$ smaller calls; run each network on rows split cyclically among its $W$ wire roles, so that each smaller call acts on volume $V/W$.
    - motivation (explicit): A call at parameter $mf$ makes $s$ calls at parameter $f$ on streams of volume $V/W$, so after dividing cost by volume the recursive contribution grows by $s/W<m$ per factor $m$ of the parameter instead of by $m$; iterating this strict inequality yields a power saving in the width.
    - relies on: fixed-tape-model, array-order, big-o

# Plan P08

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A single deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ worst-case time with $\kappa=2^{-182}$.
  - method: start from the Gaussian-resampling reduction of multiplication to transforms, make the transforms cheaper by two tape procedures that each save a power of the logarithm, then recover the product exactly and add up all costs
  - motivation (explicit): Scanning the whole array at each of the $\Theta(\log n)$ transform levels costs $\Theta(n\log n)$, so a power saving needs savings in both data movement and arithmetic.
  - relies on: n-log-n-conjecture, fixed-tape-model, nlogn-subroutine, radix-digit-convolution, schoolbook-multiplication-and-divide-and-conquer-multiplication, big-o, turing-machine-tapes

# Plan P10

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A deterministic multitape Turing machine multiplies two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: Build two faster tape procedures (address chunk interchange and simultaneous butterfly layers) from rank-saving linear networks, use them in synthetic polynomial transforms and resampled source transforms for a convolution, reduce integer multiplication to that convolution, then prove exactness and add up costs.
  - motivation (explicit): Scanning an array of $\Theta(n)$ bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so savings are needed both in data movement and in arithmetic.
  - relies on: n-log-n-barrier, multitape-turing-machine, schoolbook-and-karatsuba-multiplication, big-o-notation, binary-numerals-and-bit-strings, subroutines-and-composition-of-algorithms
  - **A0** (show): The elementary tape operations that every later procedure calls cost $O(V)$ in the logical volume $V$.
    - method: State the linear-time scans (digit moves, splits, row splits) and the controlled cyclic shift that follow from them.
    - motivation (explicit): The later address and butterfly procedures are built from a fixed number of such scans, so their costs are only meaningful once these are known to be linear.
    - **A0.1** (infer, page `tape-address-model`): Fixed digit permutations, digit moves, splits on a digit and cyclic row splits of an array of logical volume $V$ stored in lexicographic order each take $O(V)$ steps on a fixed number of tapes.
      - relies on: multitape-turing-machine, multidimensional-arrays-and-row-major-order, positional-notation-in-any-radix, big-o-notation
      - quotes line 494: "volume $V$ takes $O(V)$ steps on a fixed number of one-dimensional tapes:"
    - **A0.2** (show, page `controlled-cyclic-shift`): Adding to a target address field $y\in[Q]$ an offset computed from earlier control fields, modulo $Q=q^b$, costs $O(V)$ although the fields may be arbitrarily long.
      - method: Treat each fiber of $Q$ blocks as a list: split it at $Q-a$ into two pieces and merge them in the opposite order, which is a cyclic rotation of the blocks.
      - motivation (recoverable): A cyclic shift of the target coordinate by $a$ is just moving the last $a$ blocks of the fiber in front of the first $Q-a$ blocks, which is one split and one reordered merge on tapes.
      - relies on: tape-address-model, modular-arithmetic, cyclic-shifts-and-rotations-of-lists
      - **A0.2.1** (infer): For each prefix fiber, split its $Q$ consecutive blocks at $Q-a$ and append the two pieces to two tapes.
        - quotes line 577: "For an offset $a\in[Q]$, split these blocks at $Q-a$."
      - **A0.2.2** (infer): Merging by reading the second piece and then the first piece gives the shifted coordinate in one more pass, so only the offset computation $b^{O(1)}=O(Q)$ remains, absorbed by the fiber.
        - quotes line 579: "merge read the second piece and then the first piece for each prefix."

    - motivation (explicit): When values are arrays, a common representation at each gate lets the gate act pointwise without disturbing the representation, so the question reduces to how cheap the changes of representation along edges are.

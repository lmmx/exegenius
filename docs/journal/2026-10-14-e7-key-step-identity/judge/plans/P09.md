# Plan P09

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A single deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, using fast address interchange and fast simultaneous butterfly layers inside a Gaussian-resampling, chirp and synthetic-transform reduction.
  - method: Reduce the product to a convolution evaluated through Gaussian-resampled, chirped synthetic transforms, make the two costly tape operations (address movement and butterfly layers) cheaper by a power of the logarithm using networks with a rank saving, and then assemble the algorithm and add up its costs.
  - motivation (explicit): Scanning $\Theta(n)$ bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so beating $n\log n$ requires cheaper address movement and cheaper arithmetic.
  - relies on: multitape-model, nlogn-multiplier, nlogn-conjecture, big-o, turing-machine-basics, binary-integers, schoolbook-and-karatsuba-multiplication
  - **S1** (show, page `rank-saving-recurrence`): If a network of $W$ wires has total edge rank $s<Wm$, a call at parameter $e=mf$ makes $s$ calls at parameter $f$ on streams of volume $V/W$, so the cost per unit volume obeys $F_k\le(s/W)F_{k-1}+O(1)$ and grows only like $e^{\tau}$ with $\tau<1$.
    - method: Unroll the recursion after dividing each level's cost by its volume: every level multiplies the width by $m$ but the cost only by $s/W<m$, and the resulting geometric sum is a power of the width.
    - motivation (explicit): A level multiplies the parameter by $m$ yet the per-volume cost only by $s/W$; because $s/W<m$ strictly, the sum over levels is $O(e^\tau)$ with $\tau<1$, a genuine power saving.
    - relies on: divide-and-conquer-recurrences, convergent-series-and-the-geometric-series, exponential-and-logarithm-functions, array-layout, big-o
    - **S1.1** (infer): The decisive property of the finite networks is that the total number $s$ of smaller calls satisfies $s<Wm$.
      - quotes line 167: "The decisive property is that the total number $s$ of smaller calls satisfies $s<Wm$."
    - **S1.2** (infer): A recursive call at parameter $mf$ uses $s$ calls at parameter $f$, each on a stream of volume $V/W$.
      - quotes line 170: "A recursive call at parameter $mf$ therefore uses $s$ calls at parameter $f$, each on a stream of volume $V/W$."
    - **S1.3** (infer): After dividing by the volume, passing from $f$ to $mf$ multiplies the recursive contribution to $F_k$ by only $s/W<m$.

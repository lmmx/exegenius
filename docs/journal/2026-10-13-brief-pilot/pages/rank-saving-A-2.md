The strict total rank deficit is the fact that, in each of two fixed networks, total edge cost is less than wires times label dimension, which the recursion needs to save a power. Write $s$ for the total edge cost, $W$ for the number of wires and $m$ for the dimension of the label space, so the deficit is $s<Wm$. The recursion saves a power only when each wire makes fewer than $m$ smaller calls on average.

The inequality is built on [Three-stage bank exchange network](bank-exchange-network.md). Edges join consecutive vertices on a wire. Let $h=100$ be the size of the ground set $[h]$, so $m=h^3$. Let $v=\binom h3$ be the number of three-element subsets of $[h]$. Let $N=v^3$ be the number of index triples $a$ of them.

The total cost $s$ is measured by the dimension of each edge's orthogonal residual, using [Nested subspace labels and orthogonal residuals](subspace-labels.md). In the bit network the cost is a rank: it equals that dimension, plus one on each of the $N$ edges leaving the sources of bank $X$.

Along each wire the signed changes telescope to sink dimension minus source dimension. The sources total $N$ and the sinks $Wm-N$ <cite data-source="paper">The source dimensions sum to $N$ and the sink dimensions to $Wm-N$</cite>, so the signed changes sum to $Wm-2N$. Each absolute change is its signed change plus twice its decrease (zero for an increase). Let $L$ be the total dimension lost on decreasing edges. So $s=Wm-2N+2L$ for the complex network and $s=Wm-N+2L$ for the bit network.

Only the central edges from time 3 to time 4 decrease, each losing $h$ dimensions. The construction runs $3v^2$ invocations of the three-element subset gadget. Let $c$ be the number of central wires per invocation, the wires that gather and scatter its values, so $c=h$ for the bit network and $c=h+1$ for the complex one. Hence $L=3v^2ch$ and $L/N=3ch/v$. The exact values are $L/N=100/539$ <cite data-source="paper">\frac{L_{\rm b}}{N}=\frac{100}{539}</cite> for the bit network and $101/539$ for the complex one. Both are below $1/2$, so the deficits $Wm-s=N-2L$ and $Wm-s=2(N-L)$ are positive.

The deficit is a tiny fraction of $Wm$ because $Wm$ is far larger than $N$: in the bit network $(Wm-s)/(Wm)\approx1.5\cdot10^{-11}$ <cite data-source="paper">\frac{339}{22587335000000}</cite>. Strict positivity is all the saving needs. The networks are fixed, so $s/W$ is a fixed number below $m$, and some fixed exponent $\tau<1$ has $s/W<m^\tau$.

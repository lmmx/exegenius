The strict total rank deficit is the inequality $s<Wm$, where $s$ is the sum of the edge ranks, $W$ is its number of wires and $m$ is the dimension of its label space. Recursing $k$ levels on size $n=m^k$ with $s/W$ smaller calls per wire costs $n^{\log_m(s/W)}$ per unit of data: a saving exactly when $s/W<m$.

The rank sum is counted over the edges of the [Three-stage bank exchange network](bank-exchange-network.md), which sends $(X_a,Y_a)$ to $(-Y_a,X_a)$. Here $h=100$ is the ground-set size, $v=\binom h3=161700$ the number of triples, and $N=v^3$ the number of input roles. Write $W_{\rm b},s_{\rm b}$ and $W_{\rm c},s_{\rm c}$ for the wire counts and rank sums of the two networks. Each vertex $p$ has a nondegenerate subspace $L_p$ (with $L_p\cap L_p^\perp=0$), and an edge $p\to q$ has matrix $M_q-M_p$, where $M_p=P_{L_p}$ is the orthogonal projection onto $L_p$. The rank count follows from [Nested subspace labels and orthogonal residuals](subspace-labels.md): adjacent labels are nested, and only central edges from time 3 to time 4 decrease. For nested $U\subset V$, $P_V-P_U$ projects onto $V\cap U^\perp$, so the edge has rank $\dim V-\dim U$.

The exception is the source of each input $X_a$, with matrix $-P_{U_a}$. That edge has rank one with no dimension change, so the $N$ inputs add $N$. Along each wire the changes telescope, and gate labels cancel, leaving sink minus source dimension: $(Wm-N)-N=Wm-2N$, as $X_a$ sources have dimension one and $Y_a$ sinks have $m-1$. Decreasing edges lose $L_{\rm b}$ in total, so the absolute sum is $Wm-2N+2L_{\rm b}$, giving
$$s_{\rm b}=W_{\rm b}m-N+2L_{\rm b}.$$
By [Frames: changing representation along the network](frames.md), a route applies only its endpoint operator, the sink matrix minus the source matrix. For $X_a$, with output $Y_a$ of sink label $U_a^\perp$, this is $P_{U_a^\perp}+P_{U_a}=I_m$; the other inputs give $I_m$ too, their source labels being $0$ and sinks the whole space.

The $3v^2$ invocations each have $c_{\rm b}=100$ central wires, each losing $h$, so the total loss on decreasing edges is $L_{\rm b}=3v^2hc_{\rm b}$; likewise $L_{\rm c}=3v^2hc_{\rm c}$ with $c_{\rm c}=101$ central wires for the complex network. By [Phase-frame (complex) network for the butterfly](phase-network.md), its residual dimensions sum to $s_{\rm c}=W_{\rm c}m-2N+2L_{\rm c}$.

Both are positive: $L_{\rm b}/N=3hc_{\rm b}/v\approx0.19$ and $L_{\rm c}/N\approx0.19$ are below $\frac12$. It is tiny against $W_{\rm b}m\approx4\cdot10^{10}N$, but positivity suffices.

Let $\eta_{\rm b}=(W_{\rm b}m-s_{\rm b})/(W_{\rm b}m)$ and $\eta_{\rm c}=(W_{\rm c}m-s_{\rm c})/(W_{\rm c}m)$ be the relative deficits, so $s/W=m(1-\eta)$. Here $\eta_{\rm b}\approx1.5\cdot10^{-11}$ <cite data-source="paper">\frac{339}{22587335000000}</cite> and $\eta_{\rm c}\approx3.7\cdot10^{-12}$ <cite data-source="paper">\frac{73}{19906842167500}</cite>, both above $20\cdot2^{-50}$. Take $\tau=1-2^{-50}$. Since $m=10^6<2^{20}$, $\ln m<20$, so $m^{\tau}=m\,e^{-2^{-50}\ln m}>m(1-20\cdot2^{-50})>m(1-\eta)$. Hence each wire makes fewer than $m^{\tau}$ smaller calls.

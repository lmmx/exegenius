The strict total rank deficit says that, in a fixed linear network, the total cost $s$ of its edges is less than the number of wires times the label dimension; this is what lets the main recursion save a power.

Let $W$ be the number of wires and $m$ the dimension of the label space. A wire carries one value through gates; its source and sink are its first and last vertices, and an edge joins consecutive vertices. Each edge changes representation ([Frames: changing representation along the network](frames.md)). An edge costs the number of smaller operations its change needs: its rational rank in the bit network, and the dimension of its orthogonal residual in the complex network. The total $s$ is summed over every edge of the [Three-stage bank exchange network](bank-exchange-network.md).

The sum $s$ is measured by [Nested subspace labels and orthogonal residuals](subspace-labels.md): on an edge with nested labels, the cost is the change in label dimension.

Along each wire the signed dimension changes telescope to sink minus source dimension. Let $N$ be the total dimension of the source labels. The sinks total $Wm-N$, so the signed changes sum to $Wm-2N$. Only decreasing edges, on the central wires, lose dimension; let $L$ be their total loss. Taking absolute values adds $2L$, so $s=Wm-2N+2L$ in the complex network. The bit network adds $N$, because the first edge from each nonzero source has rank one but no dimension change, giving $s=Wm-N+2L$.

Both deficits, $2N-2L$ and $N-2L$, are positive once $L<N/2$ <cite data-source="paper">We will obtain $L<N/2$.</cite> Few edges decrease, against $N$ source dimensions. The relative deficit is about $1.5\cdot10^{-11}$ for the bit network <cite data-source="paper">\frac{339}{22587335000000}</cite> and about $3.7\cdot10^{-12}$ for the complex one <cite data-source="paper">\frac{73}{19906842167500}</cite>.

Each level divides the size by $m$, and the $s$ calls spread over $W$ wires, so each wire carries on average $s/W$. Let $k$ be the recursion depth. If each level multiplies the cost by $s/W$ and adds $O(1)$, the cost is governed by $\sum_{j\le k}(s/W)^j$. Choose a rational exponent $\tau<1$ with $s/W<m^\tau$; this is possible exactly when $s<Wm$. Then the sum is $O(m^{k\tau})$, a power saving in the size $m^k$. The paper takes $\tau=1-2^{-50}$ <cite data-source="paper">\tau=\sigma=1-2^{-50}</cite>. Since $m<2^{20}$, $\ln m<20$, so $m^{1-2^{-50}}=m\exp(-2^{-50}\ln m)>m(1-20\cdot2^{-50})$. The loss $20\cdot2^{-50}$ is below the relative deficit, so $m^\tau>s/W$.

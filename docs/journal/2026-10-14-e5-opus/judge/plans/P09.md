# Plan P09

The plan of the argument for the main theorem, as a tree of steps.

- **S** (show, page `main-theorem`): A single deterministic fixed-tape Turing machine computes the exact product of two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: reduce multiplication through radix digits, a CRT address map, Gaussian resampling and a coefficient twist to convolution over $\mathbb C[y]/(y^r+1)$, accelerate its address moves and butterfly layers with two tape procedures derived from finite linear networks with a rank saving, recover the product exactly, and balance the parameters
  - motivation (explicit): Scanning $\Theta(n)$ bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so both data movement and butterfly arithmetic must each save a power of the logarithm.
  - relies on: n-log-n-conjecture, harvey-van-der-hoeven-multiplier, multitape-turing-machine, worst-case-running-time, deterministic-algorithm
  - **S0** (infer, page `radix-digit-convolution`): Splitting each $n$-bit input into radix-$2^b$ digits reduces the product to a convolution of short integer coefficient sequences followed by carry propagation.
    - relies on: cyclic-convolution, polynomial-multiplication-as-convolution, positional-radix-representation, binary-addition-with-carries
    - quotes line 76: "Splitting the inputs into radix digits reduces multiplication to"
  - **S1** (show, page `rank-saving`): There are two fixed finite linear networks, a bit network over $\mathbb F_2$ and a complex network over $\mathbb Z[i,1/2]$, each exchanging two banks with prescribed signs while restoring scratch values, whose frames cost $s<Wm$ smaller calls in total and whose endpoint operators are the address shear and the $C^{\otimes m}$ layer.
    - method: construct the scalar network, transfer it to arrays with frames, attach nested subspace labels, count residual dimensions, and read off the two interfaces
    - motivation (explicit): When values become arrays split among the $W$ roles, each edge costs smaller calls in proportion to its rank, so a total $s$ strictly below $Wm$ is what makes the recursion save a power.
    - relies on: linear-network, frames, matrix-rank, subspace-labels
    - **S1.1** (show, page `linear-network`): The three-stage scalar network sends $(X_a,Y_a)\mapsto(-Y_a,X_a)$ and restores every scratch wire, whatever its initial value.
      - method: build a forward invocation $y\gets y+x$ from copy, gather, scatter and side-injection gates with a restoring schedule, then compose three invocations like an XOR swap
      - motivation (recoverable): Three additions $y\gets y+x$, $x\gets x-y$, $y\gets y+x$ realize a signed exchange, so it suffices to make one addition step out of cheap gates that restore their scratch wires.
      - relies on: linear-combinations-and-linear-maps, matrix-rank
      - **S1.1.1** (infer, page `scratch-restoration`): A forward invocation's schedule first subtracts the effect of the old scratch values, then adds the source effect and finally restores the scratch values, so its net effect is independent of the initial scratch contents.
        - relies on: linear-network, linear-combinations-and-linear-maps
        - quotes line 707: "the next four introduce the source values and add their effect to the"
      - **S1.1.2** (infer, page `triple-intersection-construction`): Gathering through central wires gives coefficients depending on $|S\cap T|$, and the side wires cancel the unwanted ones, so each forward invocation computes $y\gets y+x$.
        - relies on: linear-network, scratch-restoration, binomial-coefficients, sets-cartesian-products-and-indicator-vectors, the-two-element-field
        - quotes line 759: "Thus both net maps are $y\gets y+x$."
      - **S1.1.3** (infer): Composing a forward, an inverse and a forward invocation over the three stages sends $(x,y)$ to $(-y,x)$.

    - **S1.2** (infer, page `frames`): Giving each vertex an invertible frame $D_v$ and each edge $D_vD_u^{-1}$, a pointwise gate commutes with its common frame, so the network on arrays implements $D_{\rm out}\mathsf S_\Omega D_{\rm in}^{-1}$.
      - relies on: linear-network, elementary-streams, invertible-matrices, pointwise-operations
      - quotes line 812: "Thus the common frame commutes with the pointwise gate, and

    - **S1.3** (show, page `subspace-labels`): Nested nondegenerate subspaces of the $m$-dimensional label space can be attached to all vertices so that the absolute label-dimension changes over all edges sum to $Wm-2N+2L$ with $L=Ich$.

      - relies on: bilinear-form, tensor-product, frames, triple-intersection-construction, linear-independence-basis-and-dimension
      - **S1.3.1** (infer): Under the form $x^{\mathsf T}(I-J/9)y$ over $\mathbb Q$, or the dot product over $\mathbb F_2$, every triple line is nondegenerate and neighboring triple lines are orthogonal.

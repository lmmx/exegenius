# Plan P06

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): One deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: Give the multiplication algorithm and show its output is exact, then total its cost stage by stage
  - motivation (explicit): Plain transforms already cost $\Theta(n\log n)$ because each of $\Theta(\log n)$ levels scans $\Theta(n)$ bits, so the proof needs components that save on both movement and arithmetic, and the exactness and the cost are best argued separately.
  - relies on: nlogn-conjecture, fixed-tape-model, big-o, worst-case-time-analysis-of-deterministic-algorithms
  - **S1** (show, page `multiplication-algorithm`): The algorithm, with digits placed on prime axes by the Chinese-remainder map, transformed by Gaussian resampling, chirp convolution and polynomial-ring convolution, multiplied pointwise, transformed back, rescaled, rounded and carry-propagated, outputs the exact $2n$-bit product.
    - method: Reduce the product to a cyclic convolution of digit lists and evaluate it with Fourier transforms, building from the fastest inner primitive (convolution over a polynomial ring) outward through the resampling, prime-axis and twist reductions, then bound the error so that rounding is exact
    - motivation (recoverable): Splitting into digits turns multiplication into convolution, and convolutions are cheap through transforms, but each transform has the wrong shape for the one below, so each reduction is added around the innermost primitive.
    - relies on: convolution, dft, binary-arithmetic

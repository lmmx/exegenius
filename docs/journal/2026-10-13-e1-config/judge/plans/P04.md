# Plan P04

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `sub-nlogn-multiplication`): A deterministic fixed-tape Turing machine multiplies $n$-bit integers in $T_A(n)=O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.
  - method: reduce the product to a digit convolution computed by synthetic transforms, replace the address rearrangement and butterfly layers inside those transforms by two faster recursive tape procedures, then assemble, round and bound the cost
  - motivation (explicit): The source starts from the reduction of multiplication to convolution and says that both movement and arithmetic need savings.
  - relies on: nlogn-conjecture, integer-mult-as-convolution, turing-machine-tapes, big-o-notation
  - **S1** (show): Two recursive tape procedures, an address-chunk interchange and a simultaneous butterfly layer, run faster than the naive costs of address rearrangement and Fourier layers by a power of the width.
    - method: build the elementary tape tools, derive a general recursive power saving from a fixed linear network, and instantiate it twice, once for bits and once for complex values
    - motivation (explicit): Scanning at each of the logarithmically many transform levels already costs $n\log n$, so both movement and arithmetic need savings.
    - relies on: turing-machine-tapes

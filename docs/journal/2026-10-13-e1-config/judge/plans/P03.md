The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): One deterministic multitape Turing machine multiplies $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ worst-case time with $\kappa=2^{-182}$, refuting the $n\log n$ optimality conjecture in this model.
  - method: Build two fast tape procedures (address interchange and simultaneous butterfly layers), run them inside synthetic transforms, reduce integer multiplication to such a convolution by resampling, chirps and a Chinese-remainder layout, then check precision and total up the time
  - motivation (explicit): Scanning $\Theta(n)$ stored bits at each of $\Theta(\log n)$ transform levels costs $\Theta(n\log n)$, so a power saving needs a faster way to move addresses and a faster way to do butterfly levels, both inside a multiplication reduction that still gives exact integers.

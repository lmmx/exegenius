# Plan P08

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A single deterministic multitape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ worst-case time with $\kappa=2^{-182}$, refuting the $n\log n$ optimality conjecture in this model.
  - method: Reduce the product to a cyclic convolution of radix digits, evaluate it with Fourier-type transforms whose data movement and butterfly layers are accelerated by two power-saving tape procedures, recover the exact integers by rounding and carries, and add up the costs.
  - motivation (explicit): Scanning the whole array at each of the $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so savings are needed in both data movement and arithmetic, which the two tape procedures supply.
  - relies on: mult-history, big-o, turing-machine, time-and-bit-complexity-of-turing-machine-computation
  - **S1** (show, page `address-interchange`): Two disjoint address chunks of $u$ bits each in an array of bit volume $V$ can be interchanged in $O(Vu^\tau)$ time for a fixed $\tau<1$, although the intermediate steps form XOR combinations of the data.
    - method: Realize the shear $H\leftarrow H+D$ by a fixed bit network of pointwise XOR gates with scratch wires and nested subspace labels, perform each edge by smaller interchanges on role streams, and solve the resulting recurrence.
    - motivation (explicit): The saving comes from a strict rank inequality: each recursive call spends fewer than $m$ units of cost per wire, so the cost per bit grows as a power of the width below one.
    - relies on: stream-scans, controlled-shifts, scratch-network, common-frame, subspace-labels, matrix-shear, rank-saving-recurrence, permutations-of-indices, bitwise-xor-and-hamming-weight

# Plan P09

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A single deterministic Turing machine with a fixed finite alphabet and a fixed finite number of one-dimensional tapes multiplies two $n$-bit integers exactly in time $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$.
  - method: Reduce the product to a cyclic convolution of radix-digit polynomials, evaluate it by Fourier transforms made cheap with Gaussian resampling, Bluestein chirps and synthetic polynomial transforms over $\mathbb C[y]/(y^r+1)$, and speed up the two bottlenecks of that evaluation, address rearrangement and butterfly layers, with two linear-network tape procedures that each save a power of the width; then verify exactness and total the costs.
  - motivation (explicit): A transform of $\Theta(n)$ stored bits with $\Theta(\log n)$ levels already costs $\Theta(n\log n)$ just to scan, so a power saving in the logarithmic factor needs a saving in the cost of moving data between layouts and in the cost of the butterfly arithmetic.
  - relies on: nlogn-conjecture, big-o, turing-machine-basics
  - **S1** (show, page `elementary-streams`): On a fixed number of one-dimensional tapes, interchanging the values of two digits, moving one digit, splitting an array on a digit and applying a pointwise map before merging, and splitting whole rows cyclically into $W$ streams each take $O(V)$ steps for an array of logical volume $V$.
    - method: Implement each operation by splitting the lexicographically stored array into streams indexed by the digits or row classes concerned, then scanning the aligned streams once.
    - motivation (recoverable): Splitting on a complete digit leaves streams with the same remaining address set in the same order, so one aligned scan applies any pointwise map; every counter reset is charged to the scan it controls, so nothing costs more than a fixed number of passes.
    - relies on: multitape-model, array-layout, positional-notation-in-any-radix-and-mixed-radix

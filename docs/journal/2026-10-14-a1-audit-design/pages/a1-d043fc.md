Fast interchange of address chunks is a procedure that runs on a [Fixed-tape machine model](fixed-tape-model.md) and swaps two disjoint, equal-width address fields of an array. The multiplication algorithm uses it so that tape cost per unit of stored data is sublinear in the field width.

Let $H$ and $D$ be the two fields, each of $u$ bits, and let $V$ be the stored volume, the number of data units in the array. Here $u$ and $V$ are rebound: on the dyadic and frame pages $u$ is a butterfly input or a tail vertex, and on the role-streams page $V$ is a padded bit volume. The exponent $\tau$ is a fixed number below 1 that sets the saving. The interchange costs $O(Vu^{\tau})$ <cite data-source="paper">Its cost is $O(Vu^\tau)$ for a fixed $\tau<1$</cite>.

The interchange reduces to three updates, and the middle one is the [Address shear](address-shear.md), which replaces $H$ by $H+D$ and leaves $D$ fixed. The updates are $D\leftarrow D-H$, $H\leftarrow H+D$, $D\leftarrow H-D$, where $\leftarrow$ is assignment: the field on its left takes the value on its right. The outer two take linear time.

The shear is carried by a bit network, a [Linear network](linear-network.md) whose wires each carry one bit. Each vertex holds a rational $\mu\times\mu$ matrix, where $\mu$ is its number of rows. An edge matrix, the head's matrix minus the tail's, of rank $a$ costs $a$ smaller calls, so $s$ is the sum of these ranks. Each smaller call acts on one of the $W$ [wire streams](role-streams.md), each of volume $V/W$. The bound needs $s<W\mu$ <cite data-source="paper">s<Wm</cite>, and the paper's explicit network has $W=W_{\rm b}$ and $s=s_{\rm b}$ <cite data-source="paper">supplies these conditions with $W=W_{\rm b}$ and $s=s_{\rm b}$</cite>.

The shear is computed by a [Rank-saving recursion](recursive-saving.md) on that network. Let $F_d$ be the time per unit volume of a width-$\mu^d$ interchange, where $d$ is the recursion depth. Width one ($d=0$) is a single-digit operation, so $F_0=O(1)$. At depth $d$, the $s$ smaller calls are interchanges of width $\mu^{d-1}$ on streams of volume $V/W$, which costs $(s/W)F_{d-1}$ per unit volume. Splitting, merging and gates are a fixed number of linear passes, $O(1)$ per unit volume. So $F_d\le\lambda F_{d-1}+O(1)$, with $\lambda=s/W$, and unrolling gives $F_d=O(1+\lambda+\cdots+\lambda^d)$.

The bound needs $\lambda<\mu^{\tau}$ for one fixed $\tau<1$, not merely $\lambda<\mu$. Write $\eta=(W\mu-s)/(W\mu)$, so $\lambda=\mu(1-\eta)$. For the explicit network the paper computes $\eta>20\cdot2^{-50}$ <cite data-source="paper">Both exact deficits displayed above are greater than $20\cdot2^{-50}$.</cite> Take $\tau=1-2^{-50}$. Since $\mu<2^{19}$, $\ln\mu<20$, so $\mu^{-2^{-50}}=\exp(-2^{-50}\ln\mu)>1-20\cdot2^{-50}>1-\eta$, and hence $\lambda<\mu^{\tau}$. If $\lambda\le1$ the sum is at most $d+1$. If $\lambda>1$ it is $O(\lambda^d)$, and $\lambda^d<\mu^{d\tau}$. As $\mu\ge2$, $F_d=O(\mu^{d\tau})$, which for width $u=\mu^d$ is $O(u^{\tau})$ per unit volume.

For any initial auxiliary values, a forward invocation from $X$ to $Y$ subtracts $x_S$ from $y_S$ and changes no other value <cite data-source="paper">a forward invocation changes $y_S$ to $y_S+x_S$ and leaves every other value unchanged</cite>. The shear is such an invocation, with $D$ as $X$ and $H$ as $Y$, so it is exact for any initial auxiliary contents. A forward, inverse, forward schedule of these invocations exchanges the two banks and returns every auxiliary wire to its starting value <cite data-source="paper">restores every auxiliary value</cite>.

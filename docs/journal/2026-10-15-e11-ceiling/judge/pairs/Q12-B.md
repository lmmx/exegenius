- **S0** (show, page `main-theorem`): A single deterministic multitape Turing machine multiplies $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, which refutes the $n\log n$ optimality conjecture of Schönhage and Strassen in this model.
  - method: Save a power of the logarithmic factor in both address movement and Fourier arithmetic: build two recursive tape procedures that exploit a strict rank deficit, use them to run synthetic transforms over $\mathbb C[y]/(y^r+1)$, embed the radix-digit convolution into that ring by a Chinese-remainder map, Gaussian resampling, a chirp convolution and a phase twist, recover the exact product by rounding and carries, and add up the cost table.
  - motivation (explicit): Scanning an array at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so a power saving needs savings in both movement and arithmetic.

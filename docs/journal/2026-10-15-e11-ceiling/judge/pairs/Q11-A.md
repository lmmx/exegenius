# Plan A of pair Q11

The plan of the argument for the main theorem, as a tree of steps. Its step ids are this plan's own.

- **S0** (show, page `main-theorem`): One deterministic Turing machine with a fixed finite alphabet and a fixed finite number of one-dimensional tapes computes the exact $2n$-bit product of any two $n$-bit integers in worst-case time $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$, so $n\log n$ is not the optimal order of multitape multiplication.
  - method: Reduce the product to a normalized cyclic convolution evaluated through Gaussian resampling, Bluestein chirps and synthetic polynomial transforms, make the two operations that cost a full pass per transform level — address interchange and butterfly layers — cheaper by a power of their parameter using finite linear networks with a rank deficit, then prove exact recovery and sum a cost table.
  - motivation (explicit): The established reduction already spends $\Theta(n)$ per transform level over $\Theta(\log n)$ levels, so beating $n\log n$ requires that both data movement and butterfly arithmetic in a level cost less than one full pass.
  - relies on: nlogn-conjecture, nlogn-multiplier, multitape-model, radix-digit-convolution, big-o, big-theta-big-omega-and-little-o-notation, turing-machine-basics
  - **S1** (show, page `rank-saving-recurrence`): If a fixed linear network with $W$ wires exchanges two banks, restores arbitrary scratch values, and has frames whose edge changes need $s<Wm$ smaller calls in total, then a call at parameter $mf$ costs $s$ calls at parameter $f$ on streams of volume $V/W$ plus $O(V)$, so the volume-normalized cost obeys $F_k\le(s/W)F_{k-1}+O(1)$ and is $O(m^{k\tau})$ for any $\tau<1$ with $s/W<m^\tau$.
    - method: Distribute whole rows cyclically among the $W$ wire roles, apply each gate pointwise, implement every change of frame on an edge by recursive calls of the same procedure, and divide cost by volume.
    - motivation (explicit): Row splitting gives every role stream exactly $1/W$ of the volume, and frames let each expensive change of representation be paid for by smaller instances of the same procedure, so the cost satisfies a self-similar recurrence whose growth factor is $s/W$.
    - relies on: gate-network-frames, array-layout, elementary-streams, subspace-labels, divide-and-conquer-recurrences, convergent-series-and-the-geometric-series, big-o
    - **S1.1** (infer): Rows (complete suffix blocks at a fixed prefix and row index) are distributed cyclically among the $W$ roles after padding the row count to a multiple of $W$, so all role streams share one address set and each holds $V/W$ bits.
      - relies on: array-layout, elementary-streams
      - quotes line 127: "All role streams have the same local address set and each contains $V/W$ bits."
    - **S1.2** (infer): With an invertible frame $D_v$ at each vertex and $D_vD_u^{-1}$ applied along each edge, a common frame commutes with every pointwise linear gate, so the intermediate frames cancel and a route from input role $w$ to output role $\rho(w)$ applies $D_{\mathrm{sink}(\rho(w))}D_{\mathrm{source}(w)}^{-1}$ with its scalar sign.
      - relies on: gate-network-frames, linear-algebra-basics
      - quotes line 142: "Thus the intermediate frames cancel"
    - **S1.3** (infer): The decisive property of the networks is that the total number $s$ of smaller calls needed on edges satisfies $s<Wm$.
      - relies on: subspace-labels
      - quotes line 167: "The decisive property is that the total number $s$ of smaller calls satisfies $s<Wm$."
    - **S1.4** (infer): Hence one call at parameter $mf$ uses $s$ calls at parameter $f$, each on a stream of volume $V/W$.
      - quotes line 170: "A recursive call at parameter $mf$ therefore uses $s$ calls at parameter $f$, each on a stream of volume $V/W$."
    - **S1.5** (infer): After dividing cost by volume, multiplying the parameter by $m$ multiplies the recursive contribution by $s/W<m$, which is the recurrence $F_k\le(s/W)F_{k-1}+O(1)$.
      - relies on: divide-and-conquer-recurrences

    - **S1.6** (infer, reported out of order): With $a=s/W<m^\tau$, unrolling gives the geometric sum $\sum_{j=0}^ka^j=O(m^{k\tau})$ (at most $k+1$ if $a\le1$, $O(a^k)$ if $a>1$), so $F_k=O(m^{k\tau})$, a power $\tau<1$ of the parameter $m^k$.
      - relies on: convergent-series-and-the-geometric-series

# Plan A of pair Q07

The plan of the argument for the main theorem, as a tree of steps. Its step ids are this plan's own.

- **S0** (show, page `multiplication-below-nlogn`): One deterministic Turing machine with a fixed finite alphabet and a fixed finite number of one-dimensional tapes outputs the exact $2n$-bit product of any two $n$-bit integers in worst-case time $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$, so no fixed multiplication machine in this model needs $\Omega(n\log n)$ time.
  - method: Supply linear-time stream operations, build two fast tape procedures from fixed linear networks with a rank deficit (address-chunk interchange and simultaneous butterfly layers), use them to compute convolutions over $\mathbb C[y]/(y^r+1)$ by synthetic transforms, express the prime-length source transforms through these by Gaussian resampling and Bluestein chirps with the permutations left in place, then assemble the algorithm, prove exact recovery and add up a cost table.
  - motivation (explicit): A fast-Fourier-transform route touches all $\Theta(n)$ stored bits at each of $\Theta(\log n)$ levels, so one plain pass per level already costs $n\log n$; going below requires both the address rearrangements and the butterfly arithmetic of the levels to cost less than a pass each, which is what the two tape procedures supply.
  - relies on: turing-machines, big-o, convolution-multiplication, hvdh-multiplier
  - **S1** (infer, page `multitape-streams`): On a machine with one fixed alphabet and a fixed number of tapes, where an array is a stream in lexicographic address order and $V$ counts its stored data bits, permuting the digit values at two radix-$q$ positions, moving one digit, splitting on a digit with a fixed pointwise map and merging back, and splitting whole rows cyclically into a fixed number $W$ of streams each cost $O(V)$, counters and head returns included.
    - relies on: turing-machines, big-o, cartesian-products-and-lexicographic-order, polynomial-time-and-computational-cost-on-tapes
    - quotes line 493: "Each of the following operations on an array of volume $V$ takes $O(V)$ steps on a fixed number of one-dimensional tapes"
  - **S2** (infer, page `controlled-shifts`): For a fixed prime $q$ and a target field $y\in[q^b]$ placed after its control fields, the update $y\mapsto y+a(\text{controls})\bmod q^b$ (a cyclic rotation of the target's blocks) and multiplication of $y$ by a fixed rational unit modulo $q^b$ cost $O(V)$ whenever the offset takes $b^{O(1)}$ time to prepare, since $b^{O(1)}=O(q^b)$ is absorbed by the fiber.
    - relies on: multitape-streams, modular-arithmetic-and-congruences, euclidean-algorithm-and-modular-inverses
    - quotes line 566: "costs $O(V)$ if the offset can be prepared in $b^{O(1)}$ time from the fixed number of control values"
  - **S3** (show): Two tape procedures save a fixed power: two disjoint $u$-bit address chunks of an array of stored volume $V$ can be interchanged in $O(Vu^\tau)$ time, and $H_0=\frac12\begin{pmatrix}1&1\\1&-1\end{pmatrix}$ can be applied to one selected bit in each of $D\le d$ equal-width chunks of an array of polynomial records in $O(Vd^{\lambda'})$ time, with $\tau=1-2^{-50}$ and $\lambda'=1-2^{-54}$.
    - method: Build two fixed linear networks that exchange two banks of wires while restoring all scratch wires, attach nested subspace labels whose edge residuals total $s<Wm$, read each edge's change of label as one smaller call of the same procedure per residual dimension on a $1/W$ share of the rows, and solve the resulting volume-normalized recurrences.

    - relies on: recurrences-and-induction, big-o, multitape-streams

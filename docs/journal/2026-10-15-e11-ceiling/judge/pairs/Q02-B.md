- **S0** (show, page `main-theorem`): There is one deterministic Turing machine with a fixed finite alphabet and a fixed finite number of one-dimensional tapes that, for every $n\ge1$, outputs $\operatorname{bin}_{2n}(\operatorname{val}(x)\operatorname{val}(y))$ on input $x\#y$ with $x,y\in\{0,1\}^n$ in worst-case time $T_A(n)=O(n(\lg n)^{1-\kappa})$, $\kappa=2^{-182}$, which disproves the Schönhage–Strassen $n\log n$ optimality conjecture in this model.
  - method: Build two tape procedures that beat one pass per level by a power, an address-chunk interchange and a simultaneous butterfly layer, from fixed linear networks with a rank saving; use them to evaluate the Harvey–van der Hoeven reduction of the digit convolution to power-of-two synthetic transforms; and bound every cost divided by $V=Tp$ by the power $p^{1-2\kappa}$.
  - motivation (explicit): In the O(n log n) approach every one of the Θ(log n) transform levels scans all Θ(n) stored bits, so going below n log n needs cheaper data movement and cheaper butterfly arithmetic per level, which the two tape procedures supply.
  - relies on: n-log-n-barrier, multiplication-algorithm, cost-accounting, multitape-turing-machine, big-o-notation

    - method: Unfold what an eventual lower bound for every fixed machine means and negate it with one machine.
    - motivation (recoverable): The conjecture is a claim about every fixed machine, so a single machine whose cost divided by $n\lg n$ tends to zero refutes it.

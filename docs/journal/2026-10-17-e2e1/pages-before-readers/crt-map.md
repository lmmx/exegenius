Let $d$ be the number of prime cyclic axes (unlike on the cyclic-convolution page, no coefficient axis is counted), $i$ index them, and $s_1,\dots,s_d$ be pairwise coprime axis lengths (these $s_i$ are unrelated to the chirp page's multipliers). The Chinese-remainder address map rewrites a cyclic convolution of length $S=s_1\cdots s_d$ as a $d$-axis one, moving the data on tape by controlled shifts and axis reorderings only. The split is due to Agarwal and Cooley <cite data-source="paper">Agarwal and Cooley used the Chinese remainder theorem to convert one cyclic convolution into multidimensional cyclic convolution</cite>; the exponents below make the movement triangular.

Let $P_i=\prod_{j<i}s_j$ be the product of the lengths $s_j$ of the axes $j$ before axis $i$, and $\mu_i=P_i^{-1}\pmod{s_i}$. Define $\Phi:\mathbb C[x]/(x^S-1)\to\mathbb C[x_1,\dots,x_d]/(x_i^{s_i}-1)$ by $x\mapsto\prod_i x_i^{\mu_i}$, with one variable $x_i$ per axis. Since $s_i\mid S$, each $x_i^{\mu_iS}=1$, so $\Phi$ respects $x^S=1$ and defines an algebra map.

The letter $k$ changes meaning here: it is a single coefficient index, an exponent of $x$, not an output index tuple as on the multidimensional-transform page. Then $\Phi(x^k)=1$ exactly when $s_i\mid\mu_ik$ for every $i$; as $\mu_i$ is a unit modulo $s_i$ this means $s_i\mid k$ for every $i$, and as the $s_i$ are pairwise coprime, $S\mid k$. So the image of $x$ has order $S$ and its $S$ powers are distinct. The target has exactly $S$ monomials, so the powers run through all of them exactly once. Hence $\Phi$ is an isomorphism and preserves [Cyclic convolution](convolution.md). This prepares [Multidimensional transforms](multidim-transform.md).

Write $k=\sum_ja_jP_j$ in mixed radix, with digits $0\le a_j<s_j$. The axis-$i$ coordinate $b_i$ of $\Phi(x^k)$ is $\mu_ik\bmod s_i$. Terms with $j>i$ vanish modulo $s_i$, since $s_i$ divides $P_j$, and $\mu_iP_i\equiv1$ modulo $s_i$. Hence $b_i=a_i+\mu_i\sum_{j<i}a_jP_j\pmod{s_i}$, which depends only on lower-index digits.

Coefficients are stored in the order of $k$, which is lexicographic in $(a_d,\dots,a_1)$ with $a_d$ outermost. Pad axis $i$ with zero records to a length $t_i$, a power of two with $r/2\le t_i\le r$, where $r=2^\ell$ is the record length, so $\ell$ is the number of address bits of an axis of length $r$. One nested scan of the box $\prod_i[0,t_i)$ copies the next coefficient where every $a_i<s_i$ and writes zero elsewhere. Let $T=\prod_it_i$ be the number of padded records, each of $O(p)$ bits.

The scan keeps one binary counter per axis, so the counters have $\log_2T$ bits in total. The parameters of [Parameter and prime-length choice](parameter-choice.md) give $T<2^p$ <cite data-source="paper">$t_i\leq r\leq T<8n/b<2^{6b}=2^p$</cite>, so the counters and stored bounds $s_i$ have $O(p)$ bits. At each of the $T$ addresses, updating counters, testing validity and copying a record take $O(p)$ steps, so a scan costs $O(Tp)$.

In this order the controls $a_j$, $j<i$, follow the target $a_i$. Reversing the axis order to $(a_1,\dots,a_d)$ puts the controls first. Update the targets for $i=d,d-1,\dots,1$, so no lower-index control has yet changed when axis $i$ is updated and the offset is computed from the original digits. Each update is a prefix-controlled cyclic shift of the valid interval $[0,s_i)$ and the identity on $[s_i,t_i)$, so zero padding stays zero. The map is implemented by these shifts, each of linear cost by [Controlled shifts and rational scalings](controlled-shifts.md). Computing the offsets, for at most $T/t_i$ prefixes, is negligible next to $Tp$ because <cite data-source="paper">$t_i\ge r/2$ and $r$ exceeds every fixed power of $p$</cite>.

Let $V=Tp$ be the stream volume and $\tau<1$ a fixed exponent. A [chunk interchange](address-interchange.md) exchanges two equal-width axes in $O(V\ell^\tau)$ time <cite data-source="paper">equal width $L$ in $O(VL^\tau)$ time</cite>. Axes have $\ell$ or $\ell-1$ address bits; for unequal widths, move the longer axis's leading bit aside, swap the equal-width remainder, and restore the bit, adding a fixed number of linear passes. Reversing $d$ axes takes $O(d^2)$ such moves, so reordering dominates the $O(dTp)$ shifts and $O(Tp)$ scans. The inverse subtracts the same offsets for $i=1,\dots,d$, then reorders back and deletes the padding. The map, its inverse and the padding cost $O(Tp\,d^2(1+\ell^\tau))$ <cite data-source="paper">O\bigl(Tp\,d^2(1+\ell^\tau)\bigr).</cite>

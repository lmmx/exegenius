A controlled shift adds to one field of each record an offset computed from earlier fields, and a rational scaling multiplies that field by a fixed unit; both run in time linear in the array volume.

Fix a prime $q$, the radix of the stored digits (on this page $q$ is a prime, not a sequence length). Let $b\ge1$ be the number of base-$q$ digits of a field (this $b$ is not the lowest bit of an index). Put $Q=q^b$, the number of values a field can take, and let $V$ be the array volume, the number of stored base-$q$ digits. The target field has value $y\in\{0,\dots,Q-1\}$ (here $y$ is a field value, not the ring variable) and follows a fixed number of control fields. The update is
$$y\longmapsto y+a \pmod Q,$$
where $a$ is the offset, prepared from the control values (here $a$ is not a bank index). It costs $O(V)$ if each control used in the offset has $O(b)$ digits and the offset can be prepared in $b^{O(1)}$ time from the fixed number of control values <cite data-source="paper">costs $O(V)$ if the offset can be prepared in $b^{O(1)}$ time from the fixed number of control values</cite>. A fixed rational linear combination of the controls, reduced modulo $Q$, qualifies.

**Why a shift is linear.** Because the target follows its controls, fixing everything before the target fixes $a$. Let $B$ be the number of digits that follow the target (here $B$ is not the number of entries per row). The target and its suffix form $Q$ consecutive blocks of $B$ digits, and adding $a$ modulo $Q$ rotates these blocks. Split them at $Q-a$, append the two pieces to two tapes, then merge by reading the second piece before the first. Each update is carried out by splitting into streams and merging back, as in [Elementary stream operations](stream-ops.md). Reading the $O(b)$-digit controls and computing $a$ takes $b^{O(1)}=O(Q)$ time per prefix, absorbed by the $QB\ge Q$ digits of the blocks.

**Scaling.** Let $c$ be a fixed positive integer prime to $q$ (not the machine constant). The map $y\mapsto cy \pmod Q$ sends the block at position $y$ to position $y'=cy-jQ$, where $j=\lfloor cy/Q\rfloor$ counts how often $cy$ wraps past $Q$ (this $j$ is not a wrapped position). So it consists of $c$ increasing pieces, one per $j$. Split the blocks into $c$ streams by $j$; each stream is in increasing order of $y$, hence of $y'$. Then produce output positions $y'=0,\dots,Q-1$ in order, each time taking the next block of the stream $j$ with $y'+jQ\equiv 0\pmod c$, where $y=(y'+jQ)/c$. This $j$ is unique since $\gcd(Q,c)=1$.

**Inverse scaling.** Multiplication by $c^{-1}$ must put at position $y$ the block from position $y'=cy-jQ$, with $j=\lfloor cy/Q\rfloor$. The positions $y$ sharing one $j$ form a consecutive range, and their sources $y'$ increase in steps of $c$ through a single class of residues modulo $c$, namely $y'\equiv -jQ$. So the roles of split and merge are exchanged: split the input into $c$ streams by the residue of its position modulo $c$, then write the output range by range, filling range $j$ from the stream of class $-jQ \bmod c$. Different $j$ give different classes because $\gcd(Q,c)=1$, so each stream is consumed by exactly one range, in order. This is again one split and one merge <cite data-source="paper">Reversing the roles of this split and merge implements multiplication by $c^{-1}$ modulo $Q$.</cite>

**Negation and units.** Negation sends block $y$ to block $Q-y$: it leaves block $0$ fixed and reverses the other $Q-1$ blocks <cite data-source="paper">Negation leaves the block at zero fixed and reverses the order of the other $Q-1$ blocks.</cite> Push them onto a temporary tape and pop them, then reverse each popped block again on a second tape to restore its digits.

A rational unit is a signed ratio $c/c'$ of positive integers $c,c'$ both prime to $q$. Multiply by $c$, multiply by the inverse of $c'$, and negate if the sign is negative: a fixed number of $O(V)$ passes, so the unit and its inverse cost $O(V)$.

# Plan P04

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): One deterministic multitape Turing machine with a fixed finite alphabet and a fixed finite number of tapes multiplies two $n$-bit integers exactly in worst-case time $T_A(n)=O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$.
  - method: Build two tape procedures that beat one scan per level (an address-chunk interchange and a simultaneous butterfly layer) from fixed linear networks with a strict rank deficit; use them inside the Harvey–van der Hoeven reduction of multiplication to convolution (radix digits, Chinese-remainder axes, Gaussian resampling with chirps, a phase twist to $\mathbb C[y]/(y^r+1)$); recover the exact product; and divide every cost by $V=Tp=\Theta(n)$.
  - motivation (explicit): The transform calculation consists of address rearrangements, signed shifts and butterflies, and a single scan per transform level already costs $\Theta(n\log n)$; so both data movement and butterfly arithmetic must be done faster than one scan per level.
  - relies on: integer-multiplication-conjecture, multiplication-algorithm, time-accounting, multitape-tm, big-o
  - **S1** (infer, page `integer-multiplication-conjecture`): Schönhage and Strassen proposed $n\log n$ as the optimal multitape order and Harvey and van der Hoeven reached $O(n\log n)$, so a bound $O(n(\lg n)^{1-\kappa})$ gives $T_A(n)/(n\lg n)\to0$ and refutes an eventual $\Omega(n\log n)$ lower bound for every fixed machine.
    - relies on: big-o, multitape-tm, big-omega-theta-and-little-o-notation
    - quotes line 41: "proposed $n\log n$ as the optimal order of growth"

# Plan P05

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): There is one deterministic Turing machine with a fixed finite alphabet and a fixed finite number of one-dimensional tapes that returns the exact $2n$-bit product of any two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ worst-case time with $\kappa=2^{-182}$, disproving the $n\log n$ optimality conjecture of Schönhage and Strassen in this model.
  - method: Observe that one machine with a power saving refutes the conjecture; build two tape procedures, a fast interchange of address chunks and a simultaneous butterfly layer, whose recursive costs carry a power saving from linear networks with a rank deficit; then place them inside Harvey and van der Hoeven's reduction of multiplication to synthetic polynomial transforms, accounting for every change of representation, precision and cost.
  - motivation (explicit): The transform route already spends $\Theta(n\log n)$ just scanning $\Theta(n)$ stored bits at each of $\Theta(\log n)$ levels, so beating $n\log n$ needs savings in both data movement and arithmetic, which the two tape procedures supply.
  - relies on: fixed-tape-model, nlogn-conjecture, nlogn-multiplier, big-o, logarithms-and-exponentials, determinism-and-exact-versus-approximate-computation
  - **S1** (infer): Refuting an eventual lower bound $T_A(n)\ge c_An\lg n$ for every machine needs one machine with $\liminf_{n\to\infty}T_A(n)/(n\lg n)=0$, and a power saving in the logarithm gives limit zero through all input lengths.
    - relies on: nlogn-conjecture, asymptotic-notation-beyond-big-o
    - quotes line 384: "Its negation requires one machine satisfying $\liminf_{n\to\infty}T_A(n)/(n\lg n)=0$. The power saving proved here gives a limit of zero through all input lengths, which is a stronger conclusion."
  - **S2** (show): Two fixed-tape procedures run with a power saving: interchanging two disjoint $u$-bit address chunks of an array of volume $V$ costs $O(Vu^\tau)$, and applying the normalized butterfly at one selected bit of each of at most $d$ address chunks of polynomial records costs $O(Vd^{\lambda'})$, with fixed $\tau,\lambda'<1$.
    - method: Derive each procedure from its own fixed linear network that exchanges two banks of values and restores every scratch value: split array rows cyclically among the $W$ wire roles, give each vertex a frame so that the endpoint effect is the wanted operator and each edge is a few smaller calls of the same procedure, and solve the resulting volume-normalized recurrence.
    - motivation (explicit): With rows split among $W$ roles, a call at parameter $mf$ makes $s$ calls at parameter $f$ on streams of volume $V/W$, so per unit volume the cost grows by $s/W$ when the parameter grows by $m$; a network with $s<Wm$ gives an exponent below one.
    - relies on: fixed-tape-model, array-order, big-o

    - **S2.2** (show, page `controlled-shifts`): When a target field $y\in[Q]$, $Q=q^b$, follows its control fields, the update $y\mapsto y+a(\text{controls})\bmod Q$, a cyclic shift of whole blocks, and multiplication of $y$ by a fixed rational unit each cost $O(V)$, provided the offset is prepared in $b^{O(1)}$ time.

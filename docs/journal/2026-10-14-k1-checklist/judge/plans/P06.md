- **S0** (show, page `main-theorem`): One deterministic multitape Turing machine with a fixed alphabet and a fixed number of tapes multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, so no eventual $\Omega(n\log n)$ lower bound holds in this model.

  - motivation (explicit): Merely scanning $\Theta(n)$ stored bits at each of $\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$, so beating $n\log n$ requires savings in both data movement and butterfly arithmetic.

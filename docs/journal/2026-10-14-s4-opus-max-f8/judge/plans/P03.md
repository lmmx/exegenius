# Plan P03

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): One deterministic Turing machine with a fixed finite alphabet and a fixed number of one-dimensional tapes outputs $\operatorname{bin}_{2n}(\operatorname{val}(x)\operatorname{val}(y))$ for all $n$-bit inputs $x,y$ in worst-case time $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$, so the conjectured $n\log n$ lower bound fails in this model.
  - method: Reduce the product to normalized convolutions over $\mathbb C[y]/(y^r+1)$ computed by synthetic polynomial transforms, accelerate the transforms' address interchanges and butterfly layers by two recursive network procedures whose normalized cost grows by $s/W<m$ per level, assemble an exact multiplier, and sum the costs divided by the volume $V=\Theta(n)$.
  - motivation (explicit): A transform method that scans all $\Theta(n)$ stored bits once per level already pays $\Theta(n\log n)$ over $\Theta(\log n)$ levels, so going below $n\log n$ requires making both the data movement and the arithmetic of a level cheaper than a scan.
  - relies on: n-log-n-barrier, multitape-turing-machine, big-o-notation, asymptotic-notation-beyond-big-o, binary-numerals-and-bit-strings
  - **S0.1** (infer): An eventual lower bound $T_A(n)\ge c_An\lg n$ for every fixed multiplication machine is refuted by one machine with $\liminf_{n\to\infty}T_A(n)/(n\lg n)=0$, and a bound $O(n(\lg n)^{1-\kappa})$ even gives limit zero.
    - relies on: n-log-n-barrier, asymptotic-notation-beyond-big-o
    - quotes line 384: "Its negation requires one machine satisfying $\liminf_{n\to\infty}T_A(n)/(n\lg n)=0$."

    - method: Prove the bound for chunks of $e=m^k$ radix-$q$ digits preceded by a row field of length divisible by $W^k$, by running the bit network recursively; then supply rows from a few high digits, split a general width into base-$m$ power-width pieces, and pad binary ranges to powers of $q$.
    - motivation (explicit): Each edge of the network costs as many smaller interchanges as its matrix rank, and the ranks sum to less than wires times $m$, so a recursion on the chunk width saves a power of the width.

# Plan P04

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A deterministic multitape Turing machine multiplies two $n$-bit integers exactly in time $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$.
  - method: speed up the tape operations of the transform-based multiplication by a power of the logarithm, then assemble the multiplication
  - motivation (explicit): The O(n log n) bound is limited by scanning n bits at each of log n transform levels, so a power saving needs cheaper address rearrangement and butterfly layers, which must then be placed inside the exact multiplication.
  - relies on: multitape-tm, big-o, nlogn-conjecture
  - **S1** (show): Two tape procedures cost $O(Vu^\tau)$ for interchanging address fields of $u$ bits and $O(Vd^{\lambda'})$ for a butterfly layer on $d$ chunks, with $\tau,\lambda'<1$, on bit volume $V$.
    - method: build fixed linear exchange networks with frames and subspaces, then recurse so that the number of smaller calls gives a power saving
    - motivation (explicit): Plain scans at each transform level cost n log n; the networks let each procedure be done by smaller calls on shorter streams with strictly less total work than naive passes.
    - **S1.1** (infer, page `linear-network-frames`): A fixed linear network exchanging two banks of values and restoring auxiliary values acts pointwise on arrays via invertible frame operators that cancel along routes.
      - relies on: tape-streams, vectors-matrices-and-linear-maps
      - quotes line 131: "The representation of a role's array may change along the network."
    - **S1.2** (infer, page `subset-network`): Networks from three-element subsets with nested subspaces at gates and terminals have total number $s$ of smaller calls less than $Wm$.
      - relies on: linear-network-frames, subspaces-dimension-and-rank
      - quotes line 159: "The finite construction in Section~\ref{sec:finite-networks} attaches"
    - **S1.3** (infer, page `recursive-saving`): Recursion with $s$ calls at parameter $f$ on volume $V/W$, with $s/W<m$, yields a power saving over naive passes.
      - relies on: subset-network, divide-and-conquer-recurrences
      - quotes line 170: "A recursive call at parameter $mf$ therefore uses $s$ calls at parameter"
    - **S1.4** (infer, page `address-interchange`): Interchanging two disjoint address fields of $u$ bits on volume $V$ takes time $O(Vu^\tau)$ with exact final permutation.
      - relies on: recursive-saving, tape-streams, binary-representation-and-bit-operations, permutations-and-bijections, multidimensional-arrays-and-index-tuples
      - quotes line 1350: "We use the bit network to interchange two equal address chunks on tape."
    - **S1.5** (infer, page `simultaneous-butterfly`): Applying $H_0(u,v)=((u+v)/2,(u-v)/2)$ on the same bit in up to $d$ address chunks takes time $O(Vd^{\lambda'})$ using exact Gaussian dyadics and one final truncation.

    - method: chain reductions from the product to convolution over the polynomial ring, then recover the exact integer and sum the cost table
    - motivation (recoverable): Only the ring convolution can use the fast tape procedures, so the product must be turned into it exactly; each step changes the problem or representation and its error and cost must be accounted for.
    - relies on: nlogn-conjecture, dft, tensor-transform, tape-streams, poly-ring

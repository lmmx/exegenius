# Plan P12

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-multiplication`): A deterministic multitape Turing machine multiplies $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time, $\kappa=2^{-182}$.
  - method: reduce the product through a chain of changes of representation down to convolution over a polynomial ring, speed up the transforms with two tape procedures, then recover the exact integer
  - motivation (recoverable): Each reduction turns the problem into one for which the next fast tool applies, and only the transform data movement and arithmetic need to beat n log n; exactness is restored at the end by known rescalings and rounding.
  - relies on: nlogn-conjecture, turing-machine, big-o, convolution, fourier-transform, logarithms-and-floor-ceiling, time-and-space-on-tapes
  - **S1** (infer, page `radix-digit-reduction`): Splitting the $n$-bit inputs into short radix digits reduces the product to a convolution of digit lists, followed by carry propagation.
    - relies on: convolution, radix-base-b-representation, schoolbook-multiplication-and-carries, polynomials
    - quotes line 76: "Splitting the inputs into radix digits reduces multiplication to"
  - **S2** (show): Address rearrangement of a stored array of volume $V$ and the butterfly layers of the transforms can each be done in time $O(V f^{\theta})$ for a fixed $\theta<1$ in the parameter $f$, instead of linear in $f$.
    - method: build each procedure from a fixed linear network applied on role arrays under frames, then use a recursive call that makes $s<Wm$ smaller calls to get a power saving
    - motivation (explicit): Plain scans cost n log n already, so a saving in the per-level cost is needed in both data movement and arithmetic.
    - relies on: recursion-and-recurrences
    - **S2.0** (infer, page `elementary-streams`): Permuting, moving, splitting and merging digit streams on a fixed number of tapes takes $O(V)$ steps for volume $V$.

      - motivation (recoverable): A shear costs only as much as the rank of its matrix, and it is the endpoint operator of the network, so shears are the cheap pieces from which an exact permutation can be assembled.

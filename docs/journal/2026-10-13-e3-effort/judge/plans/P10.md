# Plan P10

The plan of the argument for the main theorem, as a tree of steps.

- **S0** (show, page `main-theorem`): A single deterministic multitape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time, with $\kappa=2^{-182}$.

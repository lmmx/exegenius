The three-element subset intersection construction is a fixed network of gather, scatter and auxiliary wires that makes few enough smaller calls for the recursion to save a power. It is built inside a [Finite linear network with roles and frames](linear-network-roles.md).

Let $[h]=\{1,\dots,h\}$ be the ground set, with $h=100$, as in Alon's construction that the paper specializes (the letter $h$ changes meaning here). For a three-element subset $T$ of $[h]$, called a triple, $t_T$ is its indicator vector, and $\mathcal T$ is the set of all triples. Call two triples $T,S$ *neighbors* when $|T\cap S|=1$. Each triple $T$ carries a value $g_T$.

**Coefficients.** Over $\mathbb F_2$, gather puts the sum of the $g_T$ with $T\ni e$ on a central wire $C_e$ for each element $e$, and scatter adds $\sum_{e\in S}C_e$ to the target $S$. So $g_T$ reaches $S$ with coefficient $|S\cap T|$ mod $2$. A copy of $g_T$ on an auxiliary wire $A_{ST}$ for each neighbor pair, injected back into $S$ and never cleared afterwards, adds $1$ exactly when $|S\cap T|=1$. The net coefficient $|S\cap T|+[|S\cap T|=1]$ mod $2$ is $0$ for sizes $0,1,2$ and $1$ for $T=S$, so only $g_S$ remains.

**Labels.** Over $\mathbb Q$, the bilinear form with matrix $I-J/9$, where $J$ is the all-one matrix (the letter $J$ changes meaning here), gives $\langle t_T,t_S\rangle=|T\cap S|-1$; neighbors are orthogonal. Let $\mathcal F=(\mathbb Q^h)^{\otimes 3}$, a space built from the [Tensor product of vector spaces](tensor-product-of-vector-spaces.md) of three copies of $\mathbb Q^h$, of dimension $D=h^3$ (the label space dimension). A label $U$ is a nondegenerate subspace of $\mathcal F$. For an index $\iota=(T_1,T_2,T_3)\in\mathcal T^3$, the label $U_\iota$ is the line spanned by $t_{T_1}\otimes t_{T_2}\otimes t_{T_3}$. Along a side wire, a label containing $t_T$ may grow to $t_S^\perp$, since $t_T\perp t_S$, adding $h-2$ dimensions.

**Counting.** Give each gate or sink with label $U$ the projection $P_U$ onto $U$ along $U^\perp$, and the source of index $\iota$ the matrix $-P_{U_\iota}$. If $U\subseteq V$, then $P_V-P_U$ is the identity on $V\cap U^\perp$ and zero on $U\oplus V^\perp$, so its rank is $\dim V-\dim U$. Let $s$, the total rank over all edges, change meaning here. Each unit of rank costs one smaller call. <cite data-source="paper">An edge matrix of rank $a$ will require $a$ smaller interchanges.</cite>

Let $N=\binom h3^3$, the number of indices $\iota$ (the letter $N$ changes meaning here). Signed label changes telescope along each wire, and gate labels cancel. Sources have dimension $1$, summing to $N$; sinks have dimension $D$, except the $N$ sinks that receive the sources, which have label $U_\iota^\perp$ and dimension $D-1$. So the signed total is $WD-2N$.

Let $L$ be the total dimension lost on decreasing edges (the letter $L$ changes meaning here). Each of the $3\binom h3^2$ invocations has $h$ central wires, each losing $h$ on a decreasing edge, so $L=3\binom h3^2h^2$. Absolute values add $2L$. The first edge out of each source has matrix $2P_{U_\iota}$, rank one, with no label change; these $N$ ranks give
$$s=WD-2N+2L+N=WD-N+2L$$

Now $L/N=3h^2/\binom h3=100/539$ <cite data-source="paper">The loss ratios have the exact values</cite>, so $2L<N$ and $s<WD$. Here $\mathcal F$ is the fixed space, so the paper's dimension $m$ is $D$. The paper's decisive property is a bound on the number of smaller calls, <cite data-source="paper">smaller calls satisfies $s<Wm$</cite>.

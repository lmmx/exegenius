Fixed-point disk-grid arithmetic is the number format and rounding rule that lets the algorithm do complex transforms with exact integer operations on tapes, rounding only once per layer, with a controlled error.

**Disk grid.** Let $p$ be the precision, the number of fractional bits kept. A complex coefficient $z$ is stored as $2^{-p}(a+ib)$ with integers $a,b$, each written as a signed $w$-bit two's-complement word, where $w$ is the number of bits in a word. The coefficient lies in the unit disk $|z|\le 1$, so $|a|,|b|\le 2^p$, and $w\ge p+2$ suffices to hold even $-1$ and $1$. An array whose coefficients all lie in the unit disk is a disk array, with norm at most one <cite data-source="paper">A disk array has norm at most one.</cite>. If its parts are also multiples of $2^{-p}$, it is a $p$-bit grid array.

**Exact intermediates.** The transforms in the following pages are built from additions, halvings and multiplications by $\pm1,\pm i$. Starting from grid values, these produce Gaussian dyadics: numbers $(a+ib)/2^m$ with integers $a,b$ and $m\ge0$ <cite data-source="paper">Intermediate values are exact Gaussian dyadics,</cite>. They are computed exactly by appending fractional zero bits and a few guard bits, extra high and low bits that prevent overflow and loss. The width stays $O(p)$, and no rounding error accumulates inside a layer.

**One truncation.** After a whole layer is evaluated exactly, $Q_p$ truncates the real and imaginary part of every coefficient toward zero to the grid $2^{-p}\mathbb Z$. Each part moves by less than $2^{-p}$ and its absolute value does not grow. Hence each coefficient's error has modulus less than $\sqrt2\,2^{-p}$, and the maximum modulus does not increase <cite data-source="paper">For any array, let $Q_p$ truncate each real and imaginary coefficient part toward zero to this grid.</cite>:
$$\|Q_p z-z\|_\infty<\sqrt2\,2^{-p},\qquad \|Q_p z\|_\infty\le\|z\|_\infty.$$
Truncation is a shift of the absolute numerator followed by restoring the sign, so it costs a linear scan.

**Why this shape.** A contractive layer, one that maps disk arrays to disk arrays, followed by $Q_p$ gives a disk grid array again. The error bound is per layer and per coefficient, so later pages add up a fixed number of such terms. Because truncation is applied once per layer, not after each addition, the error does not grow with the number of internal operations.

For example, with $p=2$ and exact value $z=0.8-0.6i$, $Q_2$ keeps $0.75-0.5i$. Both parts shrink in size and the error has modulus about $0.25$, below $\sqrt2/4\approx0.35$.

A controlled cyclic shift adds to one address field of a tape array an offset computed from earlier fields, in linear time; the algorithm builds the lower-triangular address changes behind its fast address rearrangements from these shifts and related scalings.

Here the letter $y$ changes meaning: it is the value of the *target*, one address field of the array. It ranges over the $Q=q^b$ values $[Q]=\{0,\dots,Q-1\}$, where $q$ is a fixed prime and $b$ is the target's number of radix-$q$ digits. Earlier fields, its *controls*, determine an offset $a\in[Q]$. The update

$$y\longmapsto y+a(\text{controls})\pmod Q$$

shifts every entry's target coordinate by $a$. Let $V$ be the number of stored data bits. The update costs $O(V)$ whenever the offset takes $b^{O(1)}$ time to compute <cite data-source="paper">costs $O(V)$ if the offset can be prepared in $b^{O(1)}$ time from the fixed number of control values</cite>, as a fixed rational linear combination of the controls does. Other fields between controls and target, and a suffix, are allowed <cite data-source="paper">Arbitrarily long intervening spectator fields and suffix records are permitted.</cite>

In lexicographic storage order, fixing all fields before the target leaves a *fiber*: $Q$ consecutive blocks, block $y$ holding the suffix entries with target value $y$. The controls precede the target, so they are constant on a fiber and its blocks simply rotate.

Split each fiber's blocks at $Q-a$ onto two tapes, fiber after fiber; then merge, reading each fiber's second piece before its first. With $Q=8$ and $a=3$, blocks $0,\dots,7$ become $5,6,7,0,\dots,4$, so block $5$ lands at $5+3\equiv0$. Recomputing the offset per fiber costs $b^{O(1)}=O(q^b)=O(Q)$, absorbed by the fiber's at least $Q$ bits <cite data-source="paper">this work is absorbed by the $QB\ge Q$ bits of the fiber</cite>. These scans follow the split-and-merge pattern of the [elementary stream operations](elementary-stream-ops.md), with counters charged by the same analysis, so the total is $O(V)$.

Let $u$ be a fixed positive integer prime to $q$. The map $y\mapsto uy\bmod Q$ has $u$ increasing runs, and $j=\lfloor uy/Q\rfloor$ is the index of the run containing $y$. Split each fiber into these runs; the output target value $y'$ comes from the run $j$ with $y'+jQ\equiv0\pmod u$, unique since $\gcd(Q,u)=1$, tracked by a counter modulo $u$. Reversing split and merge multiplies by $u^{-1}$. Negation fixes block $0$ and reverses the others by pushing them onto a tape and popping, re-reversing each popped block's bits. Composing these multiplies by any fixed rational unit whose numerator and denominator are prime to $q$, in $O(V)$ <cite data-source="paper">Multiplication of $y$ by any of the specified rational units, and its inverse, also costs $O(V)$.</cite>

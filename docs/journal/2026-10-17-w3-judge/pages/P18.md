Convolution over the polynomial ring computes a normalized convolution of arrays with entries in $\mathbb C[y]/(y^r+1)$ by two forward transforms, a pointwise product and one opposite transform.

The arrays have $d-1$ axes, $d$ being an algorithm parameter, and axis $i$ has length $t_i\in\{2^{\ell-1},2^\ell\}$ with $\ell=\log_2 r$. Let $M=\prod_i t_i$ count the records and $T=rM$ the complex coefficients. Components have $p$ bits of precision; $K$ is the width in bits of the address chunks moved below.

Let $*$ be the [cyclic convolution](cyclic-convolution.md) with ring entries, and $\mathcal M_r(f,g)=\frac{f*g}{rM}=\frac{f*g}{T}$ the normalization of $*$. Each output coefficient averages $rM$ signed scalar products, so $\mathcal M_r$ is a bilinear contraction.

It is computed with the [synthetic transforms](synthetic-transform.md) $F^\pm_{\boldsymbol t}$, which satisfy $F^-_{\boldsymbol t}(f*g)=M(F^-_{\boldsymbol t}f)(F^-_{\boldsymbol t}g)$ and $F^+_{\boldsymbol t}F^-_{\boldsymbol t}=I/M$, so $MF^+_{\boldsymbol t}\bigl((F^-_{\boldsymbol t}f)(F^-_{\boldsymbol t}g)/r\bigr)=\frac{f*g}{rM}$. The forward output is stored in order $LB$, with $B$ the retained frequency order and $L$ the layout permutation defined by the moves below. Let $P(x,y)=xy/r$. Since $LB$ permutes records and leaves their polynomial suffixes intact, $P(LBu,LBv)=LBP(u,v)$. So the stored outputs are multiplied directly, by [signed packing](signed-packing.md), and passed to $\mathcal T_+=F^+_{\boldsymbol t}B^{-1}L^{-1}$ <cite data-source="paper">The two forward synthetic transforms retain the same frequency order through their pointwise product</cite>.

Put $b=(\ell-1)\bmod K$ and $q=\lfloor(\ell-1)/K\rfloor$. Moving the top slot of every long axis and slots $h=b-1,\dots,0$ of all axes to a prefix leaves each axis as $q$ consecutive $K$-bit chunks, at cost $O(TpdK)$ for the $O(dK)$ listed slots. Reordering chunks from axis-major to chunk-index-major uses at most $(d-1)q-1$ exchanges, each $O(TpK^\tau)$ by the [chunk interchange](address-chunk-interchange.md) with fixed $\tau<1$, in total $O(Tp\,pK^{\tau-1})$ because $(d-1)q=O(p/K)$.

A round is a butterfly layer $\mathcal H$ then a twiddle $J_E$, multiplication by a monomial $y^E$, a signed coefficient shift costing $O(rp)$ per record. The first $b+1\le K$ rounds process bits one at a time, exactly, costing $O(TpdK)$. Each remaining round costs $O(Tpd^{\lambda'})$ by the [simultaneous layer](fast-butterfly-layer.md) with fixed $\lambda'<1$, so the $\ell$ rounds cost $O(Tp\ell d^{\lambda'})$.

Truncation $Q_p$ is odd and $J_E$ is a signed coefficient permutation, so $J_EQ_p(\mathcal Hz)=Q_p(J_E\mathcal Hz)$: each round is one truncation after an exact contraction. Each adds error less than $\sqrt2\,2^{-p}$, so $\ell$ rounds give error less than $\sqrt2\ell\,2^{-p}$; layout permutations add none.

Put $\delta=\sqrt2\ell\,2^{-p}$ and $\eta=\sqrt2\,2^{-p}$; each forward error is below $\delta$. As $P$ is bilinear with $\|P(x,y)\|_\infty\le\|x\|_\infty\|y\|_\infty$, the pointwise product has error below $2\delta$, and one truncation gives $\|\widetilde z-z_*\|_\infty<2\delta+\eta$. The contraction $\mathcal T_+$ adds error below $\delta$, so $\|\widetilde h-\mathcal T_+z_*\|_\infty<3\delta+\eta$. Multiplying exactly by $M$ gives error less than $\sqrt2\,M(3\ell+1)2^{-p}$ <cite data-source="paper">has an approximation with error less than</cite>.

There are $M$ pointwise products, costing $O(Tp\log(rp))$, so the cost is $O(Tp[dK+pK^{\tau-1}+\ell d^{\lambda'}+\log(rp)])$.

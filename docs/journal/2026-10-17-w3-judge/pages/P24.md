A controlled cyclic shift adds an offset, computed from earlier control fields, to a later target field modulo a prime power, in time linear in the data volume; the address rearrangements of the main result ([Integer multiplication below n log n](main-theorem.md)) are built from such updates.

Let $q$ be a prime, $b\ge 1$ an integer, and $Q=q^b$. The target is a field $y\in[Q]$ of an array of volume $V$, and it follows its control fields: they come earlier in each record. Let $a\in[Q]$ be the offset, computed from a fixed number of control values of $O(b)$ digits each. The update $y\mapsto y+a \pmod Q$ costs $O(V)$ <cite data-source="paper">costs $O(V)$ if the offset can be prepared in $b^{O(1)}$ time from the fixed number of control values</cite>. A fixed rational linear combination of the controls, reduced mod $Q$, qualifies, and spectator fields of any length may intervene.

**Why it is linear.** Fix all fields before the target. The resulting fiber is $Q$ consecutive blocks, each of $B$ bits, where $B$ is the length of everything after the target. Adding $a$ moves block $y$ to position $y+a \bmod Q$, so the fiber is cut at $Q-a$: blocks $[Q-a,Q)$ become the new positions $[0,a)$, and blocks $[0,Q-a)$ become $[a,Q)$. Split every fiber into these two pieces, appended to two tapes, then merge by reading the second piece before the first. For $Q=8$ and $a=3$, blocks $0,\dots,7$ come out as $5,6,7,0,1,2,3,4$.  Computing $a$ and the piece lengths takes $b^{O(1)}$ time per fiber; since $b^C=O(Q)$ for any fixed $C$, this is absorbed by the $QB\ge Q$ bits of the fiber.

These splits and merges inherit the nested-scan cost analysis of the [Elementary stream operations](elementary-stream-ops.md), so no factor $\log V$ per bit appears.

**Units and negation.** Let $c$ be a fixed positive integer prime to $q$. The permutation $y\mapsto cy \pmod Q$ has $c$ increasing pieces, indexed by $j=\lfloor cy/Q\rfloor$. Split each fiber into these $c$ streams, then produce output positions $y'=0,\dots,Q-1$ in order, taking each from the stream $j$ with $y'+jQ\equiv 0 \pmod c$. This $j$ is unique because $\gcd(Q,c)=1$. Exchanging the roles of split and merge multiplies by $c^{-1}$. Negation keeps block $0$ and reverses the order of the other $Q-1$ blocks: push them on a temporary tape, pop them (which reverses each block's bits too), and reverse each block again on a second tape. Both costs are $O(V)$, as are signed combinations of these operations.

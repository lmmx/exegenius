## 7. The subtle distinction: proof discovery versus proof exposition

There's one architectural distinction I'd draw out.

Exegenius has an explicit argument task: it reconstructs the source's argument as a tree of steps, each with a method, motivation and substeps. It then builds explanatory pages around those steps. It also checks whether quotations support the claims they're attached to and uses simulated readers to find missing explanations.&#x20;

That gives you two related but different products:

- An argument plan: what needs to be established, and how the steps depend on one another.
- An explanatory wiki: how to make those steps understandable to someone with a specified background.

The second is a valuable way to test the first, but it doesn't prove the reconstruction is correct. A simulated reader can successfully understand a beautifully explained misinterpretation.

For Philosophical Investigations, I'd add a third layer: interpretive verification. Every proposed inference should be labelled as explicit, strongly implied, interpretive, or supplied by the reconstruction. Competing reconstructions should be permitted to coexist rather than being forced into a single tree.

## 8. What I'd do with Philosophical Investigations

I'd run a pilot rather than start with the whole book.

1. Choose a connected sequence of remarks from the rule-following discussion, with enough surrounding context to interpret it fairly.
2. Generate the concept graph and argument plan, preserving the original remark numbers and quotations.
3. Inspect whether the system distinguishes Wittgenstein's own claims from objections he considers and positions he rejects.
4. Run the reader audits, then check whether the resulting wiki teaches the argument or merely teaches the model's reconstruction.
5. Compare the output against a second, independently produced interpretation before scaling to the complete work.

The README even provides a pilot mechanism for testing a small portion of a project before paying the cost of a full run.&#x20;

One caveat: Exegenius delegates to a coding agent and does not itself make model calls. Its structural checks are deterministic, but the quality of the philosophical interpretation still depends on the model doing the work.

My conclusion: this is a concrete implementation of the general approach, not merely a conceptual analogue. The particularly promising next step would be to use it to test how far evidence-linked decomposition can go beyond mathematical exposition into genuinely difficult philosophical argument. Wittgenstein would make a demanding benchmark precisely because there isn't always a single uncontested proof to recover.

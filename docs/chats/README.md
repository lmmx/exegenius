# Research conversations

Each directory here archives one research conversation, turn by turn and in order, so that
what was said stays on record. Where the turns have been named by content, a `README.md` in
the directory gives the progression.

| Directory | Conversation | Open research |
|---|---|---|
| `leviathan/` | the sequential, relational method and its failure by premature synthesis | #15 |
| `metrics-viz/` | a model × effort capability landscape | #16 |
| `ir/`, `pi/` | a pre-plan intermediate representation, with Philosophical Investigations as the test case | #17 |

## Where things go

| Place | What it holds |
|---|---|
| `docs/chats/` | the conversations, as they happened |
| `docs/journal/` | what was learned, decided or tested, with links here rather than copies |
| GitHub issues | the research questions and future work a conversation leaves open |
| Pull requests | a concrete change to merge |

An archive is merged when its files are ready, not when its ideas have been explored.
Archiving a conversation does not commit the project to any idea in it: what remains open
goes to an issue.

## Reading (fixed now)

**Judge noise for a plan:** the range of its three judges' faithful counts. A difference is "beyond judge noise" when the two plans' ranges do not overlap.

**Opus `xhigh` lifts the floor** if, on both F4 and F8, its plan:
- passes the gate by majority;
- has no major error;
- has more faithful derivations than the same extraction's reference, beyond judge noise.

**Opus `high` suffices** if, on both extractions, it is within judge noise of Opus `xhigh` on faithful derivations, with the same gate verdict and no more major errors.

**The extraction is the limit** when Opus `high` and `xhigh` both stay below the reference's ceiling on that extraction, and miss the same core results. The cause is then upstream of the argument task.

| Outcome | Action |
|---|---|
| `xhigh` lifts both; `high` does not suffice | propose Opus `xhigh` for the argument task. Fable on this paper's argument task gets a pilot only on an extraction where Opus `xhigh` still falls short of the ceiling; if none does, FB1 moves to a second document, or to auditing the key step |
| `xhigh` lifts both; `high` suffices | propose Opus `high`, the cheaper. The same consequence for FB1 |
| `xhigh` lifts one extraction, not the other | FB1's pilot runs on the extraction not lifted: one Fable run against Opus `xhigh` there |
| `xhigh` lifts neither | FB1's pilot runs on the weaker extraction. Opus `max` is considered first only if its cost is judged worth a second screen |
| the extraction is the limit | no argument-task pilot of Fable on that extraction; FB1's extraction stage is the candidate instead |

**Repeats:** none within S3, unless the two extractions disagree and a third extraction (F2, faithful 14 in J8) would decide between the outcomes above.

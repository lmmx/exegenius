**Status:** authorised by the author on 2026-10-14 at about 23:20 UTC ("I authorise the small, isolated P5 writer-stage experiment"). Written and committed before any W2 run. It fills the exposition row of `policy.md`. The pipeline default is unchanged.

**The decision it informs:** which model and effort the pipeline's writers should use. The current writer configuration is `master`'s.

## Design

**What is held fixed:**
- the plan: E9F4Y, Sonnet `high` with the combined instruction, judged 19/19 faithful and 9/9 central by every J18 judge;
- the sources and the background;
- the task files: rendered by `exegenius-params` (e8efaa3) in six fresh copies of E9F4Y's project, identical apart from the path (checked by diff, 23:25 UTC).

**Two pages,** chosen because they carry the key step:
- `0014-write-common-frame-principle`;
- `0015-write-subset-intersection-labels` (the label-residual-budget page, the result plans most often miss).

**Three configurations, one run per page each.** Each run is a `general-purpose` subagent given the prompt `next` printed, word for word:

| Configuration | Model, effort |
|---|---|
| WH | Haiku, `high` |
| WS | Sonnet, `high` |
| WO | Opus, `xhigh` |

That makes six runs, one project copy per run (`e6/W2{WH,WS,WO}P{14,15}`), so no two runs share state.

## Evaluation (fixed now, before any page exists)

**Blind page judging** (batch J22, after the reset):
- **The judges:** three Opus judges per page, with a page prompt built from J3's item rubric.
- **The material:** each judge gets the paper, the fixed plan's steps assigned to that page, and one page.
- **Per page, the judge records:**
  - for each assigned plan step: absent, stated, or derived, and faithful or not;
  - major and minor errors;
  - whether each sub-step the plan derives is carried onto the page or dropped.
- **The primary measure:** faithful derivations carried from the plan onto the page (of the assigned steps), and major errors.
- **Scale:** 6 pages × 3 judges = 18 judgements.

**Reading:**
- **"Beyond noise":** judges' ranges do not overlap.
- **A configuration is adequate on a page** if its carried-faithful range is not below WS's and it has no more major errors (by median).
- **The cheapest adequate configuration on both pages is the screen's candidate.** The screen supports a writer-model proposal only after a second page set or a repeat.

| Outcome | Action |
|---|---|
| WH adequate on both pages | Haiku is the writer candidate; a confirmation on more pages follows |
| WH not adequate, WS ≥ WO within noise | Sonnet `high` stays the writer; Opus is not worth it here |
| WO above WS beyond noise on both pages | a stronger writer buys fidelity; cost is weighed in a confirmation |

## Result (J22, complete at 23:55 UTC; `docs/journal/2026-10-14-w2-writer/judge/results.txt`, scored by `tools/pages.py`)

The assigned items are counted: page 0014 has 3 (S4.2, S4.2.1–S4.2.2), page 0015 has 8 (S4.3, S4.3.1–S4.3.7). Some judges also itemised nested sub-steps, which are not scored.

| Page | Haiku `high` (WH) | Sonnet `medium` (WM) | Sonnet `high` (WS) | Opus `xhigh` (WO) |
|---|---|---|---|---|
| 0014, faithful of 3 (each judge) | 2, 2, 2; **1 major error** (median) | 2, 3, 3 | 3, 2, 3 | 3, 3, 3 |
| 0015, faithful of 8 | 5, 4, 3 (**below**) | 5, 5, 5 (**below**) | 8, 6, 7 | 8, 8, 8 (within noise of WS) |
| Writer run cache read (0014; 0015) | 1.95 M; 7.82 M | 0.38 M; 2.12 M | 0.34 M; 4.06 M | 1.92 M; 8.13 M |
| Page length (0014; 0015) | 389; 505 words | 415; 487 | 404; 513 | 417; 635 |

**By the table: "WH not adequate, WS ≥ WO within noise", so Sonnet `high` stays the writer, and Opus is not worth it here.**
- **Haiku `high`:** a major error on the easy page, and below WS on the hard one.
- **Sonnet `medium`:** adequate on the easy page, below WS on the hard one.
- **Opus `xhigh`:** within noise of WS on both pages, at about twice WS's cost on the hard page (8.13 M against 4.06 M).

**Reported, not weighed by the table:** on the hard page every Opus judge found all 8 items faithful, while WS's judges found 8, 6 and 7. One run per page and configuration cannot separate that from run variance. A writer repeat on the hard page (WS and WO, two runs each) is the cheapest test of whether it is real.

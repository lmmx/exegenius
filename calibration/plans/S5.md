# S5 (preregistered): a repeat of Opus xhigh on F8, for run-to-run variance

**Status:** written and committed before the run (runbook item 2). The pipeline default is unchanged.

## The decision it informs

**What has to be shown before a configuration is proposed.** Opus `xhigh` beats Sonnet `high` beyond judge noise on F1, F4 and F8. But every one of those comparisons is one run per condition, so how much a second run of the same configuration on the same input differs is unknown. A configuration is proposed for this paper's argument task (runbook §6) only if that variance is smaller than its gain over Sonnet `high`: +3, +6 and +9 faithful derivations.

S5 also tells S4 how much of any Opus `max` against Opus `xhigh` difference on F8 could be run variance.

## Design

**The run, S5F8OX:**
- a fresh copy of E6's project F8, with the argument task rendered by the E7 binary (91c4fed);
- the task file identical to S3F8OX's apart from the path;
- `general-purpose`, `model: "opus"`, `effort: "xhigh"`, the prompt word for word;
- launched alongside S4's run.

**Judging, in S4's batches** (amended in `S4.md` before any S4 result was seen):
- **J12, primary:** three judges.
- **J13, checklist:** two judges.

Both batches contain S3F8OX, the first run, so the two runs are compared within one batch.

## Reading (fixed now)

- **Run-to-run difference:**
  - the difference between S5F8OX's and S3F8OX's faithful medians, and between their checklist means;
  - with their judge ranges, and whether the two runs differ beyond judge noise (ranges not overlapping).
- **What it is set against:** the smallest Opus `xhigh` gain over Sonnet `high` on the faithful count (+3, on F1) and on the checklist (+6, F1's 19 against 13 in K1).

| Outcome | Action |
|---|---|
| the two runs are within judge noise, or their difference is smaller than the smallest gain | the variance condition of runbook §6 is met on F8 |
| otherwise | it is not: more repeats are needed before any proposal, and runbook §6 says so |
